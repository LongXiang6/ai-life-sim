# AI 人生模拟器 - 功能说明

当前版本：**5.7.5**。本版本是相较服务器废弃版 2.7.4 的重写版本，完整差异可在“更新日志”中查看。

## 1. 开始与设置

欢迎页提供新模拟、继续模拟、设置、说明文档和反馈入口。

- **开始新模拟**：从世界选择开始创建一次新人生。
- **继续模拟**：读取最近自动保存的模拟进度。
- **设置**：填写自己的 API Key、网址和模型，并调整流式输出和个性化选项。
- **说明文档**：查看当前帮助与更新日志。
- **反馈与建议**：提交问题或意见并获取反馈编号。

首次使用需要确认免责声明，并在“设置 → 模型与调用”填写自己的 API Key。可一键填入 DeepSeek 官方网址和 `deepseek-v4-flash` 模型，预设不会覆盖已经输入的 Key；当前版本不再提供服务器免费体验模型。

## 2. 世界选择

世界选择页支持预设世界和自定义世界。

- **预设世界**：选择内置世界，并可切换普通、困难、噩梦、地狱难度。
- **更多世界**：展开更多预设项。
- **自定义世界**：输入世界名称、介绍、纪元和年份，再在下一页确认世界空间、本质、力量体系与上限。
- **已保存世界**：读取、编辑或删除本地保存的自定义世界。

确认世界时会显示初始化状态并禁止重复提交。若必要数据生成失败，页面会保留错误信息，玩家可调整配置后重试。

## 3. 世界定制

世界定制页用于微调生成后的世界参数。

- 可查看当前世界摘要与世界描述。
- 空间形态、世界本质、力量体系、力量上限分别支持 **AI / 选择 / 自定** 三种模式。
- 修改后的字段会被保存，并影响命格生成与后续叙事。
- 放弃编辑会返回世界选择，保存会进入角色创建。

## 4. 角色创建

角色创建页用于设定主角。

- **姓名**：可手动输入，也可按性别随机生成。
- **性别**：默认提供男、女，可展开更多选项或自定义。
- **种族**：默认人类，可从种族库搜索，也可添加自定义种族。
- **寿命设定**：按结构化种族配置给出寿命，并由玩家明确设置起始年龄；背景自由文本不会改写年龄。
- **背景信息**：描述身份、经历、穿越/转生等信息；可保存为背景预设。
- **基础属性**：角色创建与命格选择后，在独立属性页为体魄、心智、悟性、魅力分配 30 点基础值，每项范围为 0—10；命格、种族和其他来源的修正单独叠加，后续变化由叙事结构化结果写入。

## 5. 命格选取

命格页会在五个星位中逐项显示本次候选命格，并从 5 条普通命格中选择 3 条进入下一步。

- 五位星盘只在 5 条名称不重复的有效命格就绪后开放选择。
- 点击星位可查看命格，点击详情操作可选择；点击顶部已选命格可取消。
- 命格会展示稀有度、描述、属性修正和系统影响。
- 可从跨局轮回天赋库另选最多 2 项轮回天赋；它们使用独立槽位，不占 3 个普通命格名额。
- 重新抽取会保留已选普通命格，并从本地命格库替换其余星位。

## 6. 命运预览

命运预览页用于开始前的最终核对。

- 页面会展示世界事实、角色、普通命格、两个独立轮回天赋槽、玩家分配的四项基础值及独立修正、背景和寿命摘要。
- 可填写最多 8 位数字的模拟种子；相同种子会传入核心叙事调用。
- 世界初始化区域显示校准、标签、规则配置、实体生成 4 项真实进度。
- 确认后进入主故事页。

## 7. 主故事页

主故事页是模拟运行的核心界面。

- **推进模拟**：生成下一轮叙事，并推进时间、角色和世界状态。
- **时间步长**：支持日、月、季、1 年、3 年、5 年、10 年、50 年、100 年、200 年、500 年和 1000 年共 12 档推进。
- **叙事视角**：每档步长使用独立提示。日级聚焦连续现场与细节，月季级概括阶段变化并落到代表性节点，年度覆盖全年格局与转折，十年至千年逐步提升到人生阶段、家族、制度、文明和时代遗产；所有跨度仍沿同一因果主线，不写流水账。
- **时间边界**：从年切换到月、季或日时，会先跳到下一个未叙述的合法时间节点，避免把已经讲过的年份再次叙述；季节按阳历的 3—5 月春、6—8 月夏、9—11 月秋、12—2 月冬映射。
- **状态面板**：查看角色生命、四项属性、普通命格、独立神话槽、世界信息和系统状态。
- **分支选择**：遇到命运分叉时，先选择或输入行动方向，再继续推进。
- **命运分叉**：顶部信息栏的分叉图标紧邻时间步长，可要求下一轮生成命运分叉，也可在推进前取消。
- **手动存档**：保存到指定存档槽位。
- **自动保存**：每轮叙事完成后自动保存最新进度。

切换时间步长只影响下一次推进，不会在切换瞬间推进时间。

每轮目标字数只是写作节奏提示。系统不会因为偏离目标字数而重复生成或裁掉正文；故事完整性、文笔、代入感和继续游玩的吸引力优先。

## 8. 存档与调试

- **存档管理页**：查看、加载、删除手动存档和自动存档。
- **反馈与建议页**：可从欢迎页或主故事“更多”进入，提交成功后会返回反馈编号。
- **游戏结束页**：仅在模拟完成或角色死亡后展示人生评分、结构化大事、四维评价、真实叙事取样和人生摘要，再按评分档位生成 3 选 1 的轮回天赋；不会从自由文本猜测成就、境界或死因。

直接访问不符合当前流程的页面时，系统会返回合适的上一步，避免破坏当前模拟状态。

## 9. 常见问题

### 为什么生成命格或叙事较慢？

AI 生成速度取决于模型、网络和当前服务响应。若更重视速度，可选择响应更快的模型或关闭推理模式；不建议通过压缩故事篇幅换取速度。关闭 AI 命格生成会进入独立的本地预设模式。

### 为什么切换时间步长后显示更细的日期？

时间标签会按当前选择的步长显示粒度。选择按月会显示月份，选择按日会显示具体日期。

### 自动保存和手动保存有什么区别？

自动保存用于继续模拟入口，手动保存用于保留多个可命名存档槽位。两者都保存在浏览器本地。

### 2.7.4 的存档能直接带到 5.0.0 吗？

不能自动导入。5.0.0 已重写存档结构、运行状态和系统边界，废弃版 2.7.4 的聚合存档不属于当前存档格式。升级后需要开始一段新人生；两个版本使用的浏览器数据可以同时存在，但不要把旧版存档复制成新版本存档。
