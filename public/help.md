# AI 人生模拟器 - 帮助文档

## 1. 欢迎界面

启动应用后进入欢迎界面，提供以下主要功能：

- **🎮 开始新模拟**：创建全新的角色和世界，开始一段全新的人生模拟。
- **💾 继续模拟**：读取之前的存档，继续尚未完成的人生模拟。
- **⚙️ 设置**：配置 AI 接口、主题外观、个性化参数和模型调用。
- **📖 说明文档**：查看帮助信息（当前页面）。

> **提示**：首次使用需要点击**免责声明**的确认按钮，之后才能进入世界选择和角色创建。

---

## 2. 世界选择

在进入新人生模拟前，需要选择一个世界作为模拟背景。

### 2.1 预设世界

预设世界面板展示多个预定义世界，如艾泽拉斯、赛博朋克、三国等。点击即可选择。每个世界包含：

- **名称与图标**：世界的名称和标识 icon
- **纪元与年份**：当前时间起点
- **难度选择**：通过底部按钮切换（普通 / 困难 / 噩梦 / 地狱），影响事件频率和生存压力

### 2.2 更多世界

点击"更多世界"按钮展开额外预设世界列表，以紧凑布局展示更多选择。

### 2.3 自定义世界

点击"自定义世界"按钮展开编辑面板：

- **世界名称**：自定义世界名称（必填）
- **详细介绍**：描述这个世界的设定（必填）
- **纪元设置**：自定义纪元名称和年份
- **世界观类型**：选择唯物 / 唯心 / 混合 / 自动，决定世界基本法则
- **自动年号系统**：启用后年号随时间线自动切换

> 自定义世界会自动保存至浏览器本地，可在"已保存世界"面板中找到。支持编辑和删除。

### 2.4 世界模拟系统

v2.9 重构为 **中控—六大类节点—子系统** 三层架构，共 **56 个子系统** 按六大类组织：

| 大类 | 子系统数 | 核心职责 |
|------|:------:|----------|
| **基础宇宙** | 5 | 天象运行、纪元演化、世界地图空间形态、神明创世、命运预言 |
| **力量体系** | 12 | 修炼境界、战力评级、神明干涉、怪物生态、信仰之力、气运/机缘/金手指/超凡物品/特殊材料/异常现象 |
| **科技水平** | 7 | 主导产业、文化技术传播、教育知识、货币演变、商路网络、科技资源、信息媒体 |
| **社会文明** | 23 | 社会分层/阶级流动、势力动态、国家关系、贵族家族、法律体系、市场周期、经济/声望、人际关系/家庭、人生阶段、定居点、人口/识字率/人口流动、传统/艺术、成就/著作/弟子、健康/善恶、教育制度 |
| **历史动态** | 4 | 时间线生成(9级影响级别+分阶段滑动窗口)、背景事件、游戏事件 |
| **环境生态** | 6 | 气候/季节、地形地貌、生态系统、资源丰度/污染、自然资源、地理特征 |

**三层架构说明**：

| 层 | 组件 | 职责 |
|----|------|------|
| **L1 中控** | orchestrator-v2 | 回合节拍器 + AI 调用协调器，收集各节点状态组装提示词 |
| **L2 节点** | 六大类节点容器 | 节点内迷你编排器，封装内部子系统调度，暴露 collectState + applyChanges |
| **L3 子系统** | 56 个子系统 | 具体数值计算引擎，暴露 advanceState + formatForPrompt 标准接口 |

> 中控 orchestrator-v2 已完全接入 CategoryNode 管线（createAllCategoryNodes → restoreState → Gateway 收集 → EventBus 跨域联动 → applyChanges），旧三大域调度器（character-domain/society-domain/world-domain）已移除。

**v2.7 新增网文模块**：
- **金手指系统**：6 种金手指类型（系统面板/修炼传承/先天能力/知识觉醒/血脉觉醒/命运契约），按世界观自动分配
- **机缘奇遇系统**：三级奇遇（小机缘/大奇遇/传说级），运气+难度+金手指加成掷骰决定触发频率
- **冲突打脸循环**：嘲讽→打压→反击→打脸→余波，六阶段状态机自动插入挑衅事件
- **突破节奏控制**：修炼系统新增境界间隔年数、瓶颈绝望叙事、突破预兆等级
- **盟友原型生成**：关系系统新增 8 种盟友原型（冷面师姐/憨厚兄弟等）、羁绊系统
- **文化习俗增强**：传统系统新增节日池（12 个）、仪式池（8 个）、禁忌池（9 个）
- **有序叙事格式**：多年跨度时 AI 按时间顺序分段返回叙事，支持 JSON 数组和纯文本双格式

**v2.8 新增可选扩展子系统**：
- **语言与命名系统**：音素池按世界观分层（古汉语/修真通用语/精灵语/星际通用语/废土通用语/变异人语等 9 种），语言演化（消亡/方言分化/人数变动），势力命名模板（中国文化/武侠/中世纪奇幻/星际科幻/赛博朋克/废土等 9 种世界观）
- **社会价值观系统**：12 种社会核心价值观（尚武/和谐/自由/秩序/虔诚/创新/生存/自然/求知/平等/祖先崇拜/个人主义），按世界观自动筛选启用。每季度随机扰动优先级，当次要价值观超过主导值 10 分时进入变迁期，积累完成后切换社会核心价值观。主导价值观通过权重修正系数联动法律系统（判罚尺度）、声望系统（声誉计算）和经济系统（贸易效率）
- **特殊材料系统**：16 种特殊材料按世界观分池（修仙·灵石/灵气晶核/天外陨铁，奇幻·秘银/精金/龙鳞，科幻·暗物质结晶/反物质碎片/量子核心/纳米蜂群，废土·强辐射同位素/变异原液），稀有度分级（普通/稀有/罕见/传说），每季度掷骰发现，库存追踪与自动补货
- **命运与预言系统**：12 个预言模板按世界观筛选（修仙3/奇幻3/古代2/科幻3/废土1），预言来源包括星象/神谕/梦境/天启/器物。每季度推进应验进度，到达目标季度自动应验（progressFulfill=100），每 12 季度有 5% 概率自然生成新预言。可主动打破预言，累积因果惩罚值，惩罚超 100 触发天罚事件
- **信息与媒体系统**：6 级媒体技术类型（报纸→广播→电视→互联网→神经网），19 个跨世界观话题模板，每季度热点生成/消退，公众情绪追踪+舆论风暴事件检测，识字率影响传播速度
- **生物多样性系统**：27 种物种模板按世界观分池（修仙·灵兽/奇幻·传说生物/科幻·外星生命/废土·变异体），每季度种群自然波动，灭绝威胁累积（生态系统恶化+气候极端事件加剧），威胁超 80 时每轮 10% 概率灭绝，生物多样性指数随灭绝事件下降（满分 100）

#### AI 初始化系统

创建/编辑自定义世界时，AI 会自动生成以下数据并持久化：

- **26 项子系统参数**：AI 根据世界描述生成人口、生态、天象、季节、怪物、神明、资源、社会阶层等参数
- **世界观标签**：修炼体系、武力层次、科技水平等约束性标签
- **世界时间线**：历史重大事件 + 未来趋势预测
- **具名实体**：国家名、势力名、贵族世家、定居点名（含中文描述）
- **世界观分层配置**：天象事件、资源分布、艺术风格、神明体系、战力评级、人生阶段事件、修炼境界、怪物种类、物品系统、势力模板、国家名称池、社会阶层标签均按世界观类型自动适配（修仙/科幻/奇幻/废土/现代各有独立设定）

以上 4 类 AI 数据并行生成，任一项失败不影响其他项。游戏启动时优先使用 AI 生成数据，缺失时回退到预设默认值。

### 2.5 世界标签系统

每个世界都有标签系统，用于约束 AI 生成符合世界观的内容：

- **修炼体系**：禁止修炼、内力、魔法、超自然异常等
- **武力层次**：无、低武、中武、高武、超武、神级
- **科技水平**：无科技、农业时代、工业时代、信息时代、未来科技
- **世界类型**：历史、科幻、奇幻、战争、都市、星际、无限流等
- **禁止事项**：禁止超自然、禁止修炼、禁止魔法等
- **世界观适配**：古代世界自动禁止手机/互联网/汽车等现代产品

> 预设世界已预先生成标签；自定义世界保存时自动生成。

## 3. 世界自定义

选择世界后进入世界自定义界面，可微调 AI 生成的世界参数。

### 3.1 自定义字段

展示 **40+ 可编辑字段**，按子系统分组（经济基础、科技水平、社会文明、力量体系、基础宇宙、环境生态）：

- 每个字段显示 AI 原始值（灰底）和玩家编辑值
- 支持滑块（数值）、下拉（选项）、数字输入框三种控件
- 修改过的字段高亮显示，便于区分

### 3.2 操作按钮

- **恢复默认**（桌面端）/ **放弃编辑**（移动端）：清除所有编辑值，返回世界选择
- **保存并继续**（桌面端）/ **保存**（移动端）：保存覆盖值，进入角色创建

> 保存的覆盖值会优先于 AI 生成值使用，影响后续命格生成和模拟。

## 4. 角色创建

选择世界后进入角色创建界面，自定义角色特征。

### 4.1 基础设定

- **性别**：选择角色的性别（男 / 女）
- **物种**：选择物种（人类 / 外星人 / 动物等，根据世界设定可用选项不同）
- **背景身份**：选择角色的出身背景（平民、贵族、孤儿等）

> 不同物种影响初始属性基础值，背景身份影响社会地位和初始资源。

### 4.2 属性分配

通过加点/减点分配角色的 7 项基础属性：

- **武力**：战斗能力、力量判定
- **敏捷**：闪避、速度、灵活度
- **智力**：学习能力、法术强度
- **魅力**：社交、交涉、领导力
- **感知**：洞察、警觉、预判
- **幸运**：随机事件中的有利概率
- **意志**：抵抗压力、精神强度

> 可通过"重置"和"平均"按钮快速调整。

同时角色拥有 **6 项固定动态属性**（财富、声望、权力、学识、技艺、人脉），不同世界观下显示名称不同——例如修仙世界显示为"灵石、仙名、修为、道行、功法、仙缘"。

### 4.3 天赋抽取

完成属性分配后，进入天赋抽取页面：

- 每次生成展示多个天赋选项
- 每个天赋有稀有度（普通 / 稀有 / 史诗 / 传说）
- 选择一定数量的天赋作为角色的独特能力

> AI 天赋生成功能可在个性化设置中开启，开启后由 AI 实时生成更具多样性的天赋。

### 4.4 命运预览

完成天赋选择后进入命运预览页面：

- **人生方向选择**：展示 6 种人生方向原型（守护者、探索者、征服者、创造者、求道者、自由者），每种方向有预设的权重分配（财富/声望/权力/能力/人脉），影响模拟叙事走向。默认选中"自由者"（全权重 1.0），可直接进入下一步
- **自定义方向**：可输入自定义方向文本，自由定义想要的人生道路
- **角色摘要**：展示角色基础信息、属性分配、天赋列表、故事种子

> 人生方向可在模拟过程中随时切换（见"系统状态面板"）。

## 5. 人生模拟

开始模拟后，以文字叙述形式体验角色的整个生命周期。

### 4.1 叙事流程

模拟以"年"为单位推进，每轮展示当前年份的叙事文字：

- 叙事由 AI 根据角色属性、世界背景、56 个子系统状态和当前事件动态生成
- 每轮叙事 200-400 字（可在设置中调整）
- **差异传输系统**：40 个系统字段按变化频率分 4 个等级传输给 AI，大幅降低每轮 token 消耗
- 叙事持续到角色自然死亡或意外结束

### 4.2 流式叙事

支持 3 种叙事播放模式（可在个性化设置中切换）：

- **关闭**：等待 AI 完整生成后一次性显示
- **流式输出**：AI 生成过程中实时逐字显示
- **打字机效果**：模拟打字机逐字显示，更具沉浸感

### 4.3 分支选择

在模拟过程中会遇到关键分支节点：

- 分支出现在人生重大抉择时刻
- 每个分支有多个选项，选择不同走向影响后续命运
- 分支按钮开启后会持久保持，不会自动消失，方便反复斟酌

### 4.4 预生成系统

减少因分支选择导致的 token 浪费：

- 系统可预先生成后续 0~3 轮的叙事内容
- 在个性化设置中调整"预生成轮数"
- 如果玩家在预生成轮数内没改变选择，已生成的叙事直接使用，节约 token

### 5.5 系统状态面板

核心模拟页面右侧提供系统状态面板，聚焦角色相关信息：

- **📍 你的周边**：定居地、势力、国家、人口、商路（蓝色标签）
- **🌍 基础状态**：季节、气候、纪元、方向、年龄效应、生命阶段（绿色标签）
- **👤 角色状态**：健康、家庭、人际关系、声望、技能、知识、成就、物品、运气（橙色标签）

> 点击角色名后的 🧭 方向标签可随时切换人生方向。因果事件触发时底部会出现金色提示。

### 4.6 控制按钮

- **自动模式**：开启后每间隔自动推进年轮
- **快进模式**：开启后跳过叙事间隔快速推进
- **更多**：存档、分支回溯等功能

### 5.7 存档管理

随时保存当前模拟进度：

- 存档包含角色完整状态和当前世界信息
- 可创建多个存档位
- 读取存档时自动恢复上次进度

## 6. 身后事系统

当角色生命走到尽头时，世界不会立即停止。

- 世界继续模拟 **3~8 轮**，展示角色死后的世界变化
- 最终生成完整死亡结算报告，包含中文死因说明

### 6.1 五维评分

AI 从 5 个维度评分：

- **武力征服**：战斗成就、领土扩张
- **经济发展**：财富积累、贸易贡献
- **文化影响**：知识传播、艺术创作
- **传世贡献**：发明创造、制度建设
- **世界影响**：对世界格局的总体改变

评分以**雷达图**可视化展示，并附 AI 生成的关键转折点里程碑和总人生评价。

## 7. 设置

在欢迎界面点击 ⚙️ 设置进入。

### 6.1 个性化（主题与预设）

**主题切换**：支持 6 种主题风格：

- 暗黑宇宙（Dark Cosmos）
- 极光晨曦（Light Aurora）
- 赛博霓虹（Cyber Neon）
- 极简暗黑（Minimal Dark）
- 极简明亮（Minimal Light）
- 书香阅读（Book Reader）

所有主题配色经过软化处理，避免纯黑纯白带来的视觉疲劳，不同主题下文字对比度均清晰可读。

**预生成轮数**：设置 AI 预生成后续叙事的轮数（关闭 / 1轮 / 2轮 / 3轮）。适当预生成可减少分支选择后的 token 浪费。

**AI 缓存命中率**：实时显示 DeepSeek 缓存命中/未命中的 token 数量，带刷新和重置按钮。

**预设管理**：支持导入/导出预设配置（包含主题、世界和角色预设），支持加密导出。

### 6.2 模型设置

**AI 天赋生成**：开关控制是否使用 AI 实时生成随机天赋。

**推理模式强度**：控制 AI 推理深度：

- 关闭：不启用推理
- 普通强度：基础推理
- 高强度（推荐）：深度推理
- 最大强度：最大推理

> 不同模型对推理参数的支持情况不同，如果报错请关闭此功能。

**每轮叙事字数范围**：设置每轮 AI 生成内容的最小和最大字数（默认 200~400 字）。

**叙事风格**：控制 AI 叙事的整体文风：

- **默认**：由 AI 根据世界设定自行判断叙事风格
- **史诗**：宏大时空跨度、崇高措辞、强化命运感
- **写实**：平实客观的叙事风格
- **诗意**：富有诗意的叙事风格

> 叙事风格立即生效，无需重新开始模拟。

**Temperature**：控制 AI 生成随机性（0~2，默认 0.7）。值越高越有创意但越不稳定。

**Top-P**：核采样阈值（0~1，默认 0.85）。控制 AI 从概率累积达阈值的候选词中选择。

### 6.3 模型调用

**API 模式**：切换使用服务器 API 还是自定义 API。

- **服务器 API**：使用内置 API 配置，无需额外设置
- **自定义 API**：自主填写 API Key、网址和模型名

**预设模型**：选择模型厂商和对应模型后自动填入 API 信息。

**自定义 API 参数**：添加额外请求参数（Key-Value 形式）。

## 8. 常见问题

### Q: 为什么 AI 响应很慢？
A: 响应速度取决于 AI 模型性能和网络状况。可在设置中关闭推理模式、减小字数范围、或降低预生成轮数来提高响应速度。

### Q: 如何更换 AI 模型？
A: 在设置 → 模型调用中选择预设模型或填写自定义模型信息。

### Q: 存档存在哪里？
A: 存档保存在浏览器 LocalStorage 中，同时自动同步到 OPFS（浏览器私有文件系统）。清除浏览器缓存不会丢失存档；只有手动清除站点数据才会丢失。建议定期导出预设备份。

### Q: AI 缓存隔离是什么？
A: 游戏会自动为不同类型的 AI 调用分配独立的 KVCache 池（叙事/总结/世界初始化/命格/低频），通过 DeepSeek 官方 `user_id` 参数隔离。同类请求共享缓存前缀，可大幅降低 token 费用（缓存命中仅需 0.1元/百万tokens）。首次进入游戏自动生成用户标识，同一设备持久化保存。

### Q: 为什么会显示 API 错误？
A: 请检查 API Key 是否有效、模型名称是否正确，以及 API 服务商是否正常运行。

### Q: 自定义世界的详细介绍有什么限制？
A: 使用服务器 API 或默认 DeepSeek 时，世界详细介绍不能超过 2000 字；使用自定义 API 时无字数限制。

### Q: 叙事风格有什么用？
A: 叙事风格控制 AI 写故事的语气和风格。可在设置 → 模型设置中随时切换，切换后立即生效。

### Q: 什么是预生成轮数？应该设多少？
A: 预生成让 AI 提前生成后续叙事，省去等待时间。如果经常在分支选项中来回切换，建议关闭或设为 1 轮以避免浪费 token。如果选择比较果断，设为 2~3 轮可减少等待。

### Q: 流式输出和打字机效果有什么区别？
A: 流式输出是 AI 生成一句显示一句，打字机效果是逐字显示。后者更沉浸但看起来稍慢。

### Q: Temperature 和 Top-P 应该怎么调？
A: 默认值适合大多数场景。如果觉得叙事太"安全"可以适当调高 Temperature；如果觉得内容太随机可以降低。Top-P 一般和 Temperature 配合使用，不建议同时调很高。
