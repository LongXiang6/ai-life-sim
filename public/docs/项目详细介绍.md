# AI 人生模拟器 — 项目介绍

> 版本 4.0.5 · Next.js 16 + React 19 + TypeScript · MOD 插件架构

## 是什么

**AI 人生模拟器**（`ai-life-sim`）是一款由大模型驱动的文字人生模拟游戏。玩家在自定义世界中经历从出生到死亡的完整人生，每一回合由 AI 生成叙事，数十个子系统（经济、政治、战力、文化、世界时间线等）在后台协同运算，形成可回溯、可压缩的长线故事。

## 核心架构

项目采用 **MOD（Module-On-Demand）插件架构**，借鉴 [Factorio Data Lifecycle](https://lua-api.factorio.com/latest/auxiliary/data-lifecycle.html) 的分阶段加载思想，并适配 TypeScript / Web 技术栈：

```
Foundation（类型 / Token / 工具）
    ↓
Core（MOD 加载器 · EventBus · 全局 Store · AI 服务）
    ↓
MOD 层（mod-engine · mod-world · mod-character · … 18 个业务模块）
    ↓
App（Next.js 薄路由）
```

### 加载阶段（Factorio 映射）

| 阶段 | 作用 |
|------|------|
| **Settings** | 三回合配置声明与交叉校验 |
| **Prototype** | manifest / 子系统 / provides 一致性校验 |
| **Control** | `_internal/control.ts` 窄入口执行 lifecycle |
| **onInit / onLoad** | 运行时初始化与存档恢复 |
| **RuntimeRegistry** | loader 完成后冻结只读快照（data.raw 等价） |

Codegen 维护三类 importer：`MOD_CONTROL_IMPORTERS`（lifecycle）、`MOD_SUBSYSTEM_IMPORTERS`（按文件注册子系统）、`MOD_API_IMPORTERS`（Remote API）。

### 叙事回合（Phase 10）

AI 响应经 **解析 → 三步拦截器（安全 / schema / 死循环）→ RoundCommit 总线** 才写入子系统，叙事与状态提交硬分离。

## 主要 MOD

| MOD | 职责 |
|-----|------|
| `mod-engine` | 编排器、时间推进、叙事解析、记忆压缩、回合管线 |
| `mod-world` | 世界生成、实体、时间线、校准 |
| `mod-character` | 角色属性、命格、健康、寿命 |
| `mod-power-system` | 战力、修炼、怪物、气运 |
| `mod-economy` / `mod-politics` / `mod-culture` | 经济、政治、文化与社会 |
| `mod-pages` | 游戏流程页面（世界选择、角色创建、故事主界面等） |
| `mod-ui` | 液态玻璃风格 UI 组件 |

完整列表见 `src/mods/registry.generated.ts`。

## 工程化与质量闸

```bash
cd ai-life-sim
npm run dev                  # 开发（自动 generate:wiring）
npm run mod:create mod-xxx   # 新建 MOD 脚手架
npm run check:structural     # 架构扫描（编码前）
npm run gate-check:quick     # lint + tsc + check（L1 关闸）
npm run gate-check           # 全量关闸（L2/L3）
```

架构规则由 `scripts/check/` 域化扫描器执行（A-01 barrel、D-07 import 图、ATCE 信号等）。详细作者规范见同目录 [MOD作者清单.md](./MOD作者清单.md)，Factorio 映射见 `docs/FACTORIO-LIFECYCLE-MAP.md`。

## 技术栈

- **框架**：Next.js App Router、React 19
- **状态**：Zustand（全局 Store + 各 MOD 独立 store）
- **AI**：可配置模型、流式叙事、分段 Prompt / KV Cache 优化
- **UI**：Liquid Glass 设计体系（`mod-ui`）

## 目录速览

| 路径 | 说明 |
