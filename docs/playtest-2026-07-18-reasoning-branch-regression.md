# 2026-07-18 主叙事推理与自定义分支回归

## 目标

复现 5.0.3 玩家反馈：命格与首轮叙事正常，多轮后间歇性出现“推理错误”；自定义命运分支持续失败。真实模型验收只使用 DeepSeek 官方 Provider：`deepseek / deepseek-v4-flash`。未使用 `managed / dasuapi` 中转平台。

## 基线与根因

1. 标准示例包含条件字段“命运意图判定”。模型在没有当前玩家意图时偶尔照抄该字段；本地原逻辑把它作为无主意图写入错误，导致合法分支数据整包不提交。
2. 模型会把无变化写成 `关系变化:[]`、`已回收伏笔编号:[]`、`新延迟因果:[]`、`命运分支:false` 或空条件对象。严格最小数组门禁把这些无语义噪声判为协议失败。
3. 模型偶尔使用可选描述枚举近义词，例如“隐藏信息”“怀疑”，导致整包 Schema 失败。

## 修复

- 协议边界只对无语义噪声做归一：可选空数组、`命运分支:false`、空的“命运意图判定”对象视为省略；不补字段、不猜测剧情、不截断正文。
- 可选描述枚举的近义词归入“其他”并保留说明；未知可写系统、字段、核心枚举与不完整分支仍严格拒绝。
- 无聚焦意图时动态提示明确禁止复制条件字段；本地只丢弃误复制的 `intentResolution`，保留合法正文、摘要、语义与分支。
- 当前命运意图或强制分支最多进行两次同一失败原因的针对性协议修复；仍失败时不伪造结果，聚焦意图保持未完成。
- 诊断质量保留实际正文字符数与段落数，避免条件失败被错误记录为 0 字。

## 确定性证据

| 用例 | 结果 |
|---|---|
| `npm run test:narrative-protocol` | PASS；新增空数组、`false`、空条件对象和近义枚举回归 |
| `branch-intent-resolution-smoke.mjs` | PASS；稳定 ID、无额外前置调用、持续意图快照仍有效 |
| `npm run test:prompt-wiring` | PASS |
| DeepSeek 自定义意图真实调用 | 多次首稿通过；含空数组、`命运分支:false` 和近义可选枚举的响应可被本地协议边界安全归一 |
| DeepSeek 强制分支真实调用 | 首稿或至多一次针对性修复后通过三段正文、完整摘要、分支标题和 2—4 个选项 |

## 结论

本轮问题不是字数不足，也不是通过截断修复；主要是模型复制条件示例和可选无变化字段造成的协议误判。修复保持正文、摘要和全部剧情事实完整，继续严格保护当前意图 ID 与可写状态。后续交付仍需跑全量 `gate-check`、构建、提交推送和服务器部署验证。
