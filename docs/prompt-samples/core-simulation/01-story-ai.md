# 故事 AI Prompt 样品

## 样品范围

[核心原则1] 故事 AI 的唯一产品是正文、命运分支和结局。

[核心原则2] 故事 AI 只接收故事成立所需的稳定世界事实、连续历史与角色当前叙事语义，以及本轮白话引导。

[核心原则3] 属性计算、天赋等级与成长、事件登记、剧情阶段、事实审计和状态写入由各自后调用或本地所有者负责，不进入本调用。

## 发送顺序

1. 系统 Prompt。
2. 第一条用户消息：稳定世界事实 JSON。
3. 第二条用户消息：先放追加型历史剧情和最近两轮详细剧情，再放会随回合变化的角色语义。
4. 第三条用户消息：当前时间、玩家行动、年龄边界、挑战与失败取向、称呼方式、文风和篇幅；存在已到期且仍可用事项时，同一消息增加 `当前到期事件`。

三条用户消息均为完整标准 JSON 对象，对象外不添加标签或说明。

## 调用职责

本调用根据已经成立的世界事实、连续记忆和本轮引导生成合理故事。只有抵达实质互斥且必须由玩家决定的走向时输出分支；只有当前人生永久失去意识、感知、决定、行动和任何新经历时输出结局。

世界消息只保存稳定事实。历史与角色消息以历史数组和最近两轮详细剧情开头，使追加型记忆位于会变化的年龄、属性语义和天赋之前；普通命格和轮回天赋在此调用中统一投影到 `天赋` 键。当前区域和状态变化 AI 的状态投影不进入故事输入；引导中的挑战与失败取向、时间、玩家行动、年龄边界、称呼方式、文风和篇幅均使用完整句子。

## 输出格式

调用一次 `submit_story_turn`，参数为：

```json
{
  "正文": "<完整中文故事>",
  "分支": "null",
  "结局": "null"
}
```

普通故事的分支与结局均填写字符串 `null`；需要玩家选择时把分支填写为包含 2 到 4 个第二人称可执行行动的 `{"选项":["<选项一>","<选项二>"]}` JSON 字符串；永久失去意识、感知、决定、行动和任何新经历时把结局填写为包含 `{"四字评语":"<四字评语>"}` 的 JSON 字符串。三个顶层键各出现一次，分支与结局互斥。
