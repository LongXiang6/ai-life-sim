# 故事 AI Prompt 样品

## 样品范围

[核心原则1] 浏览器只发送动态数据；服务端受保护资产把 `D:/AI/docs/prompt.txt` 的固定规则与动态数据合成为模型实际接收的一条 `user` 消息。

[核心原则2] 动态数据严格使用五元素数组，字段依次为 `世界`、`玩家信息`、`历史输出`、`玩家本次点属性`、`本次信息`。

[核心原则3] `历史输出.事件`来自既有历史投影；所有未压缩轮次优先投影同一条叙事历史记录保存的结构化事件结果，缺少结果时才回退完整正文，不把两者重复拼入输入，也不用末句或结局评语替代整轮记录。压缩轮次沿用记忆所有者的事实投影，不新增第二世界状态源。模型只继承已成立事实，已结束事件身份不成为新题，不继承旧正文的焦点、结构或措辞。

[核心原则4] 模型依次输出 `时间定位`、`事件结果`、`正文`、`命运分支`、`属性`、`结局`，不强制工具调用；应用只消费后四项。事件结果统一承载世界与人生事件，每项包含事件、成因、结果和影响。

[核心原则5] 主身份为文字游戏式人生重开模拟器的世界演化与事件裁决系统。每轮先恢复事实并形成世界自主变化，再裁决玩家合龄的因果位置与新事结果，最后编译有重心、可感知的广角人生记录。世界明确规则优先于与之冲突的旧生成叙述，已确认自创事实的来源归属不为情节翻案。既有处境和已结束事件身份不自动指定题目；没有命运分支不等于角色不能行动。已确认意图落实为行动与世界响应，未决结果依条件裁决。事件、具体表现、两面性与意外具有共同因果，不强制惩罚或反转。宏观不是扩大规模，也不等于公共新闻起笔；年度跨度由过程压缩后的结果与处境变化体现；正文入口和远近视野由结果决定，不固定转场。第二人称只代指玩家，不限定句首；时间关系留在前置内部字段。

## 发送顺序

模型只接收一条由服务端按 `D:/AI/docs/prompt.txt` 的代码区块顺序组装的 `user` 消息，不接收独立主故事 `system` 消息。各阶段规则从1编号，阶段与段内规则按编号从小到大处理；编号不表示优先级。开头定义身份、权限与核心产物；五段动态数据集中位于只读输入区，数据之后依次恢复事实、形成世界局面与离散新事、裁决参与和结果、编译正文并结算。事实划定成立边界，玩家选择提供意图而非保证结果，后续区块使用前置结果。

`时间定位`只用于本次定位，不进入游戏状态、存档或界面；`事件结果`在正文提交后由同一条叙事历史记录保存，并投影到下一轮输入，不向玩家展示，也不成为独立世界状态。原始响应日志完整保留；正文采用的关键事实和因果由正文及事件结果共同进入既有历史。此处只演示字段结构，不作为内容质量合格样本或固定事件来源。`正文`供玩家阅读。`属性`输出四项结算后的当前值，本地相对输入换算为单轮差值；公开中文属性名使用 `财富`，内部由 `familyBackground` 所有者校验和提交。
