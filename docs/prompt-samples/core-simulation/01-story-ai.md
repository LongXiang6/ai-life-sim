# 故事 AI Prompt 样品

## 样品范围

[核心原则1] 浏览器只发送动态数据；服务端受保护资产把 `D:/AI/docs/prompt.txt` 的固定规则与动态数据合成为模型实际接收的一条 `user` 消息。

[核心原则2] 动态数据严格使用五元素数组，字段依次为 `世界`、`玩家信息`、`历史输出`、`玩家本次点属性`、`本次信息`；实际时间窗口放在现有 `本次信息` 内，不增加顶层元素。

[核心原则3] `历史输出.事件`来自既有历史投影；所有未压缩轮次优先投影同一条叙事历史记录保存的结构化事件结果，缺少结果时才回退完整正文，不把两者重复拼入输入，也不用末句或结局评语替代整轮记录。压缩轮次沿用记忆所有者的事实投影，不新增第二世界状态源。模型只继承已成立事实，已结束事件身份不成为新题，不继承旧正文的焦点、结构或措辞。

[核心原则4] 模型依次输出 `时间定位`、`事件结果`、`正文`、`命运分支`、`属性`、`结局`，不强制工具调用；应用只消费后四项。事件结果统一承载世界与人生事件，每项包含事件、成因、结果和影响。

[核心原则5] 主身份为文字游戏式人生重开模拟器的世界演化与事件裁决系统。固定职责先读，五段动态数据集中提供，之后恢复事实、形成世界自主变化、裁决玩家合龄因果位置与多项新事结果，先让主线具备目标、阻力、选择、转折、结果和代价，再编译有吸引力的广角人生记录。事件有主次；正文以行动、玩家位置、因果转向、结果和代价组织，不平均罗列，也不限制事件数量或题材。世界明确规则与事实来源不因情节需要被改写，历史只承接事实、不指定新题。宏观来自外部局面及整体与具体之间的视野切换，故事吸引力来自人物行动、选择后果和已成立结果，不靠固定反转或连续小说过程。玩家使用第二人称但不固定句首。正文不是按年龄或时间流逝回顾一段生活，不是成长履历或家庭流水账；时间索引只供内部判断，成文以状态变化、行动、转折、结果和代价体现跨度，不复述输入索引或历法表达。

## 发送顺序

模型只接收一条由服务端按 `D:/AI/docs/prompt.txt` 的单向生成流程组装的 `user` 消息，不接收独立主故事 `system` 消息。固定规则、五段只读数据、结算和返回协议按同一顺序提供；模型在一次调用内恢复事实、形成外部局面、裁决玩家交互与结果、编译正文并返回。

## 输出格式

```json

  "时间定位": "",
  "事件结果": [

  "正文": "南境叛军夺取漕运枢纽，你联合州兵与商会切断其补给，守军倒戈，粮道恢复。北境军镇以稳定军粮换取归附，边镇兵权收归朝廷。旧都世家失去盐引专营，转以商税换取新政席位，朝廷财赋增厚，门阀与皇权的利益格局重新划定。",

  "属性": { "心智": 1, "体魄": 0, "魅力": 1, "财富": 1 },
  "结局": false

```

`时间定位`只用于本次内部定位，不进入游戏状态、存档或界面；`事件结果`在正文提交后由同一条叙事历史记录保存，并投影到下一轮输入，不向玩家展示，也不成为独立世界状态。原始响应日志完整保留。此处只演示字段形状，不作为内容质量样本或固定事件来源；动态时间索引不应转写进正文。`属性`输出四项结算后的当前值，本地相对输入换算为单轮差值；公开中文属性名使用 `财富`，内部由 `familyBackground` 所有者校验和提交。
