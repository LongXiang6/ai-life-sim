# 核心模拟 Prompt 样品索引

## 样品范围

[核心原则1] 每个样品只描述一个 AI 调用的唯一功能、必要输入和必要输出。

[核心原则2] 样品是正式 Prompt 与调用职责的审查基线；运行时只保留与该基线一致的活动职责。

[核心原则3] 01 是故事前调用；02 与 03 在正文验收后由本地编排器并行触发，后调用之间不存在 AI 调用 AI 的依赖。

[核心原则4] 01 至 03 的固定系统 Prompt 与直接产品都使用可由 `JSON.parse` 解析的中文 JSON。

## 调用矩阵

| 顺序 | 文件 | 唯一功能 | 调用条件 |
|---:|---|---|---|
| 1 | [故事 AI](01-story-ai.md) | 生成正文、命运分支和不限于死亡的结局 | 每轮 |
| 2 | [故事连续性提取 AI](02-story-continuity-ai.md) | 提取当前回合的已发生记忆和有明确时间的未来事件 | 正文验收成功后 |
| 3 | [天赋成长判定与路线生成 AI](03-talent-growth-ai.md) | 判断一项已选天赋是否成长，并在成立时生成三个方向 | 存在仍有下一等级的已选天赋且正文验收成功后 |

## 正常建局共享基线

[核心原则1] 三份样品使用同一局已经完成世界选择、世界配置、角色创建、四槽命格选择、属性分配和命运预览的事实；共享基线证明上游信息完整，每个调用仍只接收完成自身职责所需的投影。

| 来源步骤 | 已确认信息 | 本组样品值 |
|---|---|---|
| 世界选择与配置 | 名称、描述、空间形态、世界观本质、力量体系、力量边界、文明阶段、挑战取向、节庆范围 | 雾潮群岛；位面；唯物修仙；潮汐劲有限体系；海贸城邦；合理挑战、行动可因条件不足失败；中国节庆 |
| 世界初始化 | 历法、当前区域、世界规则、气候、主要资源、力量进度、世界阶位、瓶颈、训练天赋 | 潮历；赤潮矿寨；湿冷多雾；赤铁砂与盐晶；潮汐劲进度 22；凡俗二阶；瓶颈 40；潮息训练 |
| 角色创建 | 姓名、性别、种族、种族规则、背景、起始年龄、当前年龄、预期寿命 | 岑澜；女；潮裔；18 岁开始；当前 19 岁；预期寿命 150 年；矿寨测潮学徒兼浅海潜水员 |
| 属性分配与修正 | 四项基础值、命格与种族修正、当前有效值、气运 | 基础值体魄 4、心智 4、悟性 4、魅力 3；修正后当前值 6、6、5、4；气运 4 |
| 四个携带槽 | 普通命格与轮回天赋的类型、类别、等级、当前效果和完整属性加成 | 听潮辨隙、耐压持息、守约成章、轮回天赋灰烬回响 |
| 模拟设置 | 叙事风格、时间步长、正文篇幅、模型条件 | 写实冒险；按轮次切换日/月/季度/年；正文目标随跨度变化；DeepSeek v4 flash、关闭 thinking、非流式 |

[主要规则1] 01 依次接收世界名称与描述、历史连续性事实后接角色当前叙事语义、本轮事实与方向；存在已到期且仍可用的历史事项时，本轮事实与方向额外携带 `当前到期事件` 的可读时间与事实，不携带候选编号、审计状态或内部状态。故事 AI 不接收世界维度、力量框架、当前区域、状态变化 AI 的状态投影、难度枚举、历法名称、基础/修正/当前数值、天赋等级或来源字段，只接收四项基础属性和气运的当前语义；若本局发生天赋进阶，基础属性语义同时提供 `开局自带` 与 `天赋加成后` 两层。02 不重复建局数据，只接收连续性所需的历史、近期正文和当前回合；03 先由程序筛选冷却、等级和次数，再接收仍有下一等级的天赋候选、连续记忆、最近两轮正文、角色上下文、世界上下文和成长历史。

[主要规则2] 长轮次测试从该基线开始，每轮按 `01 -> 02/03` 执行；02 的同日合并记忆与未来事件、03 中玩家选定的第一条合法成长路线进入下一轮快照，测试写入独立产物目录，不接入正式运行状态。

## 最小充分原则

[核心原则1] 先用一句话写清调用的唯一功能，再从该功能反推必要输入和必要输出。

[核心原则2] 每个字段必须能够回答：删除它后，哪个必要结果将无法产生；无法回答时删除该字段。

[核心原则3] AI 只接收业务事实；上下文编号、目标编号、路由、状态写入、数值钳制、去重和其他本地可计算内容由本地程序负责。

[核心原则4] 只有同一触发点、共享主要事实、可以组成一个严格结果包且不形成前后依赖的职责才合并为一次调用。

[核心原则5] 当前回合正文是两个后调用共同的本轮事实来源；02 的历史记忆采用无权重、同日合并的 JSON 字符串数组，03 额外读取这些连续事实。

[核心原则6] 02 的本轮记忆与未来事件分别表示已经发生和尚未发生的时间轴事实；03 保留成长判断必需的等级、属性语义与 Prompt 上限。角色数值分析、道德字段与状态变化 AI 不进入后调用。

[核心原则6a] 02 与 03 的正式 Prompt 只保留抽象字段、规则和输出形状，不携带详细人物、日期、剧情、路线、能力、属性或成品示例；详细示例仅用于离线审查。

[核心原则7] 动态剧情阶段及剧情引导 AI 已从样品集合移除；故事 AI 只根据世界观、连续记忆和当前引导生成正文、命运分支或结局。

## 统一系统 Prompt 结构

[核心原则1] API 模型只接收当前请求；每个系统 Prompt 先声明本次调用的任务身份和一句唯一目标，不假设模型知道项目、MOD 或调用链。

[核心原则2] 固定键按 `身份`、`目标`、`输入映射`、执行或条件规则、`输出契约` 排列，没有实际职责的键省略。

[核心原则3] 互斥结果使用 `如果`、`则`、`否则如果`、`否则`；输出媒介、形状、字段和互斥关系只声明一次。

[核心原则4] 身份名称直接描述产物且能自足说明任务边界；是否采用“文字世界运行核心”“小说作者”等文体取向身份必须隔离实测，不能假定模型知道项目、架构或调用链。

[核心原则5] JSON 结构中的键和值保持标准双引号和标准转义；只有不承担结构或示范作用的正文强调引号可以删除。缓存命中依赖稳定消息前缀，不因删除双引号自动提高。

## 合并边界

[主要规则1] 原故事压缩与未来事件提取都从当前正文形成时间轴事实，合并为故事连续性提取；历史内容只用于连续性确认，当前回合仍是唯一新输出来源。

[主要规则2] 天赋成长包含长期证据判断和三个候选方向生成，继续独立；它不从其他后调用接收成长信号，也不阻塞其他后调用开始。

[主要规则3] 04 状态变化样品与调用目标已经删除；后续正式替换时一并删除其 Prompt、Schema、缓存、状态应用和测试引用，禁止从其他位置恢复同类 AI 职责。

[次要规则1] 技能、能力、知识技术、文化、经济、人口和一般世界变化由正文与连续记忆维持，不为它们建立重复状态结果。

[次要规则2] 独立调用增加的 Token、失败概率和等待时间必须由不可替代的结果证明；合并也必须保持唯一目标、严格输出和本地所有权边界。
