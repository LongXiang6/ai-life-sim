# 故事连续性提取 AI Prompt 样品

## 样品范围

[核心原则1] 本调用从当前回合同时提取已经发生的连续记忆和具有明确时间的未来事件。

[核心原则2] 历史记忆与当前来源回合前最多四轮正文用于理解背景、消歧、衔接和去重；当前回合是两个输出区唯一的新事实来源。三者合计形成当前回合加前四轮的五轮详细窗口。

[核心原则2a] 两个输出区的所有内容都只能来自当前回合正文明确写出的事实；不得补写、推测或添加正文未出现的动作、原因、时间、结果、类型或标签。

[核心原则3] 连续记忆只保存后续叙事仍需知道的事实，并为每条本轮记忆评定后续保留权重；来源 ID、层级、衰减状态或内部标记不进入输出。权重为 2-10；正文未明确日期时使用当前回合时间窗口终点。约定进入本轮记忆时只记录约定成立及参与方，未来事件只记录尚未执行的行动、时间与对象。

[核心原则4] 连续事实使用自然完整、易于后续叙事直接理解的现代白话，按正文原意保留主体、动作或关系、对象、必要前因、阻力或限制、直接结果与持续状态；领悟某事本身可以是已经发生的客观事实，构成因果链或能力边界的必要内容随事实保留。

## 发送顺序

1. 系统 Prompt。
2. 历史记忆 JSON。
3. 当前来源回合前最多四轮正文 JSON。
4. 当前回合 JSON。

## 调用职责

本调用把当前回合新发生的、对后续仍有影响的事实提取为连续记忆，并把其中尚未发生且具有具体或可唯一换算时间的事项提取为未来事件。

## 输出格式

```json
{
  "本轮记忆": [{"时间": "<当前回合内的发生时间>", "事实": "<自然完整、可沿因果理解的连续事实>", "权重": 5}],
  "未来事件": ["<晚于当前回合终点的绝对时间>：<尚未发生的事项>"]
}
```

本轮没有值得保留的新事实或没有符合条件的未来事件时，对应数组为空。02 输出的权重供记忆管理使用；将本轮记忆投影给故事 AI 时，只保留同日合并的 `时间：事实` 字符串。
