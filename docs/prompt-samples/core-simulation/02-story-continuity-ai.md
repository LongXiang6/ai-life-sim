# 故事连续性提取 AI Prompt 样品

## 样品范围

[核心原则1] 本调用一次处理指定的连续五轮完整正文，把会影响后续人生理解的事实压缩为长期剧情，并提取时间可确定的未来事件。

[核心原则2] 输入顺序固定为历史剧情、待压缩五轮正文、压缩范围及当前调用时间。新增事实只能来自待压缩正文；历史剧情只用于理解、消歧和去重。

[核心原则3] 原始正文始终由本地系统完整保存。压缩结果只是长期记忆投影，不续写、不评价、不选择下一轮主线。

## 发送顺序

1. 系统 Prompt。
2. 历史剧情 JSON。
3. 待压缩五轮正文 JSON。
4. 压缩范围及当前调用时间 JSON。
