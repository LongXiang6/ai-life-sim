# 天赋成长判定与路线生成 AI Prompt 样品

## 样品范围

本调用只判断程序筛选后的已选天赋是否获得充分成长证据；成立时只为其中一项生成深度强化、广度强化、转变强化三条路线。玩家确认后才替换当前版本，不把候选路线写成既成历史。

正式固定资产为 `src/mods/mod-engine/server/narrative-talent-growth-system-prompt.ts`，客户端契约版本为 `4.0.0`。本样品说明同一协议的规则与动态消息，不建立另一份运行时 Prompt。

## 固定规则

- 资质阶位衡量机制复杂度，不代表能力强度、范围或胜负概率；阶名依次为普通、良好、优秀、卓越、史诗、传说、神话、本源、至高。局内成长始终保留当前资质阶位。
- 开发阶段只按初醒、掌握、圆满依次推进。初醒到掌握至少两个不同后续证据窗口且具备稳定成功；掌握到圆满至少三个不同后续窗口且经历重要挑战。两者都需要真实时间沉淀和长期使用；成长 AI 结合最近正文、证据窗口与角色上下文判断是否形成足够契机。
- 程序先筛选16岁起始、单项本局最多两次、本局最多六次、再次成长至少20轮且严格超过20年，以及新的未复评证据窗口。圆满不再进入成长调用。
- 一个来源故事回合只算一个窗口，重复事实不增加数量。天赋只可引用自己列出的可用窗口；未来回合、阶段生效同回合及更早窗口不计入。
- AI 逐项检查实际使用、可观察结果、能力与结果的因果关系，以及当前效果要求的全部触发条件。仅有能力名称、相似行为或推测不足以成长。语义门槛不满足时返回不成长。
- 三条路线都以当前版本为起点并保留已有核心能力。深度强化提高同类机制掌握，广度强化增加适用场景，转变强化根据已发生经历重塑作用对象或机制组合，不删除、削弱或倒退已有能力。
- 详细介绍为约30至45字的动作、画面或异常现象钩子；完整效果写清触发、机制、结果、边界和真实代价，不强行添加代价，不杜撰经历，也不将跨题材金手指降格为普通技巧。
- 属性使用心智、体魄、魅力、财富及较少出现的气运。完整属性加成不是增量；净加成与负值绝对总和分别不超过当前资质阶位乘以2，最高18，不要求用满。
- 文风只由 Prompt 引导，不建立关键词过滤、文风拒收、AI 评审或自动重试。每次符合调用条件只请求一次。

## 发送顺序

1. 正式固定系统 Prompt。
2. 历史记忆 JSON。
3. 最近两轮详细记忆 JSON。
4. 当前回合 JSON，包含共享证据窗口、候选天赋、角色和世界上下文、成长历史。

三条用户消息分别为完整标准 JSON 对象，对象外不添加标签或说明。

## 输出格式

证据不足时只输出：

```json
{"成长判定":{"需要成长":false}}
```

证据充分时输出一项三选一，不由 AI 输出或改变资质、开发阶段、身份及版本：
