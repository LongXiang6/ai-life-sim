# 天赋成长判定与路线生成 AI Prompt 样品

## 样品范围

[核心原则1] 本调用只判断程序筛选后的已选天赋是否已经获得成长证据；成立时只为一项天赋生成固定的三条下一阶路线。

[核心原则2] 本地只提供仍有下一等级且通过冷却、等级和次数筛选的天赋候选、压缩记忆、最近两轮正文、角色上下文与世界上下文；AI 不得补造经历、重算等级或写入状态。成长依据必须引用具体历史或近期正文事实，不能只写概括标签。

[核心原则3] 证据不足时必须返回不成长。本轮最多出现一项三选一，玩家确认后才由本地替换词条。

## 发送顺序

1. 系统 Prompt。
2. 历史记忆 JSON。
3. 最近两轮详细记忆 JSON。
4. 玩家已选天赋 JSON（含程序筛选结果、成长历史、角色上下文与世界上下文）。
