# 天赋进阶路线生成 AI Prompt 样品

## 样品范围

本调用只为一次已经由程序命中的机缘生成深度强化、广度强化、转变强化三条路线，不再判断是否成长。玩家确认后才替换当前版本，不把候选路线写成既成历史。

正式固定资产为 `src/mods/mod-engine/server/narrative-talent-growth-system-prompt.ts`，客户端契约版本为 `5.0.0`。本样品说明同一协议的规则与动态消息，不建立另一份运行时 Prompt。

## 固定规则

- 资质阶位衡量机制复杂度，不代表能力强度、范围或胜负概率；阶名依次为普通、良好、优秀、卓越、史诗、传说、神话、本源、至高。局内成长始终保留当前资质阶位。
- 开发阶段只按初醒、掌握、圆满依次推进。本次只为一次已经命中的机缘生成路线，只前进一个阶段，不能跳级。
- 程序先筛选 16 岁起始、单项本局最多两次、本局最多六次、再次成长至少 20 轮且严格超过 20 年、新的未复评证据窗口和当前阶段最低窗口数；再按本轮存档种子进行一次确定性机缘判定。未命中不调用本 AI；命中后只发送该天赋。
- 一个来源故事回合只算一个窗口，重复事实不增加数量。天赋只可引用自己列出的可用窗口；未来回合、阶段生效同回合及更早窗口不计入。
- 机缘类型分为顿悟、危机觉醒、传承回响、异变，必须与输入一致；它只影响路线表现和代价，不改变进阶成功率。异变仍是成功进阶，不是失败或天赋报废。
- 三条路线都以当前版本为起点并保留已有核心能力。深度强化提高同类机制掌握，广度强化增加适用场景，转变强化根据已发生经历和机缘气质重塑作用对象或机制组合，不删除、削弱或倒退已有能力。
- 详细介绍为约30至45字的动作、画面或异常现象钩子；完整效果写清触发、机制、结果、边界和真实代价，不强行添加代价，不杜撰经历，也不将跨题材金手指降格为普通技巧。
- 属性使用心智、体魄、魅力、财富及较少出现的气运。完整属性加成不是增量；净加成与负值绝对总和分别不超过当前资质阶位乘以2，最高18，不要求用满。
- 文风只由 Prompt 引导，不建立关键词过滤、文风拒收、AI 评审或自动重试。机缘命中后只请求一次；调用或契约失败时不记录该天赋的证据水位，下一轮可重试。

## 发送顺序

1. 正式固定系统 Prompt。
2. 历史记忆 JSON。
3. 最近两轮详细记忆 JSON。
4. 当前回合 JSON，包含本次机缘、共享证据窗口、本次唯一天赋、角色和世界上下文、成长历史。

三条用户消息分别为完整标准 JSON 对象，对象外不添加标签或说明。
