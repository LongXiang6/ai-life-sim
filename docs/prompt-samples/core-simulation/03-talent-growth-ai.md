# 天赋成长判定与路线生成 AI Prompt 样品

## 样品范围

[核心原则1] 本调用只判断程序筛选后的已选天赋是否已经获得成长证据；成立时只为其中一项生成固定的三条下一阶路线。能力类型与强度分开判断，转变路线允许依据本局经历重构为不同能力；现有字段、消息和本地资格筛选保持不变。

[核心原则2] 本地只提供仍有下一等级且通过等级、冷却、次数和最低证据窗口筛选的天赋候选、压缩记忆、最近两轮正文、角色上下文、世界上下文与成长历史；AI 不得补造经历、重算等级或写入状态。

[核心原则3] 证据必须来自具体历史或近期正文事实，并同时具备跨多个时间窗口的长期积累、真实时间沉淀和明确突破契机；证据不足时必须返回不成长。

[核心原则4] 本轮最多出现一项三选一，玩家确认后才由本地替换词条；成长路线必须严格处于目标等级边界内。

## 发送顺序

1. 系统 Prompt。
2. 历史记忆 JSON。
3. 最近两轮详细记忆 JSON。
4. 当前回合 JSON（包含程序筛选后的玩家已选天赋、可用证据窗口、角色上下文、世界上下文和天赋成长历史）。

四条用户消息均为完整标准 JSON 对象，对象外不添加标签或说明。

## 调用职责

本调用只对程序筛选后仍可成长的已选天赋进行证据判断。若没有一项天赋同时满足直接能力表现、长期积累、时间沉淀、明确契机和目标等级所需证据窗口数量，则只返回不成长；否则选择一项证据最充分的天赋并生成深度强化、广度强化、转变强化三条同级路线。现有输入、输出、解析、等级/属性字段、程序筛选、玩家选择和状态写入均保持不变；程序负责资格筛选、路线归属、属性上限、玩家选择和状态写入。
