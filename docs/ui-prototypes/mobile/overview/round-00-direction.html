全局紧凑

A. 全局紧凑

所有页面都尽量像高密度原生工具，信息多、滚动少。

优点

  • 效率高
  • 不会显空

代价

  • 叙事页也可能偏工具化
  • 仪式感较弱

B. 分场景密度（推荐）

创建页中密度、设置页高密度、叙事页低干扰；共享统一间距与层级。

优点

  • 阅读与操作都舒适
  • 最符合产品不同页面任务

代价

  • 需要逐页判断
  • 验证工作量最大

大卡片与仪式感

C. 卡片化沉浸

强化玻璃卡片、留白和阶段仪式感，让每页更像独立游戏界面。

优点

  • 视觉精致
  • 阶段感强

代价

  • 容易再次变大、变空
  • 长流程滚动更多
