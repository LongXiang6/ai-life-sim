已选择 01
入选
候选 01（胶囊去徽标）。用户确认「定版01」。要点：进度胶囊吸顶（普通 0/3 + 三槽）+ 轮回独立卡片 + 候选卡去掉右上角稀有度徽标（稀有度由卡片辉光颜色表达）+ 完整详细介绍 + 动效照抄运行时。
淘汰
候选 02（胶囊打勾）：右上打勾徽标与胶囊已选槽的反馈重复，先不采纳；候选 03（滑卡流）：横向滑卡浏览效率低于纵向列表扫读，且与创建流程其他页面的纵向节奏不统一，先不采纳。

命格选取定版候选 01（胶囊去徽标）作为创建流程连贯基线；下一界面开始属性分配（06）迭代。候选不含任何运行时状态与持久化。
