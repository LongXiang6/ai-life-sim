## 3. 方向证据

### B01 · 章节书页

**成立证据**

- 四页都以章名、节标题、页码、细线、正文和章末动作构成单页，和欢迎页的字体角色、书脊及文字入口直接同源。
- 375px/390px 下阅读路径最短；世界选择、命格抽取和核心模拟都能在相对紧凑的纵向长度内完成主任务。
- 主操作稳定落在章末，次操作退到脚注或页尾路径，禁用与完成状态仍然可辨。

**问题与代价**

- 设置页虽然清楚，但最接近传统分栏表单，是四页中书本沉浸感最弱的一页。
- 768px 仍保持单页书册，没有利用更宽空间建立信息与操作的第二层关系。
- 统一章末动作很稳定，也可能在第二阶段被机械复制；B10 若吸收此方向，应定义动作语法而非固定模板。

### B02 · 对开书册

**成立证据**

- 768px 真正形成“阅读页 + 行动页”，而不是同一面板中的两列；世界规则与选择、故事正文与状态账簿互相解释。
- 375px/390px 按“先读后做”串联为连续正反页，语义顺序没有因响应式变化而颠倒。
- 四页分别形成世界释义/目录、仪式释义/抽取、正文/状态、卷签/参数，没有把对开误用成统一模板。

**问题与代价**

- 窄屏串联两页后，世界选择、故事和设置的纵向长度明显增加。
- 设置页从目录卷签移动到参数页，移动端比原标签切换多一次空间跳转。
- 某些任务本身不需要长解释时，左页可能变成必须维护的说明页；B10 需要规定何时允许单页化。

### B03 · 批注手稿

**成立证据**

- 正文、夹注、边注、脚注四级关系稳定；状态、规则和风险退到辅助层，但没有被隐藏或依赖颜色表达。
- 768px 使用真正边注，375px/390px 将边注顺排为相关正文后的脚注，主任务顺序保持一致。
- 世界目录、命格仪式、故事正文和设置校记都能使用同一批注语法，同时保持各自结构。

**问题与代价**

- 边注一旦同时承担当前值、规则、风险和操作反馈，会从辅助层变成第二份正文。
- 设置页重复的“当前”批注增加纵向长度和阅读噪声；批注密度需要上限。
- 核心模拟中的 HUD 说明很清楚，但持续出现会削弱长篇叙事的连续性。

### B04 · 章回长卷

**成立证据**

- 回目、卷线、纪年、谱牒和卷末落款形成最完整的连续阅读轴；核心模拟与人生时间天然契合。
- 768px 章节索引转为左侧目录，375px/390px 转为顶部横向索引，位置感明确且没有依赖固定底栏。
- 重复条目被重写为谱牒、年表或条款，没有退回卡片信息流。

**问题与代价**

- 四个方向中滚动成本最高；390px 下世界选择、命格抽取、故事、设置都显著长于其他候选。
- P1 宽环和十二命印需要同屏建立仪式焦点，长卷把两者拉到不同段落，命格抽取是该方向最弱证明。
- 设置全部章节同轴展开，适合比较和回看，却不利于只修改单项设置的高频任务。

## 6. 逐页选择方式

B05 入口按四个具体界面分组，每组直接并排显示 B01–B04 的现成页面。用户可以在页面内点选，也可以在对话中给出结果：

1. 分别选择，例如“世界 B03、抽取 B01、模拟 B04、设置 B02”。四页不要求选择同一方向。
2. 某一页可以指定融合，例如“世界选择以 B01 为主，吸收 B03 的规则旁批”。
3. 某一页都不满意时，只迭代该页面，不重新生成其他已经可用的候选。
4. B01–B04 原文件始终保留；B05 只嵌入并展示，不复制或重做候选。

四个代表页面的选择明确前，不启动 B10，不开启 B11–B20，也不修改任何页面 `final.html`。B10 的职责是总结逐页胜者之间真正共用的语法和允许差异，不再强行选出一套全局母版。
