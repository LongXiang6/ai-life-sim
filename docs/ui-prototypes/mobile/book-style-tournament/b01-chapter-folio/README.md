# B01 · 章节书页 / Chapter Folio

## 设计命题

每个页面都是一章，用户先读懂章题与节次，再在章末完成这一章唯一的主任务。书本感来自文字角色、行长、次序、细线与留白，不来自仿旧纸纹、皮革、翻页特效或暖色主题。

本方向以 `welcome/final-s2a2-17c.html` 为排版语言基准：宋体承担章题、正文和关键动作，无衬线体承担页码、参数、状态与注释；透明文字入口保留稳定命中区；左侧书脊、双刻页标式编号、页尾路径和细线建立秩序。欢迎页专属右侧曲线没有复制。

## 排版规则

- 页面：375/390px 时书页铺满视口；768px 时成为居中的 640–680px 单页，不转换成对开布局。
- 字体：章题 28–34px 宋体，节标题 17px 宋体，故事正文 15–16px 宋体；状态、页码、参数和脚注使用 8–13px 无衬线体。
- 行长：叙事正文约 30–38 个汉字的可读宽度；解释文案限制在 32–38em。
- 结构：章标 → 章名 → 导语 → 细线页标 → 任务专属章节 → 章末动作 → 脚注路径。
- 容器：规则横线、条目线和留白替代大多数卡片；只有存档对话框使用明确框体。
- 动作：主操作是 62px 高的“翻至下一章”；返回、恢复默认和原型跳转收进脚注或页尾目录。
- 状态：一个云紫语义强调色只用于当前选中、进度与可继续状态；稀有度以同一色相的线条强度和文字标识区分。
- 触控：常用按钮约 34–44px，章末动作 62px；视觉框与命中区不强制等大，遵守 PD-008 的按任务校准原则。

## 四页差异

| 页面 | 章节组织 | 任务差异 |
|---|---|---|
| 世界选择 | 规则正文 + 快速目录 + 页尾目录 + 难度附注 | 当前世界先作为一段可读规则呈现，世界列表是目录而非卡片墙；保存空态与自定义表单使用原生折叠章节。 |
| 命格抽取 | 卷首仪典图版 + 十二命印登记 + 章末抽取 | 视觉中心留给 P1 云紫宽环；十二命印是一张带页眉的登记表，完成后退场，让宽环成为完成态。 |
| 核心模拟 | 运行页眉 + 连续正文 + 分支页 + 世界账簿 | HUD 变成书页运行页眉；世界/时间/更多是可展开账簿；分支位于当前正文之后，推进动作只在章末出现。 |
| 设置 | 四项索引 + 密集编校条目 + 恢复脚注 | 标签、说明与当前值形成左右稳定扫描列；分组仍有节标题，但不把每项做成卡片，证明高密度内容也能保持书页节奏。 |

## 来源内容与交互清单

### 世界选择

- 流程与字段：创建流程 `01 / 06`；世界总序 `01 / 24`；世界标、名称、年代/类型、描述、科技、超凡、危险、主要机会。
- 主世界：现代地球、武道割据、SCP 基金会、战锤 40K、赛博 2077、修真世界。
- 页尾目录：更多世界（保留“18 个其他预设世界”条件与蒸汽纪元、末日废土、星际文明、魔法学院、神话洪荒入口）、已保存世界空态、自定义世界。
- 自定义字段：世界名称、起始年代、世界描述与核心规则；字段不全显示校验，完成后成为当前选中世界。
- 操作与状态：世界选中并刷新规则正文；三个目录原生展开/收起；轻松/普通/艰难三档难度；返回欢迎页；确认后进入世界配置。

### 命格抽取

- 机制：P1 220px 云紫宽环、五层低饱和光场、110px 柔白内核、31px“命”字、六道慢速清波。
- 十二命印顺序：普通、精良、普通、稀有、精良、普通、史诗、精良、稀有、普通、传说、普通。
- 状态与条件：初始 `0 / 12`；抽取期间按钮禁用并逐枚计数；`12 / 12` 后登记表退场、核心居中并进入慢涌波完成态；第二次主操作进入神话传承式命格选择。
- 流程：返回角色创建；完成后进入命格选取。没有把抽取改造成普通卡片选择，也没有把命格选取提前塞进本页。

### 核心模拟

- 页眉字段：林清和、女、人类、6 岁、2006 年桃月、现代地球、滨海旧城；体魄 −1、心智 +4、悟性 +3、魅力 −1、生命 100。
- 时间步长：日、月、季、年、3 年、5 年、10 年、50 年、100 年、200 年、500 年、1000 年；选择只影响下一轮，当前时间不立即改变。
- 世界账簿：三条角色词条；城市为主、温带气候、市场经济、无超自然、体力 100、精神 100。
- 更多操作：手动存档；返回命运预览。存档对话框保留槽位 1 当前记录与槽位 2/3 空态、取消、保存及成功反馈。
- 故事流程：第 12 轮、向上回望、杏月与桃月两段正文；两个预设分支或自定义输入；未选择时确认和推进禁用；清空；确认后记录决定、显示生成态、追加新段落；继续推进再次追加段落；原型路径进入人生结算。

### 设置

- 页签：个性化、模型设置、模型调用、Prompt。
- 个性化：段落舒展（默认开）、减少动态效果（默认关）。
- 模型设置：AI 命格生成（默认开）；全局推理与命格生成独立开/关；每轮叙事大致字数 100–1000、每次 50、默认 200 字；预生成关闭/1/2/3 轮，默认关闭。
- 模型调用：主叙事模型的默认/高速/深度；后台任务的跟随默认/高速；保留各列表单选状态。
- Prompt：叙事偏好原文与“只作为玩家偏好附加、不覆盖世界事实和结构化契约”的条件说明。
- 操作与状态：页签切换、开关、推理切换、字数步进及边界禁用、预生成单选、模型单选、Prompt 编辑、关闭、即时反馈；内容变更前“恢复默认”禁用，变更后可用，恢复到 200 字等初始值后再次禁用。

## 主动放弃

- 不复制欢迎页右侧曲线，也不把曲线变成跨页装饰模板。
- 不使用拟真翻页、纸张纹理、皮革书封、蜡封或古风花纹；本轮不以主题材质取胜。
- 不做固定悬浮底栏；主动作跟随内容出现在章末，避免遮挡正文和设置条目。
- 不把世界、故事段落和设置项重新包成卡片；只保留存档对话框这一种必要框体。
- 不把四页套入同一 DOM 模板：四页只共享排版 Token、章法与动作语义，各自使用目录、图版、运行页眉或设置索引。
- 不接入共享 `prototype.js` 或全局入口；B01 保持隔离候选，前后流程通过既有 final 页面链接表达。
