## 最弱页面

最弱页面是 **设置**。它必须在四个页签中容纳开关、二态值、步进器、四段选择、模型单选和长文本编辑，条目密度天然压缩章节留白；在 375px 下，四项顶部索引也比其他页面更接近扫描负荷上限。当前方案用稳定的“名称与说明 / 当前值”双列、节标题、连续横线和 54px 索引控制密度，但它的沉浸感仍弱于命格图版与故事正文。

这不是遗漏功能换来的弱点：设置页保留了全部页签、设置项、默认 200 字、恢复默认、即时切换与边界禁用。后续若进入融合阶段，最值得继续测试的是把设置索引改为页边纵向目录，但不应牺牲 375px 的扫描宽度。
