# B04 · 章回长卷 / Serial Scroll

## 设计命题

B04 把每个页面视为一段持续展开的长卷，而不是一组装进容器的控件。回目、节标题、纪年、谱牒条目、正文段落、分隔符与卷末动作共同承担层级；颜色只标记当前章节、选择或完成状态。

欢迎页 `S2-A2a-17C` 提供的同源语法被转译为：

- 宋体承担回目、正文、条目名称和关键动作；无衬线体承担状态、编号、参数和注释。
- 文字入口、细线、卷线和留白取代卡片底板、阴影与大面积按钮。
- 卷首交代当前路径，卷末收束主操作；返回路径在卷首和卷末均可找到。
- 唯一语义强调色为克制的云紫，用于滚动进度、当前回目、选中态和 P1 仪式环。

## 长卷结构

页面共享一条左侧卷线。每个章节在卷线上有一个菱形定位点，滚入当前阅读区后才以云紫标记。页面最上方的 2px 细线表示整卷滚动进度，不占用正文高度。

重复条目统一写成谱牒、年表或条款：序号在左、正文居中、状态在右，条目之间只有横线。世界、命印、故事段落和设置项不使用卡片信息流。

主操作只在相关章节末尾或整卷末尾出现。B04 不保留固定底栏，因为世界页和设置页会被持续遮挡，故事页也会失去纪年阅读的完整性。仅章节定位采用 `position: sticky`：

- 375px / 390px：章节索引位于页面顶部，横向滚动，不压缩正文宽度。
- 768px：章节索引成为左侧窄目录栏，正文仍保持单列阅读尺度。
- 卷首返回 B04 目录；流程返回与下一步写在各自卷末，形成明确的回返路径。

## 四页差异

### 世界选择 · 世界谱牒

当前世界的规则纲要先出现，六个主世界随后按世系条目排列。选中条目会改写卷首的时代、描述、三项规则与主要机会。更多世界、已保存世界和自定义世界是三则就地展开的旁卷；自定义的三个字段填写完整前，生成动作保持禁用。难度只在卷末落款，避免与世界规则混写。

### 命格抽取 · 十二命印仪轨

保留 P1 的 220px 五层云紫宽环、柔白内核、31px“命”字、慢速清波、十二命印顺序和原五档稀有度序列。十二格视觉被改写为十二条命印谱牒，但 `0 / 12` 逐条归位、抽取中禁用、完成后隐藏主命印区并进入命格选择的机制不变。完成后的谱牒默认收进归档，可按需回看。

### 核心模拟 · 林清和纪年

人物与属性成为卷首账，更多操作、12 档推进步长和世界/角色账簿成为可展开旁录。两段既有故事按纪年排列，选择与自定义输入紧随当前段落。确认后显示已决选择、生成下一段人生并解锁连续推进；存档对话框、返回命运预览和跳转人生结算仍在原流程位置可达。

### 设置 · 偏好条款

四个原选项卡仍保留 `tablist / tab / tabpanel` 语义，但不再互相隐藏内容；它们是同一长卷上的章节定位。个性化、模型设置、模型调用和 Prompt 同轴展开，开关、推理模式、200 字步进、预生成、模型选择、Prompt 编辑和恢复默认均可操作。这样牺牲了单屏短小，换来跨章节比较和回看能力。

## 导航与状态规则

- 顶部进度线表示文档整体位置；章节定位只表示当前回目，两者不混用。
- 点击章节索引平滑滚动；系统要求减少动态时立即跳转。
- 选中态用正文加深、下划线或一条云紫细线表示，不依赖填色容器。
- 展开内容使用原生 `details` 或显式 `hidden / aria-expanded` 状态。
- 禁用动作保留原位置和文案，以降低不满足条件时的路径猜测。
- 所有流程链接指向现有对应 `final.html`，但没有修改任何全局入口或最终稿。

## 主动放弃

- 不使用拟真纸张纹理、渐变、阴影、翻页动画和卷轴插画；它们会把材料质感误当成排版方案。
- 不使用固定底栏；长卷的下一步由卷末动作表达，避免持续遮挡正文。
- 不把所有信息塞进同一种卡片，也不让四页共享相同章节数量和内容顺序。
- 不为世界条目、设置项或命印增加装饰图标；编号与文字已经承担识别任务。
- 不用五种稀有度颜色。稀有度名称完整保留，P1 云紫是全方案唯一强调色。
- 不把命格抽取与后续神话传承式命格选择合并。

## 文件

- `tokens.css`：长卷排版、响应式、状态和页面特有模式。
- `index.html`：B04 独立目录，不接入全局入口。
- `world-select.html`：世界选择长卷。
- `talent-draw.html`：P1 命格抽取长卷。
- `game-story.html`：核心模拟纪年长卷。
- `settings.html`：设置条款长卷。
- `evaluation.md`：按竞赛统一评分表自评。
