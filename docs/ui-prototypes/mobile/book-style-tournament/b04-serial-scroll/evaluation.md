## 页面分项判断

| 页面 | 最成立之处 | 主要风险 |
|---|---|---|
| 世界选择 | 世界规则先读、世谱后选、难度卷末落款，选择顺序比原网格更有解释性。 | 六条主世界比 3×2 网格更长，熟练用户的跳选距离增加。 |
| 命格抽取 | P1 宽环与十二命印第一次被解释成一段有前后次序的仪轨。 | 仪式本质偏空间构图，和连续长卷的契合度低于其他三页。 |
| 核心模拟 | HUD、旁录、年表、分支与生成结果自然落在同一时间轴，是 B04 最强证明。 | 高频切换推进步长时，需要滚回卷首旁录；真实产品可能需要更短的返回手势。 |
| 设置 | 四个 tab 成为连续章节定位，高密度字段可以比较、回看和统一恢复。 | 内容全展开导致页面最长；用户只改一个设置时不如互斥 tab 短。 |

## 最弱页面

**命格抽取是本方向最弱的一页。**

原因不是机制缺失，而是 P1 云紫宽环本身是一个强空间中心：用户的注意力应停留在环与十二命印的同步变化上，连续滚动反而可能把环和正在归位的命印分到不同视口。B04 通过“卷首宽环 + 下方命印谱牒 + 完成后命印归档”维持了仪式顺序，但它仍不如核心模拟和设置那样天然受益于长卷。后续评审应重点观察 375px 下用户点击“开始抽取”后，是否理解需要在宽环与命印段落之间移动视线。

## 需要对照评审的问题

1. 375px 下的横向章节索引，是否比固定底栏更能提供位置感而不打断阅读。
2. 世界谱牒的纵向比较是否足够快，还是主世界应在不回到卡片的前提下增加更短的索引。
3. 核心模拟的推进步长是否需要一个卷内“返回旁录”动作，而不是固定工具栏。
4. 设置全展开带来的可比较性，是否值得更长的滚动距离。
5. 命格抽取完成后默认收起十二命印，是否恰当地保留了 P1 完成态的视觉收束。
