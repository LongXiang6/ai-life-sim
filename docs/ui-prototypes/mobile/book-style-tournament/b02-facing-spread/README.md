# B02 · 对开书册 / Facing Spread

## 设计命题

本候选把每个任务拆成互相解释的两页：阅读页负责叙事、规则或上下文，行动页负责选择、状态和确认。对开关系不是装饰性的两栏，而是稳定的阅读顺序：先理解，再行动；完成动作后再进入下一页。

它继承欢迎页 `S2-A2a-17C` 的宋体叙事、无衬线状态、页码、书脊、细线、路径与纯文字动作，不复制欢迎页专属曲线。全套只使用中性色与一处云紫强调；云紫同时服务选中、就绪和 P1 命格宽环，颜色不承担信息结构本身。

## 响应式对开规则

- `700px` 及以上显式对开。两页各占一半，中央单线为书脊；页面自然增高，不把内容锁进两个独立滚动窗。
- `375px` 与 `390px` 改为连续正反页。阅读页在前、行动页在后，页间保留换页线与页码，不压缩成移动端双列。
- 移动端阅读页提供“转至行动页”文字动作，只做锚点定位，不使用拟真翻页、透视、纸张卷曲或手势劫持。
- 控件按任务密度保持约 `34-40px` 的稳定命中高度；高密度 HUD 和设置行不机械放大。

## 四页差异

- 世界选择：左页是当前世界的规则释义和六个主世界索引，右页收束更多世界、存档、自定义、难度和确认流程。选择任一世界会重写左页，不再把规则舞台压在选择网格上方。
- 命格抽取：左页讲清十二命印的过程和五档结果，右页只承载 P1 云紫宽环、十二格进度和主动作。抽取中按钮禁用；完成后宽环居中并提供进入命格选择的下一页动作。
- 核心模拟：左页只读连续正文，右页集中 HUD、推进步长、世界账簿、存档和分支。确认分支后新增续页，正文与状态不在同一固定层争抢。
- 设置：左页是四个设置卷签和当前范围说明，右页只呈现当前卷签的参数。切换页签会在移动端自然定位到参数页，并保留恢复默认。

## 主动放弃

- 不使用拟真纸张、折角、翻页物理、透视动画、木纹或噪点材质。
- 不依赖大面积暖白、渐变、阴影或卡片堆叠制造“书本感”。
- 不把 375px/390px 继续做成双列，也不为保持一屏而缩小正文与触控目标。
- 不固定核心模拟 HUD 覆盖正文；不把设置每一项装进独立卡片。
- 不把命格抽取改成普通候选卡选择，也不在此页引入神话传承的选取机制。
