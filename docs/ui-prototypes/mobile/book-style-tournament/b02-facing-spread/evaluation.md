## 最弱页面

设置页是本候选相对最弱的一页。它把四个页签转成左页卷签目录，768px 下扫描效率和参数定位清楚，但在 375px/390px 上，用户切换卷签后需要从目录页移动到参数页；自动定位缓解了距离，却仍比同页标签切换多一次空间跳转。保留这种代价是为了验证真正的“目录页 + 行动页”，后续若融合胜出方向，应继续比较书签式短导航或移动端粘性卷签是否更合适。
