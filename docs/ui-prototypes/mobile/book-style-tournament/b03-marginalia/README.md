# B03 · 批注手稿 / Marginalia

## 设计命题

主任务是正文，规则、数值、状态、解释和次级操作是批注。方案不模拟旧纸、墨迹或装订材质，而是用宋体正文、无衬线注释、页码、细线和留白建立两层阅读关系。

共享配色只有中性色与一个云紫强调色 `#71658f`。云紫既承接 P1 命格宽环，也只用于当前、选中、锁定、错误或待处理状态；任何状态都同时有文字、线型、符号或 `aria-*` 语义，不依赖大面积底色。

## 批注层级

| 层级 | 角色 | 桌面 / 768px | 375px / 390px |
|---|---|---|---|
| 正文 | 当前任务、叙事、可选条目、关键动作 | 页面主栏，保持最长行宽 | 单一阅读轴，优先出现 |
| 夹注 | 当前值、短状态、条件 | 紧贴字段或动作 | 保持内联，不缩成小字 |
| 边注 | 规则、风险、计数、解释 | 156px 独立边栏，以细竖线连接正文 | 顺排到相关正文之后，变为带 `↳` 的脚注段 |
| 脚注 / 展开注 | 次级路径、补充规则 | 章末或目录旁 | 使用 `details` 按需展开，避免挤压正文 |

移动端断点为 `620px`。断点以下不保留窄边栏，所有 `.annotated` 与仪式双栏改为单列；世界目录继续按需展开，故事状态抽屉继续由“更多 / 月 / 世界”触发。触控控件按任务保持约 38–42px 的命中高度，未机械放大所有信息行。

## 四页差异

### 世界选择 · 目录批注

- 当前世界先作为规则正文展示，科技、超凡、危险与主要机会组成简洁账页。
- 六个主世界改为连续目录，选中态使用左侧云紫线、`已选` 文本和 `aria-selected`。
- 更多世界、已保存世界和自定义世界退为折叠目录；空自定义表单会在字段下显示错误脚注。
- 难度是当前值夹注，仍按轻松、普通、艰难循环；返回与确认在章末收束。

### 命格抽取 · 仪式注记

- P1 五层 220px 云紫宽环、柔白内核、31px“命”字、慢清波和十二命印仍是视觉与交互中心。
- 十二命印按原普通、精良、普通、稀有、精良、普通、史诗、精良、稀有、普通、传说、普通顺序逐格揭示。
- 五档稀有度在单色约束下改用实线、双线、虚线和线重区分，标签与层级含义不变。
- 抽取时主操作禁用并显示“当前锁定”；12 / 12 后命印区收起、核心保留，主操作变为“进入命格选择”。

### 故事进行中 · 叙事旁批

- 人物、时间、世界和五项属性成为卷首校记，故事正文保持最长连续阅读宽度。
- “更多 / 月 / 世界”展开为正文上方的注释抽屉，保留存档、返回预览、12 档时间步长、角色词条和世界状态。
- 两段既有故事、分支问题、两个选项、自定义输入、清空、确认、生成、继续推进与人生结算串联全部保留。
- 风险、禁用原因、生成中和可推进状态在分支右侧作动态旁批；窄屏时紧跟选择区成为脚注。

### 设置 · 设置校记

- 四个选项卡不变，设置项以正文名称、说明和右侧控件组成连续校样，不使用卡片。
- 当前值和影响范围写成 `↳` 夹注，开关、推理模式、叙事字数、预生成、模型选择和 Prompt 都能交互。
- 恢复默认作为章末次级动作，统一恢复约 200 字及本页其他演示状态。
- 这一页刻意比故事页更紧凑，因为目标是扫描和校对，不是连续沉浸阅读。

## 主动放弃

- 不使用仿旧纸、噪点、墨渍、折痕、浮雕或拟真翻页。
- 不复制欢迎页右侧曲线；只继承宋体 / 无衬线分工、页标、路径、细线与文字入口。
- 不使用卡片堆叠、胶囊标签、渐变背景、大面积选中底色或固定底栏。
- 不在 375px 强留双栏，也不把边注压成不可读的小字。
- 不用五种颜色表达命格稀有度；单一云紫配合线型和文字保留等级。
- 不新增真实应用依赖，不更新全局入口，不修改任何 `final.html`、共享 CSS 或历史候选。

## 实现与交互

所有页面是无依赖静态 HTML，共享 `tokens.css`。主要交互包括世界选择、难度循环、自定义世界校验、十二命印抽取、时间步长、世界 / 角色展开、分支与自定义选择、故事生成、手动存档、设置选项卡、开关、步进器、分段选择、模型选择和恢复默认。
