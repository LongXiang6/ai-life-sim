## 最弱页面

**设置页最弱。** 它完整保留四个标签页和全部设置后，移动端仍不可避免地比其他三页更接近高密度表单。当前值夹注提升了可解释性，也增加了纵向长度；在 375px 下虽然没有拥挤小字或横向滚动，但“模型设置”面板的阅读节奏不如世界目录和故事正文自然。若该方向晋级，设置页最值得继续探索的是把重复的当前值夹注合并为分组级校记，同时保持每项状态可见。
