GUIDE / NOTES

说明

从选择世界到走完一生，每个页面只承担当前阶段最重要的决定。

01 / BEGIN

开始与设置

欢迎页提供开始新人生、读取存档、设置和说明入口。

  • 开始新人生会从世界选择进入一次全新人生。
  • 读取存档会展示已有记录，再回到对应故事进度。
  • 设置中的叙事字数是生成目标，完整句优先。
02 / WORLD

世界选择

选择一个预设世界，或进入世界定制创建自己的舞台。

  • 世界决定时代、社会结构、自然规律和可用题材。
  • 难度会影响风险与资源，不直接替角色做选择。
03 / CUSTOMIZE

世界定制

调整名称、介绍、纪元与世界观类型，保存后继续角色创建。

生成期间可以取消；离开页面前会明确提示未保存内容。
04 / CHARACTER

角色创建

决定姓名、性别、种族与出身。随机只改变当前可随机字段，不覆盖已经锁定的选择。

05 / FATE

命格与属性

从候选中选择普通命格，并按世界规则分配初始属性。神话传承独立于普通命槽。

  • 点击星位查看说明，再加入普通命槽。
  • 已加入的命格可以再次点击移除。
06 / STORY

故事与选择

每一轮故事会给出可选行动，也允许写下自己的做法。确认后，AI 会沿选择继续叙事。

  • 时间步长只影响下一轮，不会立即改变当前时间。
  • 世界面板保存角色词条与当前世界状态。
  • 人生结束后可回望三幕，并封存一项神话概念。
