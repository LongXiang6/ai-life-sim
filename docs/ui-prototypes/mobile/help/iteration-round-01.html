01

本轮边界

目标
将独立游戏说明页纳入定版语言：说明/更新日志两个子页面完整呈现，说明页承载六章节内容（开始与设置、世界选择、世界配置、角色创建、命格与属性、故事与选择），与欢迎页入口串联。
保持不变
页面业务契约（说明与更新日志两个 tab、章节内容、完成返回欢迎界面）不改变；继承完整定版基线（暖纸墨全页、tabs 金色下划线、卡片化 20px 圆角、定版按钮规格、底部双文字等宽纯白同底按钮）。
比较维度
章节定位方式（胶囊导航/全滚动/精简指南）、信息呈现（章节卡片 vs 指南行 vs 折叠全文）、操作路径（章节切换/展开完整说明/返回）。

无胶囊导航，说明页直接全滚动呈现六个章节卡片，信息密度高；说明与更新日志双 tab 完整呈现。

全屏打开候选 02 →

说明页先给精简指南行（关键章节 + 去查看），完整说明收纳在折叠区按需展开；说明与更新日志双 tab 完整呈现。

全屏打开候选 03 →

04

本轮决策

定版 01 · 选择候选 02
入选
候选 02（章节卡片列表）。六个章节卡片全滚动呈现，信息密度最高；说明与更新日志双 tab 完整承载，与欢迎页入口串联。
淘汰
候选 01（章节胶囊导航）：胶囊导航占位较高，首屏先见导航后见内容；候选 03（精简指南加完整折叠）：折叠把完整说明推后一步，定位不如全滚动直接。
下一轮继承
保留说明/更新日志双 tab、六章节卡片全滚动结构与完成返回欢迎界面；在定版稿上补充装饰性表情符号点缀章节标题。
