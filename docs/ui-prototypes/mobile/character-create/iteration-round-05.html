本轮边界

目标
在定版 02（同行图标钮）基础上按用户指示缩短 runningHead（顶部「AI LIFE SIM · 命书 / 03 · 08」行）高度、消除页面大片空白。已定位根因：`.paper` 为 `display: grid; min-height: 100%`，grid 默认 `align-content: normal` 会把所有 auto 行等量拉伸填满视口——视口高于内容时 runningHead 由自然高度 14px 被拉高至 80px+，三个 section 底部也各留空白；本轮的三个候选围绕运行头高度与空白消除方式差异。
保持不变
业务契约：runningHead（03 / 08）、去 header 后角色摘要（头像/名字/性别·种族·背景/寿命·起始·世界）、核心身份（姓名·随机、性别、种族）、寿命与起始（单行句 + 🔄 图标钮同行、结果行排序一致）、人生背景（背景输入/预设/保存预设、textarea 自适应增高）、底部双文字等宽返回与确认角色（04，下一页面为命格抽取）。候选不含 localStorage/sessionStorage/fetch。
比较维度
运行头高度稳定性（各视口是否恒定）、空白消除（行拉伸是否消失）、结构改动量（是否引入绝对定位等机制）。

候选 02内容定高

入选
候选 02（内容定高）。用户确认：`.paper` 去掉 `min-height: 100%` 随内容定高、runningHead 显式固定 16px 行高，任何视口下运行头恒定、无拉伸空白，为角色塑造第五轮定版基线。
