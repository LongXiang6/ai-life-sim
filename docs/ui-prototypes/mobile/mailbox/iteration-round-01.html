01

本轮边界

目标
在已定版基线（欢迎页候选 02 单列极简结构、原版按钮规格、暖纸墨色系、节奏留白、统一居中；存档栏位聚焦式弹层；排行榜聚焦式榜单 + 双文字等宽底栏 + 纯白同底按钮）上，为邮箱子界面建立第一轮候选。邮箱业务事实：查看来信 → 展开消息 → 接受天赋/删除 → 返回欢迎界面。
保持不变
页面业务契约：meta 顶栏、标题"邮箱"与副标题、写邮件入口、分类 tabs（收件箱/已发送）、消息列表（身份、标题、预览、时间、未读点、正文、天赋附件、到期、删除）、底部操作栏（返回 + 返回欢迎界面）；不改变运行时行为与数据契约。
比较维度
信息层级（写信入口、分类、消息列表的主次）、操作效率（展开消息到接受/删除的路径）、精简协调性（与定版欢迎页、存档栏位、排行榜是否同一语言）。

04

本轮决策

已选择 02
入选
候选 02（精简单列统一）。用户确认：暖纸墨全页 + 消息卡片化 + 定版按钮规格的精简单列统一被接受，作为下一轮继承基线。
淘汰
候选 01（当前运行基线）：蓝白语言与定版基线不一致。候选 03（聚焦式收件）：入口收敛方向正确，但本轮用户偏好 02 的消息卡片同级统一。
下一轮继承
继承候选 02 的精简单列统一（暖纸墨全页、消息卡片化 20px 圆角、写邮件/接受/删除按钮按定版按钮规格、底部双文字等宽纯白同底按钮），以及既有定版基线。
