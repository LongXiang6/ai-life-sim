动效清单
照抄运行时参数，不加其他动画：bar-rebirth-flow 13s ease-in-out infinite（前世武骨流光，延迟 -3.1s，reduced-motion 停）；reveal 0.18s ease both（信息面板滑出）；narrativeFadeIn 280ms ease-out（叙事条目入场）；blink 900ms step-end infinite（生成光标）；advancePulse 2.8s ease-in-out infinite（推进 idle 呼吸，generating/blocked 无动画，reduced-motion 停）；transition transform 0.16s ease（步长箭头）。面板融入仅静态视觉（背景/投影/圆角/分隔/配色），不新增任何动画。
比较维度
面板是否真正融入页面暖纸墨体系（不再是纯白浮窗的「格格不入」观感）、三个融入方向的差异度与辨识度（同族纸卡 / 同底融入 / 暖调书签）、融入后与正文流、branchResolved 回声块、信息面板、ledger 的层级协调、是否因过度融入失去「命运分叉点」的决策区辨识度、small 15px 600 后顶栏层次（13px 姓名 strong 与 15px 时间 small 的层级、是否过大挤压步长区）、面板标题压 14px 后与选项 12px 的层级、选项行可点击区域与墨黑单选保留、单选/输入联动与按钮文字不变、textarea 圆角与金棕聚焦、主按钮禁用/可用态、branchResolved 月白暖白不变、右栏 🪪/⏳ 行尾保留、窄屏下右栏与面板协调、chip 纯白细线与白板的协调、菱形分隔两端对齐、entryMeta 岁数精简节奏、动效照抄一致性、与创建流程已定版页面（暖纸墨 / 金棕 / 命书口吻）的协调性。

入选
候选 A · 纸卡同源：面板背景换月白暖白 #fffdf8（与 branchResolved / 信息面板同族）+ 强投影弱化为极淡光晕 + 圆角 16→12px + 选项块改页面米纸 #fdf9f1 悬浮/选中泛白——不再是纯白悬浮弹窗，像页面原生暖纸卡，与暖纸墨体系最连贯且保留「命运分叉点」决策区的可辨识边界。
淘汰
候选 B · 同底融入（面板与页面同底 #fdf9f1、去投影、hairline 分隔无块）：最融入但决策区与正文的边界过弱，选项行靠极细线界定，窄屏下易与正文混读；候选 C · 暖调书签（#faf4e8 + 金棕边框 + 标题短横线装饰）：有辨识度但与页面底色差一度、书签带观感对「抉择编辑器」偏装饰化。
