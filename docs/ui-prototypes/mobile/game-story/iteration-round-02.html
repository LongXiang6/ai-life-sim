本轮决策

已选择 C
入选
候选 C（章节头单行化）：顶栏保持两段基线，章节头从四行居中堆叠改为左标题 + 右三步胶囊竖排单行结构，状态标签并入标题下方小字，虚线底部分隔保留——阅读正文更快进入、垂直占用最小，且章节信息仍在同一视觉区内完整可见。
淘汰
候选 A（顶栏单行瘦身）：barTop 与 barVitals 合并单行后四维/命格/轮回依赖横向滚动，随身可见性比两段基线弱化，顶栏高度收益以信息可达性为代价；候选 B（账簿分类折叠面板）：账簿四组默认收起，首屏高度降低有限（面板主体仍高），且每次查看账簿需多点一次展开，可发现性下降。
下一轮继承
候选 C（章节头单行化）为游戏故事（08）当前基线。进入 ROUND-03「条目外框与长篇叙事」：用户指示——属性变化 chip（span）加标签外框、时间线多添加几个轮次展示长篇效果、命运分叉回显（div）加外框且外框与页面背景协调不形成明显色差、轮回胶囊去掉「轮回」二字并把「轮回」移动到轮回天赋区第二行。三个候选分向外框风格，共同基线先全部应用。
