目标

保持不变
业务契约：readerBar（顶栏：身份信息 + 推进步长下拉 + 命运分叉按钮 + 当前信息按钮；barTop grid minmax(0,1fr) auto 40px）、vitals（四维 💪 4 / 🧠 4 / ✨ 5 / 💫 5 直显、已选命格胶囊「灵根淬体 / 慧心通明 / 笑靥如花」+ 前世武骨流光胶囊独立第二行，barVitals grid minmax(0,1fr) auto 两行）、章节头单行化结构、长篇时间线五轮 + 暮年 70 岁待抉择编辑器、advanceDock 流末推进、信息面板。身份信息口径（姓名性别「林晚 · 女」、世界「沧澜界」、季节「春」、年龄「18 岁」）全部保留，仅改变摆放位置与行层次。前世武骨流光动画参数照抄运行时（bar-rebirth-flow 13s ease-in-out infinite，延迟 -3.1s，reduced-motion 停）。候选不含 localStorage/sessionStorage/fetch（步长下拉、信息面板、单选联动、输入框收起/展开与自适应均为纯 DOM 交互，不持久化）。
动效清单
照抄运行时参数，不加其他动画：bar-rebirth-flow 13s ease-in-out infinite（前世武骨流光，延迟 -3.1s，reduced-motion 停）；reveal 0.18s ease both（信息面板滑出）；narrativeFadeIn 280ms ease-out（叙事条目入场）；blink 900ms step-end infinite（生成光标）；advancePulse 2.8s ease-in-out infinite（推进 idle 呼吸，generating/blocked 无动画，reduced-motion 停）；transition transform 0.16s ease（步长箭头）。
比较维度
右栏 strong 两行的层级与可读性（姓名性别 / 年龄主次是否分明）、顶栏 small「世界名 · 时间」是否足够清晰不单薄、右栏两行与左侧四维/命格及前世武骨第二行的高度协调、窄屏下右栏是否挤压左侧命格胶囊、chip 纯白细线与白板的协调、墨黑中心原点与白板金棕描边的搭配、菱形分隔两端对齐、entryMeta 岁数精简节奏、动效照抄一致性、与创建流程已定版页面（暖纸墨 / 金棕 / 命书口吻）的协调性。

04

本轮决策

已选择 A · 等权两行
入选
候选 A 等权两行——右栏 strong 两行同 serif 大字层级，姓名性别与年龄等权平视、信息一目了然，与右侧强信息位匹配；顶栏 small「沧澜界 · 春」保持次要小字不抢。
淘汰
候选 B 主次两行——年龄降为 8px 小字后与顶栏 small 层级重复、年龄信息被弱化、右栏主位只用一半；候选 C 细线两行——行间细线与 chip 细灰边框 #e5e1d6 重复、右栏两行被分隔线切断成两个独立块、打破身份整体性。
下一轮继承
用户「A继续」+ 指示「`small` 这个文字太小了，需要加大，表明重要性，还有几几年的时间怎么不见了，需要补充。`span` `span` 这两个能不能加个彩色的表情装饰之类的，太单调了」——顶栏 small 字号加大（体现重要性）、补充时间信息（年龄「18 岁」）、右栏 strong 两个 span（姓名性别 / 年龄）加彩色表情装饰。进入 ROUND-16（顶栏时间增强 · 表情装饰），候选 A 为基线。
