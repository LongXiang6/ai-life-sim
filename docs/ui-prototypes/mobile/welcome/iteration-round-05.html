本轮边界

目标
收紧"继续人生"按钮内主文案与副文案两行文字的行距。用户明确指出两行距离太远，本轮只调整行距密度，不改变文字内容与对齐。
保持不变
结构、按钮规格、色系、节奏留白、统一居中排版与文案均与第四轮入选基线一致；本轮只改变按钮内两行的行距与间距。
比较维度
行距密度（两行的视觉贴合度）、层级辨识（收紧后主副文案是否仍可分）、精简协调性（收紧后是否自然不拥挤）。
