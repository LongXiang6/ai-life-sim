03

迭代顺序

  1. 01
    固定目标

    记录本轮只解决的页面问题、必须保留的业务行为和不可改变的状态契约。

  2. 02
    建立候选

    候选之间比较结构、信息层级和交互，不用换色代替方案差异。

  3. 03
    记录选择

    写明入选项、淘汰原因和下一轮唯一继承内容。

  4. 04
    接入运行时

    只有用户确认的方案才进入真实页面；方案库不拥有业务状态或运行时规则。
