候选 A（轻分隔）。用户确认「A继续迭代」。要点：不拆子卡，保持运行时四区单卡连续结构，世界与角色区内以虚线分段（世界描述 → 角色身份 → 核心数据）、属性与命格区内以虚线分隔四属性网格与命格行——分区最轻且不碎，兼顾折中意图。
