# 天赋自动进阶与机缘突破

> 设计判据：**自动成长 > 主动修炼；机缘随机 > 固定打卡；进阶必成功 > 随机失败。**
> 状态：已按本文默认方案实现（2026-11-14）。本地判定在 `narrative-talent-opportunity.ts`，03 只生成路线。

## 1. 目标

让天赋在人生推进中自动成长，但玩家无法精确预测下一次进阶的时机和形态。

玩家不需要：

- 主动点击“修炼”
- 管理熟练度点数
- 计算还差几个证据窗口
- 反复查看进度条

玩家可以感知：

- 这个天赋最近很活跃
- 它似乎到了瓶颈
- 某次危机、顿悟或传承之后，它发生了变化
- 变化方向由自己选择

## 2. 非目标

- 不改变资质阶位；资质升阶仍只走轮回。
- 不新增修炼按钮、行动点、天赋经验货币。
- 不新增永久失败、天赋损毁或洗点。
- 不让 03 天赋成长调用变成每轮固定调用。
- 不为“随机”增加新的内容过滤、黑名单或静默丢弃。

## 3. 核心循环

```text
主故事实际使用天赋
  → 返回“引用 + 可观察结果”
  → 引擎记录证据
  → 本地计算机缘倾向并做随机判定（不调用 AI）
  → 未命中：无提示、无调用，故事继续
  → 命中：创建“命格机缘”
  → 调用 03 生成三条进阶路线
  → 玩家选择一条
  → 下一阶段生效，下一轮故事承接新能力
```

关键点：

- **随机发生在触发层**，不是“进阶成功/失败”层。
- 一旦机缘成立，进阶必定成功；随机的是时机、形态和代价。
- 没有机缘时，系统不打扰玩家。

## 4. 状态设计

### 4.1 复用现有状态

- `DestinyPatternGrowthEvidence`：主故事产出的天赋表现窗口。
- `DestinyPatternGrowthHistoryEntry`：已经完成的成长记录。
- `DestinyPatternGrowthAssessment`：最近一次评估水位。
- `DestinyPattern`：当前资质阶位、开发阶段、效果和属性加成。

### 4.2 新增“机缘”状态

机缘是待处理状态，不是永久资源：

```ts
interface DestinyPatternOpportunity {
  lineageId: string
  roundSequence: number
  kind: 'insight' | 'crisis' | 'legacy' | 'mutation'
  seed: string
  createdAtBasePoints: number
}
```

- `kind` 只影响 03 的叙事倾向和路线表现，不改变资质或阶段规则。
- `seed` 用于保证同一局、同一回合、同一天赋重载后得到同一结果，避免读档重掷。
- 机缘未处理时，不重复创建同一天赋的新机缘。

### 4.3 不新增可见进度条

“暗线积累”由已有证据窗口和最近使用情况推导，不新增玩家可见的熟练度数值。

内部可以使用：

- 证据窗口数量
- 证据距今的回合/时间
- 最近是否在重要场景中使用
- 当前人生阶段
- 气运

这些只参与权重计算，不形成固定公式展示给玩家。

## 5. 机缘判定

### 5.1 判定时机

只在以下条件同时满足时做本地判定：

- 天赋已选、未到圆满
- 年龄、次数、冷却等现有程序门槛已通过
- 自上次判定后出现了新的证据窗口
- 当前没有待处理的同天赋机缘

不为没有新证据的回合反复掷骰。

### 5.2 判定方式

使用确定性随机：

```text
seed = hash(lifeRunId, roundSequence, lineageId, latestEvidenceRound, evidenceCount)
roll = deterministicRandom(seed)
chance = clamp(base + evidenceCount × perWindow + age + stage + luck - aptitude, min, max)
hit = roll < chance
```

约束：

- 不使用 `Math.random()` 作为唯一随机源；读档不能重掷。
- 初版概率参数集中在 `TALENT_OPPORTUNITY_TUNING`，不向玩家展示百分比。
- 气运只做倾向修正，不保证触发；高资质天赋作为更稀有的机缘来源，用小幅减益表达。
- 同一候选用最新证据窗口水位作为种子的一部分；同一批证据不会因重载或重复执行重掷。

### 5.3 情绪节奏

机缘应该更像“人生里突然发生的事”，而不是“系统定时发奖励”：

- 久未使用：机缘倾向低。
- 连续在危机、选择、关系冲突中使用：机缘倾向上升。
- 人生阶段转换：可以作为一次更强的机缘窗口。
- 命运分支、重大失败、重要关系变化之后：可以提高权重。
- 长期没有机缘：通过“久未触发权重”缓慢上升，而不是硬保底。

## 6. 机缘类型

| 类型 | 触发气质 | 03 路线倾向 |
|---|---|---|
| `insight` 顿悟 | 长期积累后突然想通 | 深度强化、精度提升、旧能力新用法 |
| `crisis` 危机 | 在危险、失败或失去中被迫突破 | 代价型强化、应激适应、保护性变化 |
| `legacy` 传承 | 师承、遗物、旧地、前史回响 | 广度强化、旧能力与新来源结合 |
| `mutation` 异变 | 力量失控、世界规则冲突、未知机缘 | 转变强化，允许机制重组和真实代价 |

`mutation` 不是“进阶失败”，而是“进阶后形态不可预测”。它仍然推进开发阶段。

## 7. 03 天赋成长调用的调整

### 7.1 从“判定是否成长”改为“生成进阶路线”

机缘命中代表程序已经确认：

- 有足够证据
- 年龄、次数、冷却等边界已通过
- 这次成长已经成立

因此 03 不再需要回答“要不要成长”，只需要回答“这次长成什么样”。

建议输出：

```json
{
  "命格血脉编号": "命格-1",
  "机缘类型": "crisis",
  "成长依据": "只引用输入中已经成立的直接事实",
  "下一阶方向": [
    {"路线": "深度强化", "名称": "", "详细介绍": "", "效果描述": "", "属性加成": {}},
    {"路线": "广度强化", "名称": "", "详细介绍": "", "效果描述": "", "属性加成": {}},
    {"路线": "转变强化", "名称": "", "详细介绍": "", "效果描述": "", "属性加成": {}}
  ]
}
```

与现在相比：

- 去掉 `成长判定.需要成长` 分支。
- 输入只保留本次机缘对应的一个天赋，不再让 AI 在多天赋之间选择。
- 保留三条固定路线和现有属性边界。
- `机缘类型` 只影响路线气质，不改变属性上限或阶段规则。

这样 03 的输入更小、输出更稳定，也不会出现“机缘已经触发，但 AI 说不成长”的断裂。

### 7.2 路线中的随机性

不新增第四种路线，避免 Schema 扩散：

- 三条路线仍然固定为深度、广度、转变。
- 根据 `机缘类型`，其中一条可以带“异变色彩”：
  - 额外代价
  - 不稳定触发
  - 条件更苛刻
  - 外观/表现异常
- 异变不降低阶段，不删除核心能力，不把天赋变成纯负面。

随机体现在“这次机缘带来哪种形态”，不体现在“是否白费”。

## 8. 玩家可见反馈

机缘命中后，显示一个轻量的“命格机缘”面板：

```text
命格机缘：折光留影
初醒 → 掌握
机缘：危机中觉醒
[深度强化] [广度强化] [转变强化]
```

未命中时：

- 不弹窗
- 不显示“本次未触发”
- 不写系统日志给玩家
- 故事正常结束

正文中可以自然出现“瓶颈”“异象”“忽然顺手”“旧伤发热”等感受，但不要求主故事额外输出字段。

## 9. 边界与不变量

- 机缘只推进开发阶段，不改变资质阶位。
- 触发后进阶必成功；不允许随机失败或天赋报废。
- 同一时间只处理一个天赋机缘。
- 已圆满天赋不进入机缘判定。
- 现有年龄、单条次数、总次数、冷却和最低证据门槛继续生效。
- 没有新证据的回合不重复判定。
- 读档不能重掷同一回合的机缘结果。
- 机缘未处理时不能创建同天赋的第二个机缘。
- 玩家选择路线后，下一轮故事必须承接新能力，不把旧能力写没。

## 10. 成本

| 部分 | 成本 |
|---|---|
| 本地机缘判定 | 无 AI 调用 |
| 02 故事连续性 | 不变 |
| 03 天赋路线生成 | 只在机缘命中时调用 |
| 路线生成输入 | 只含一个天赋，比现在更小 |
| 路线生成输出 | 仍然是三条路线，规模不变 |

预期结果：

- 比现在“可能每轮调用 03”更便宜。
- 比“每五轮固定复评”更有随机感。
- 不会因为增加随机判定而增加模型费用。

## 11. 验证

- 固定 seed 下，同一局同一回合结果可复现。
- 没有新证据时不重复判定。
- 不满足年龄/次数/冷却/阶段边界时不产生机缘。
- 机缘命中后只调用一次 03。
- 03 只生成路线，不再返回“不成长”。
- 玩家选择后只推进一个开发阶段，资质不变。
- 读档后同一回合机缘结果不变。
- 未命中时不出现 UI、系统提示或额外 AI 调用。
- 03 Prompt 版本、Schema、权威文档和测试同步更新。

## 12. 初版平衡参数

以下参数已落在 `TALENT_OPPORTUNITY_TUNING`，后续可单独调整，不影响协议：

- 基础命中率 `2%`；每个证据窗口 `+2.5%`，最高 `+12%`。
- 成年 `+1%`；60 岁以后 `-1%`；第三人生阶段 `+1%`。
- 气运按 `0.03%/点` 修正，最多 `±3%`；高资质每阶 `-0.3%`。
- 总命中率限制在 `1%–25%`，不向玩家展示百分比。
- 机缘类型初版倾向：顿悟约 30%，危机觉醒约 30%，传承回响约 25%，异变约 15%。
- 同一次只处理一个机缘；不增加延迟处理或主动储存机缘。
- 成长面板沿用现有时间线卡片，只在标题追加机缘类型标签。
