# 第一层：玩家表层

## 产品主线

玩家从欢迎界面进入一段新人生，依次选择或创作世界、建立角色、选择命格、分配属性、确认命运，然后在核心故事界面推进人生，最终进入结算并开始下一世。

1. **欢迎界面**：展示产品主体入口，提供开始新人生、继续已有进度以及设置、说明、排行榜、邮箱等附属入口。
2. **世界选择界面**：让玩家从已有世界中选择，或进入自定义世界创作。
3. **自定义世界界面**：让玩家定义世界名称、描述、时代、世界性质、力量体系与其他创建条件，并看到当前设定的结果概览。
4. **角色创建界面**：让玩家定义角色姓名、身份、背景、起始年龄和寿命范围等角色事实。
5. **命格界面**：让玩家从候选命格中完成选择，并区分本局普通命格与跨局轮回天赋。
6. **属性分配界面**：让玩家确认本局起始基础属性。
7. **命运预览界面**：汇总已经确认的世界、角色、命格与属性，作为进入模拟前的最后确认。
8. **核心故事界面**：展示已经生成的故事、时间、角色状态、分支选择与推进操作。正文收到并通过协议后立即进入阅读区，后续分析继续完成本轮附加结果。
9. **人生结算界面**：展示人生评分、评语、诗句、重要经历、轮回结果和下一段人生入口。

## 附属界面

- **设置**调整阅读、叙事和玩家自有模型配置。
- **说明**介绍游戏流程、更新记录和关联项目。
- **排行榜**展示符合条件的优秀人生记录。
- **邮箱**承载站内消息与可转移轮回天赋。
- **账号**管理可选登录、云端数据和账号内容。
- **存档管理**保存、读取和管理本地人生。
- **反馈**提交问题并提供可关联诊断编号。

## 统一布局

- 所有稳定玩家界面使用同一个共享主体宽度，不按页面建立不同的桌面宽度特例。
- 桌面视口中的主体宽度至少占可用宽度的一半，并使用 `max(42rem, 58vw)` 保持统一；移动视口继续占满可用宽度。
- 统一的是页面主体板块，按钮、表单、卡片、提示框和对话框继续按各自内容与交互需要保持合理宽度。

## 统一配色

- 阅读主题下主体页面保持低饱和淡黄色底色；暗夜主题和白色主题分别切换到对应的低亮度深色或中性白色层次。辅助背景、卡片、输入面、选中态和浮层必须在当前主题内保持清晰层级，不使用成块的高饱和强调面。
- 辅助边框只负责区分层次，使用低对比度暖灰；辅助文字和图标使用中性暖灰，不以深黄作为常规说明色。
- 主要操作、错误、成功、警告、稀有度和分类可以使用必要语义色；阅读主题额外提供赤橙黄绿青蓝紫七组低饱和辅助色，但不能反向成为大面积辅助背景、强渐变或正文底色。
