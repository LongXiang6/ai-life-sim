# 故事连续性提取机制

## 目标

故事连续性提取把每轮已经完成的完整故事转换为可供后续叙事使用的本轮记忆，并登记正文已经明确安排的未来事件。

## 结果

- 每轮正文发布后提取当前已完成回合。
- 调用依次接收历史记忆、最近两轮正文和当前回合三条标准 JSON 用户消息。
- 本轮记忆每项只含时间、事实和权重；未来事件使用 `时间：事实` 字符串。
- 本轮事实使用绝对客观、最精简的现代白话，保留后续叙事必需的主体、动作或关系、对象、必要前因、直接结果和持续状态；只有去除后不改变事实、因果、边界或持续状态的冗余叙述才不保留。
- 学习、认识或能力变化按正文原意记录；领悟某事本身可以是已经发生的客观事实，不要求改写为形成、掌握或应用，也不要求后文再次展示。负责说明结果为何发生、如何发生或在何种边界内成立的行动、条件、工具、材料、限制、失败原因和验证继续保留。
- 当前回合是新增事实的唯一来源，历史消息只用于消歧、衔接和去重。
- 完整原文继续永久保存在正式故事历史中。
- 本轮记忆进入后续主叙事的历史投影，未来事件进入既有历史事件账本。

## 语义边界

该机制提取的是故事中的客观事实，不是角色记忆本体。统一记忆与历史事件账本是消费方，提取结果本身不拥有记忆状态、遗忘状态或人物认知。
