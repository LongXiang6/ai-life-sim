# Prompt 与缓存机制

## 目标

Prompt 机制把固定职责、慢变事实、故事历史和本轮条件组成稳定、可理解的 AI 输入。

## 结果

- 主故事固定资产当前只保存一句合理叙事目标和输出格式/结构协议；主故事动态六段 JSON、事实投影和本地解析仍按各自所有者运行。故事连续性与天赋成长固定资产继续保留各自职责，不因主故事固定资产收缩而删除。
- 固定 Prompt 位于最前方，并直接声明“根据输入生成一段合理的故事”这一唯一目标；不假设模型知道项目、系统、MOD 或调用链背景。
- 固定 Prompt 使用中文代码式 JSON 组织输入映射、执行规则、条件判断和输出契约；每个键只承担一个职责，执行数组保持依赖顺序。
- 固定 Prompt 与需要机器识别的动态 JSON 保持标准双引号和标准转义；只删除不承担结构、语义或输出示范职责的强调引号。缓存命中取决于消息与字节前缀稳定，不因删除双引号自动提高。
- 条件结果使用明确的“如果、则、否则如果、否则”关系；输出形状、字段类型和互斥关系只声明一次。
- JSON 既可以组织 Prompt，也可以承载需要由本地程序拆分校验的结构化直接产品；输出媒介按当前唯一产品选择，不为保留旧协议而混用 JSON 与裸行文本。JSON 字符串中的换行、引号和控制字符使用标准转义。主故事最终且只调用一次 `submit_story_turn`，其唯一参数对象恰好包含正文、分支、结局三个顶层键，三个键各出现一次，分支与结局互斥且未使用时明确为 null。
- 主故事解析优先读取 `submit_story_turn` 的可用 JSON 参数；工具调用数量、字段顺序和对象外说明不作为整包拒绝条件。解析先做围栏、别名、乱序、局部补全和多候选识别；一个坏字段、坏数组项、截断尾部或重复度诊断不得丢弃同一响应中其他可用结果。只有正文等最低可用产品完全不存在时才失败，不从解析恢复中生成故事事实。
- 故事正文以单个 JSON 字符串承载；全部段落保持在同一字符串内，需要换行时使用标准 `\n` 转义，不把段落拆成相邻字符串或额外字段。
- 正文段落按模型自然语义边界保留；不得用固定首句模板强行从时间、年龄或日期开头，也不得由渲染器把自然段改造成固定行数或固定换行节奏。
- 核心模拟的单个正式回合固定消费一个主故事结果并执行两个并行后调用：连续性提取同时形成本轮记忆与未来事件，天赋成长同时完成成长判定与三路线生成。开启下一轮预生成时，只在两路后调用提交后提前执行下一回合的主故事请求，不提前执行其后调用；系统分析、事件识别、剧情引导与状态变化 AI 不保留实际调用或资产。
- 正式替换前的共享审查基线沿正常创建流程包含世界名称与描述、历法与叙事风格，角色姓名、性别、种族、背景、起始年龄、寿命，四项基础值、修正值与当前值，以及四个携带槽中的普通命格和轮回天赋；每个调用只接收完成自身职责所需的投影，不重复发送整份基线。
- 连续审查把已确认的本轮记忆、未来事件与玩家选定成长路线应用到下一轮输入，用同一角色和世界验证长期连续性；测试数据不写入正式运行状态。
- 连续性提取先保留近期完整正文退出上下文后仍需成立的最终状态、持续关系、关键发现、承诺和未解决结果；同一回合中已经被后续最终结果完整覆盖且没有独立影响的中间动作、复测和阶段结果不再保留，同一因果阶段合并表达，不设置固定条数上限。
- 连续性提取输出本轮记忆的时间、客观事实和权重，权重只服务于 02 的记忆取舍职责；投影给后续故事 AI 时只保留同日合并的 `时间：事实` JSON 字符串数组。未来事件使用无权重的 `时间：事实` JSON 字符串数组。
- 未来事件只接收正文已经给出具体日期、明确历法周期或可从当前绝对时间唯一计算的事项；“某事发生前后”“下次处理时”等没有排期的条件继续作为连续性事实，不伪造为当前回合结束之后的绝对时间。未来事件逐条识别、逐条去重和逐条登记，单条无法换算时放弃该条，其余合法事项继续使用；本轮记忆不因未来事件异常而丢弃。
- 解析器红线：除非最低可用产品绝对不存在，不得使用严格 Schema、未知字段、字段顺序或整包严格判定阻断响应；不得增加格式修复请求、重试、备用模型或旁路兼容层。
- 命格抽取的五类首批调用分别只接收行动、认知、表达、经营或杂类一个方向，每次目标四条普通命格；五类调用完成后才发布选择页。选择页发布后按分类继续补充至每类十二条，候选逐条合并并由命格池缓存按世界与 Prompt 版本增量保存。
- 命格页从同一缓存恢复时重新建立五类计数；只有五类都至少有四条可用普通候选才恢复首批完成状态，缺少任一分类或任一分类不足四条的缓存不直接进入选择交接。达到每类十二条后停止该类后续调用；最后一个完整响应中已经识别出的有效条目继续保留，不为凑固定总数丢弃。
- 命格解析支持围栏、对象外说明、顶层多候选、字段乱序、字段别名、中文或英文分类名、字符串数字和文本属性加成；属性字段或单个命格无法恢复时只放弃对应局部结果，不能牵连同一响应中的其他有效命格。传输 Schema 只做宽容观测，不作为整包运行阻断。
- 命格分类由每次调用的分类系统 Prompt 唯一承载；用户消息不重复发送 `generationTask`。`existingNames` 表示全池已被占用的名称，新命格不得与其重复；每次补充调用还必须接收目标类别已有候选的名称、设定描述和效果摘要，并不得以同义词、改名或换写效果重复已有能力方向。内部 ID、lineageId 和调用编号不发送给 AI。未使用的固定分类模板不作为第二真源保留。
- 基础抽取 Prompt 只生成普通等级；普通候选只能表达局部、低强度、有限条件的优势。杂类不得直接生成灵体、长生、不灭、预知、必然逢凶化吉、因果操控、言出法随、全知全能或万法通晓等高阶结果，高阶方向由独立成长调用决定。运行时不以关键词黑名单、名称、相似度或换写效果判断丢弃可解析候选；重复与强度偏移必须回到 Prompt、分类输入和现有候选摘要修复。
- 命格候选只在最低字段无法恢复、类别无法归一化、属性不是有限整数、普通级明确数值预算越界或身份 ID 重复时放弃对应局部项；这些完整性边界不得扩展为内容过滤。首批响应中已经解析出的额外候选继续保留，不按四条目标截断。
- 天赋成长的动态组装先完成可确定的机械筛选：证据窗口固定为来源故事回合，同一故事回合经连续性提取形成的多条记忆、多个事实日期或重复正文只合并为一个窗口；再按候选本级生效时间标明窗口可用于哪些候选，剔除成长选择等结果记录，并移除可用窗口数量尚未达到目标等级最低门槛、单条天赋已进阶 2 次、全局已进阶 6 次、距上次确认不足 20 轮或模拟时间未严格超过 20 年的候选。本地不判断事实是否真正体现天赋。全部候选被程序过滤时不调用成长 AI。AI 只在剩余候选及其可用窗口中判断核心能力、结果强度与成长路线；有条件的当前效果必须在同一窗口中同时满足必要触发条件和核心能力实际表现，且成长必须同时具备反复训练或使用形成的长期积累、窗口之间真实经过的时间沉淀和至少一个明确契机（机缘、奇遇、顿悟、重大变故、情绪冲击或同等具体事件），任一缺失都不构成成长证据。路线说明先直述能力，只有真实存在条件、限制或属性牺牲时才补充，不强制能力+代价模板。属性上限为普通 2、精良 4、稀有 6、史诗 8、传说 10、神话 12；每条路线的负属性绝对值总和与净分配都不得超过目标等级上限，不要求用满或高等级实际点数超过低等级。名称为二至六字并优先四字，使用叙事逻辑说明剧情变化，不使用成功率、判定值、触发率、冷却等系统化措辞，最多使用一处点睛比喻，不复制长篇输入或逐字叠加旧效果。
- 轮回升阶的 `attrBonus` 是最终属性加成的稀疏表示：只输出非零项，零值省略；没有数值加成时允许 `{}`。Schema 要求属性对象存在，但不要求五个键全部出现。
- Prompt 使用中性字段与类型占位，不提供人物、世界、事件或成品正文示范。
- 慢变内容位于动态内容之前，可升级内容位于稳定前缀之后。
- 主故事六条动态消息依次为稳定世界名称与描述 JSON，历史连续性事实 JSON，最近五轮完整正文 JSON，角色当前叙事语义 JSON，世界模拟产出 JSON，以及本轮事实与方向 JSON；对象外不使用 `⟦…⟧` 标签。历史连续性事实用于消歧、衔接和识别已完成状态、持续关系与未解决结果；最近五轮完整正文独立于压缩后的历史连续性事实发送，作为主故事可见的近期完整正文窗口；本轮事实与方向提供当前时间、玩家行动、年龄边界、事件材料、称呼和篇幅。当前区域、历法和其他环境材料如有必要，只作为最后一条消息中的事实参考，不附加固定叙事模板。历史连续性事实使用同日合并的 JSON 字符串数组且不含权重；当前年龄、属性语义和角色天赋位于历史与最近正文之后，避免高频角色变化截断追加型历史的缓存前缀。存在已到期且仍可用的历史事项时，最后一条消息额外增加只含可读时间与事实的 `当前到期事件`。称呼方式由设置选择，默认第二人称；动态称呼指令只改变主角称呼，不改变结构化输出协议。
- 每个逻辑调用拥有独立缓存归属，同一主体同一调用保持稳定。

## 最大边界

Prompt 提供事实和职责，不拥有业务状态，也不替代本地协议校验。01、02、03 样品是字段、排序、消息数量、内容语义、输出形状和文风的唯一接入基线；不在样品中的 AI 可见字段不接入，也不从其他来源补回。04 的调用、Prompt、Schema、缓存、动态组装、状态应用、活动阶段和测试引用全部删除，不恢复同类 AI 职责。
