# Prompt 与缓存机制

## 目标

Prompt 机制把固定职责、慢变事实、故事历史和本轮条件组成稳定、可理解的 AI 输入。

## 结果

- 主故事固定资产当前版本为 `7.27.0`，逐字采用 `D:/AI/docs/系统prompt.txt` 的单时间节点叙事生成规则；每次调用只生成当前节点的一条世界内事件叙事，只写当前节点，不跨时间、不总结一生、不输出多条。叙事可以使用人生事件、社会事件、世界事件等不同视角；事件叙事必须是因果闭合的纯粹事件内容，不包含任何时间锚点。世界观作为全局背景，玩家信息定义事件中的角色，其中天赋技能作为被动效果在相关叙事中自动触发；历史事件上下文是非连续性因果片段，由离散化节点事件只读提供前情。属性变化只由重大事件触发并按正文依据变化。正文采用第二人称，现代白话为主并点缀古风，长度 100 至 200 字；只有在发生改写命运的大事级别才提供三个不同的命运走向，并按状态行、正文、命运分支和结局的文本协议输出。动态数据层严格采用 `D:/AI/docs/数据层示例.txt` 的五个顶层字段和单对象 JSON。故事连续性与天赋成长固定资产继续各自保留职责，不因主故事固定资产调整而删除。
- 固定 Prompt 位于最前方；随后只发送一条数据层用户消息，不把示例人物、世界或历史写进固定资产。
- 固定 Prompt 是纯文本规则，动态输入是可由 `JSON.parse` 直接解析的数组；两种媒介各自只有一个所有者。
- 固定 Prompt 与需要机器识别的动态 JSON 保持标准双引号和标准转义；只删除不承担结构、语义或输出示范职责的强调引号。缓存命中取决于消息与字节前缀稳定，不因删除双引号自动提高。
- 条件结果使用明确的“如果、则、否则如果、否则”关系；输出形状、字段类型和互斥关系只声明一次。
- 主故事输出使用固定 Prompt 声明的状态行、`正文`、`命运分支`、`结局`文本协议，不强制工具调用或 JSON 模式。状态行只包含年龄、心智、体魄、魅力和家境；分支和结局互斥，未触发字段使用 `false`；分支为三个字符串选项，结局为包含四字评语与最终总结的对象。
- 主故事解析先识别正文，再识别状态行、分支与结局。固定 Prompt 中的 `{["选项一","选项二","选项三"]}` 与 `{"评语":"四字评语","总结":"一句最终总结"}` 简写、标准 JSON 写法、引号和句末标点差异都不得牵连同一响应中的可用正文。只有最低可用正文完全不存在时才失败，不从解析恢复中生成故事事实。
- 故事正文以单个 JSON 字符串承载；全部段落保持在同一字符串内，需要换行时使用标准 `\n` 转义，不把段落拆成相邻字符串或额外字段。
- 正文段落按模型自然语义边界保留；不得用固定首句模板强行从时间、年龄或日期开头，也不得由渲染器把自然段改造成固定行数或固定换行节奏。
- 核心模拟的单个正式回合固定消费一个主故事结果。天赋成长按现行条件执行；故事连续性只在近期完整正文超过十轮且到达五轮间隔时调用，一次压缩最早连续五轮。开启下一轮预生成时，只等待本轮实际启动的后调用完成，不提前执行下一回合的后调用。
- 正式替换前的共享审查基线沿正常创建流程包含世界名称与描述、历法与叙事风格，主角姓名、性别、种族、背景、起始年龄、寿命，心智、体魄、魅力、家境四项基础值、修正值与当前值，以及四个携带槽中的普通命格和轮回天赋；每个调用只接收完成自身职责所需的投影，不重复发送整份基线。
- 连续审查把已确认的本轮剧情、未来事件和玩家选定成长路线投影应用到下一轮输入，用同一角色和世界验证长期连续性；测试数据不写入正式运行状态。
- 连续性提取先保留近期完整正文退出上下文后仍需成立的最终状态、持续关系、关键发现、承诺和未解决结果；同一回合中已经被后续最终结果完整覆盖且没有独立影响的中间动作、复测和阶段结果不再保留，同一因果阶段合并表达，不设置固定条数上限。
- 连续性提取一次输出五轮批次中各来源回合的时间、剧情和权重，权重只服务于 02 的记忆职责；投影给后续故事 AI 时转为“时间：剧情”字符串。近期完整正文按“年龄·时间·轮次：正文”字符串发送，达到压缩阈值后至少保留最近五轮。
- 未来事件只接收正文已经给出具体日期、明确历法周期或可从当前绝对时间唯一计算的事项；“某事发生前后”“下次处理时”等没有排期的条件继续作为连续性事实，不伪造为当前回合结束之后的绝对时间。未来事件逐条识别、逐条去重和逐条登记，单条无法换算时放弃该条，其余合法事项继续使用；本轮剧情不因未来事件异常而丢弃。
- 解析器红线：除非最低可用产品绝对不存在，不得使用严格 Schema、未知字段、字段顺序或整包严格判定阻断响应；不得增加格式修复请求、重试、备用模型或旁路兼容层。
- 命格抽取的五类首批调用分别只接收行动、认知、表达、经营或杂类一个方向，每次目标四条普通命格；五类调用完成后才发布选择页。选择页发布后按分类继续补充至每类十二条，候选逐条合并并由命格池缓存按世界与 Prompt 版本增量保存。
- 命格页从同一缓存恢复时重新建立五类计数；只有五类都至少有四条可用普通候选才恢复首批完成状态，缺少任一分类或任一分类不足四条的缓存不直接进入选择交接。达到每类十二条后停止该类后续调用；最后一个完整响应中已经识别出的有效条目继续保留，不为凑固定总数丢弃。
- 命格解析支持围栏、对象外说明、顶层多候选、字段乱序、字段别名、中文或英文分类名、字符串数字和文本属性加成；属性字段或单个命格无法恢复时只放弃对应局部结果，不能牵连同一响应中的其他有效命格。传输 Schema 只做宽容观测，不作为整包运行阻断。
- 命格分类由每次调用的分类系统 Prompt 唯一承载；用户消息不重复发送 `generationTask`。`existingNames` 表示全池已被占用的名称，新命格不得与其重复；每次补充调用还必须接收目标类别已有候选的名称、设定描述和效果摘要，并不得以同义词、改名或换写效果重复已有能力方向。内部 ID、lineageId 和调用编号不发送给 AI。未使用的固定分类模板不作为第二真源保留。
- 基础抽取 Prompt 只生成普通等级；普通候选只能表达局部、有限、非决定性的优势，并以输入世界中普通个体与常规水平的凡俗尺度为基准。分类按主要作用机制判断，不按场景、题材、角色身份或种族判断；题材只改变机制形式与尺度，种族、身份和背景只限定实际可用的行动、感知、表达和资源通道。杂类只在行动、认知、表达、经营无法承载主要机制时使用，不得直接生成灵体、长生、不灭、预知、必然逢凶化吉、因果操控、言出法随、全知全能或万法通晓等高阶结果，高阶方向由独立成长调用决定。运行时不以关键词黑名单、名称、相似度或换写效果判断丢弃可解析候选；重复与强度偏移必须回到 Prompt、分类输入和现有候选摘要修复。
- 命格候选只在最低字段无法恢复、类别无法归一化、属性不是有限整数、普通级明确数值预算越界或身份 ID 重复时放弃对应局部项；这些完整性边界不得扩展为内容过滤。首批响应中已经解析出的额外候选继续保留，不按四条目标截断。
- 天赋成长的动态组装先完成可确定的机械筛选：证据窗口固定为来源故事回合，同一故事回合经连续性提取形成的多条记忆、多个事实日期或重复正文只合并为一个窗口；再按候选本级生效时间标明窗口可用于哪些候选，剔除成长选择等结果记录，并移除可用窗口数量尚未达到目标等级最低门槛、单条天赋已进阶 2 次、全局已进阶 6 次、距上次确认不足 20 轮或模拟时间未严格超过 20 年的候选。本地不判断事实是否真正体现天赋。全部候选被程序过滤时不调用成长 AI。AI 只在剩余候选及其可用窗口中判断核心能力、结果强度与成长路线；有条件的当前效果必须在同一窗口中同时满足必要触发条件和核心能力实际表现，且成长必须同时具备反复训练或使用形成的长期积累、窗口之间真实经过的时间沉淀和至少一个明确契机（机缘、奇遇、顿悟、重大变故、情绪冲击或同等具体事件），任一缺失都不构成成长证据。路线说明先直述能力，只有真实存在条件、限制或属性牺牲时才补充，不强制能力+代价模板。属性上限为普通 2、精良 4、稀有 6、史诗 8、传说 10、神话 12；每条路线的负属性绝对值总和与净分配都不得超过目标等级上限，不要求用满或高等级实际点数超过低等级。名称为二至六字并优先四字，使用叙事逻辑说明剧情变化，不使用成功率、判定值、触发率、冷却等系统化措辞，最多使用一处点睛比喻，不复制长篇输入或逐字叠加旧效果。
- 轮回升阶的 `attrBonus` 是最终属性加成的稀疏表示：只输出非零项，零值省略；没有数值加成时允许 `{}`。Schema 要求属性对象存在，但不要求五个键全部出现。
- Prompt 使用中性字段与类型占位，不提供人物、世界、事件或成品正文示范。
- 慢变内容位于动态内容之前，可升级内容位于稳定前缀之后。
- 主故事只发送一条单对象 JSON 消息，顶层依次为 `世界`、`玩家信息`、`历史事件上下文`、`玩家本节点属性`、`本节点信息`。`历史事件上下文` 只含 `节点事件` 字符串序列；`玩家本节点属性` 只含心智、体魄、魅力、家境整数字符串；`本节点信息` 只含 `时间节点` 和 `命运抉择`。对象外不使用标签或说明；`命运抉择` 只承载玩家已确认行动，没有输入时为空字符串，不新增字段或追加系统材料。
- 主故事、故事连续性和天赋成长三个逻辑调用各自拥有独立缓存归属，同一主体同一调用保持稳定；已删除的 04 事件库不保留缓存池或兼容映射。

## 最大边界

Prompt 提供事实和职责，不拥有业务状态，也不替代本地协议校验。指定系统 Prompt、数据层示例、02 与 03 样品分别是主故事固定规则、动态字段、连续性压缩和天赋成长的接入基线；不在对应样品中的 AI 可见字段不接入，也不从其他来源补回。旧 04 世界模拟和后续事件库的调用、Prompt、Schema、缓存、动态组装、概况/状态应用、活动阶段、瞬态结果和测试引用全部删除，不保留兼容入口或旁路。
