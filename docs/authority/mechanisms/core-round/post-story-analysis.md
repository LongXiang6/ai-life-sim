# 后调用

## 共同目标

后调用在正文发布后，从各自样品规定的冻结 JSON 用户消息中产生附加结果。正式结构包含故事连续性提取、天赋成长与事件库三个并行后调用；系统分析、事件识别、剧情引导、角色数值、道德变化和状态变化 AI 不进入目标调用链。

## 现行结果

1. 故事连续性提取按五轮 cadence 触发，读取历史剧情、待压缩五轮正文和压缩范围，产出带来源回合的剧情及可确定的未来事件；未达到阈值时跳过调用。历史剧情只用于理解背景、时间关系和重复，待压缩五轮正文是两个输出区唯一的新事实来源。
2. 天赋成长判断本局已选的普通天赋或轮回天赋是否形成下一阶三选一，成立时按深度强化、广度强化、转变强化固定顺序输出三条同级等强路线及成长后的完整属性加成；现有固定 Prompt 顶层、动态输入、输出字段、解析、本地筛选、冷却、次数、玩家确认与持久化均保持不变，本轮只吸收样例的判定与路线表达优化。三者分别使同一场景的优势更显著、增加能力适用场景、让作用方式发生根本变化，必须来自同一原能力且没有强弱层级。转变强化只改变作用方式，不额外扩大影响总量；提高精度、抗噪、注意力或速度仍属于深度强化，只有改变能力的输入媒介、作用方式或产生结果的路径才属于转变强化。长期证据按来源故事回合计数，同一回合的多条记忆只构成一个证据窗口，有条件的效果必须在窗口中同时发生必要触发条件和核心能力实际表现，相似经历不构成成长依据。程序先依据本局进阶次数、单条天赋历史次数、上次确认进阶回合、模拟基础点和候选可用证据窗口数量筛选候选；AI 不判断冷却、总次数或资格。成长结果必须返回实际引用的证据窗口编号，程序验证编号属于该候选、互不重复且达到目标等级最低窗口数；窗口数量不足或引用无效时按不成长处理。路线名称为二至六字并优先四字，说明先直述能力；首句直接落到能力机制、触发条件、动作或可观察结果，三条路线可采用不同自然主语，不默认以“此人”“该角色”“这位人物”“此天赋”或“拥有……”开头。只有真实存在条件、限制或属性牺牲时才说明代价或边界，不要求每条路线固定采用“能力加代价”结构。使用叙事逻辑说明剧情变化，不使用系统化措辞，最多使用一处点睛比喻。属性加成以稀疏对象表示最终结果，只写非零项，无数值加成时允许空对象，不要求五个属性键全部出现。
3. 事件库读取当前世界状态、历史剧情数组和本轮故事与时间，生成 0 至 3 条相互独立的候选事件；每条仅含标题与描述。事件可发生在世界任意区域，供下一轮故事 AI 自主参考，不要求因果衔接，不围绕主角，不维护世界状态、概况、冷却或事件账本。

## 角色数值边界

角色数值变化不再由本调用链生成。故事 AI 可以接收当前角色的基础属性语义与气运语义，但不承担数值计算、等级换算、变化判定或写入。道德字段、道德变化和道德叙述倾向不进入状态、Prompt 或玩家结果。

## 天赋属性边界

- 体魄表示力量、耐力、恢复和身体承受；心智表示理解、记忆、判断和心理韧性；悟性表示学习、领悟、迁移和修炼能力；魅力表示外貌气质、表达、关系和群体影响；气运表示难以完全由普通因果解释的机缘倾向。
- 普通、精良、稀有、史诗、传说、神话的完整属性总加成净分配上限分别为 2、4、6、8、10、12。路线不要求用满上限，高等级也不要求实际分配点数必然超过低等级；气运可以成为加成，但出现概率明显低于四项基础属性。
- 天赋允许降低一个或多个属性以换取其他属性，负值参与净总量抵扣；每条路线的负属性绝对值总和与净分配都不得超过目标等级上限。只有存在真实属性牺牲时才使用负值，不以负值凑足点数。等级上限同时作为 Prompt 创作边界和本地提交校验边界。

## 失败结果

- 后调用失败不撤回已经发布的正文，未完成结果不伪装为成功。
- 故事正文可用且没有提前结局是硬要求；分支判定、应结局而漏结局和天赋成长结果是可在后续流程修正的非硬要求。
- 压缩失败不阻塞正文提交，只记录待重试来源回合；在最近详细故事仍保留时至少提供两次后续重试机会，成功后才写入摘要。
- 事件库失败或返回空数组不阻塞正文，也不触发世界概况更新、冷却补偿或备用调用。
- 下一轮以已发布正文和已经成立的正式状态为事实。

## 正式收口边界

旧 04 世界模拟/状态变化 AI 的世界变化、概况变更、因果链、冷却和状态应用职责已从正式运行移除，不得保留旧协议、旧缓存或兼容入口。现行 04 仅为事件库调用，正式拥有独立 Prompt、Schema、缓存归属和动态组装；其结果是瞬态候选批次，只在下一轮一次性投影给故事 AI，不进入 Store、存档、世界状态或概况。
