# 后调用

## 共同目标

后调用在正文发布后，从各自样品规定的冻结 JSON 用户消息中产生附加结果。正式结构只包含故事连续性提取与天赋成长两个后调用；事件库、系统分析、事件识别、剧情引导、角色数值、道德变化和状态变化 AI 不进入目标调用链。后调用不是主故事的补救链，不得替主故事形成世界变化或正文，也不得回写或重做已经发布的主故事结果。

## 现行结果

1. 故事连续性提取按五轮 cadence 触发，读取历史剧情、待压缩五轮正文和压缩范围，产出带来源回合的剧情及可确定的未来事件；未达到阈值时跳过调用。历史剧情只用于理解背景、时间关系和重复，待压缩五轮正文是两个输出区唯一的新事实来源。压缩剧情保留仍会影响玩家后续人生的人物身份与关系变化、教育经历、职业或社会身份变化，以及家庭资源和限制对玩家造成的持续影响；区分已成立状态与计划、传闻或未决结果，后续仅在故事明确改变状态时更新。家庭成员的独立经历不作为玩家事实，除非它直接改变玩家处境。以上内容继续写入现有逐轮剧情摘要并由记忆时间轴投影，不增加独立人物关系或玩家身份状态。
2. 天赋成长只在本地成长状态机形成“可成长”窗口并命中机缘时调用。主故事同次响应可返回天赋表现线索，线索只记录不透明天赋引用与可观察结果；来源回合由引擎按本轮记录，不由模型输出；`mod-character` 负责把线索合并为证据窗口并记录每条血脉已复评到的证据水位。天赋有初醒、掌握、圆满三个开发阶段；初醒到掌握至少需要两个证据窗口，掌握到圆满至少需要三个证据窗口。资质阶位不因局内成长改变。程序先按年龄、阶段、窗口数量、证据水位、本局成长次数、单条天赋历史次数、上次确认成长回合和模拟基础点筛选候选，再按本轮存档种子做一次确定性机缘判定；未命中不调用 AI，也不显示成长面板，命中后只把该天赋、机缘类型和证据窗口送入 03。普通天赋或轮回天赋命中后，成长调用按深度强化、广度强化、转变强化固定顺序输出三条同阶段路线及成长后的完整属性加成；玩家确认后才写入结果。深度强化提高当前机制的掌握，广度强化拓展适用场景；转变强化依据玩家本局已成立经历和机缘气质重塑机制组合，但不得删除或削弱已经成立的核心能力。机缘类型分为顿悟、危机觉醒、传承回响、异变，只影响路线表现和代价，不改变进阶成功率。血脉编号只串联被替换词条的成长记录，不锁定能力来源；宏观分类不限制路线类型。完整新效果替换旧版本，不默认叠加历代能力。证据资格仍针对当前版本：窗口只由主故事明确引用的可观察结果形成，同一故事回合的多条线索只构成一个窗口；没有新的未复评证据时不重复判定机缘。03 只生成路线，不判断是否成长；成长结果必须返回本次机缘对应的血脉编号、机缘类型、实际引用的证据窗口编号，程序验证编号属于该候选、互不重复且达到该开发阶段的最低窗口数；调用或契约失败时不记录该天赋的证据水位，下一轮可重试。路线名称为二至六字并优先四字，说明先直述能力；首句直接落到能力机制、触发条件、动作或可观察结果，三条路线可采用不同自然主语，不默认以“此人”“该角色”“这位人物”“此天赋”或“拥有……”开头。只有真实存在条件、限制或属性牺牲时才说明代价或边界，不要求每条路线固定采用“能力加代价”结构。使用叙事逻辑说明剧情变化，不使用系统化措辞，最多使用一处点睛比喻。属性加成以稀疏对象表示最终结果，只写非零项，无数值加成时允许空对象；正向净加成与负属性绝对值均不得超过资质阶位乘以2，最高为18。
## 角色数值边界

角色数值变化不再由本调用链生成。故事 AI 可以接收当前角色的基础属性语义与气运语义，但不承担数值计算、等级换算、变化判定或写入。道德字段、道德变化和道德叙述倾向不进入状态、Prompt 或玩家结果。

## 天赋属性边界

- 心智表示理解、记忆、判断和心理韧性；体魄表示力量、耐力、恢复和身体承受；魅力表示外貌气质、表达、关系和群体影响；财富表示家庭资源、成长环境与早期可获得的现实支持；气运表示难以完全由普通因果解释的机缘倾向。
- 九阶资质对应的属性净加成与负属性绝对值上限为资质阶位乘以2，最高为18。路线不要求用满上限；资质阶位表达机制复杂度，不要求属性点数或影响范围随阶位递增。气运可以成为加成，但出现概率明显低于四项基础属性。
- 天赋允许降低一个或多个属性以换取其他属性，负值参与净总量抵扣；每条路线的负属性绝对值总和与正向净加成都不得超过资质阶位上限。只有存在真实属性牺牲时才使用负值，不以负值凑足点数。资质上限同时作为 Prompt 创作边界和本地提交校验边界。

## 失败结果

- 后调用失败不撤回已经发布的正文，未完成结果不伪装为成功。
- 主故事生成失败时不新增世界模拟、事件识别、状态变化、重复主故事或质量补救调用；只能按现有主故事终态处理，后调用不承担恢复主故事的职责。
- 故事正文可用且没有提前结局是硬要求；分支判定、应结局而漏结局和天赋成长结果是可在后续流程修正的非硬要求。
- 压缩失败不阻塞正文提交，只记录待重试来源回合；在最近详细故事仍保留时至少提供两次后续重试机会，成功后才写入摘要。
- 下一轮以已发布正文和已经成立的正式状态为事实。

## 正式收口边界

旧版 04 世界模拟/状态变化 AI 不恢复为正式运行链；条件式事件卡池只负责生成抽象事件卡整池（名称、正负、权重），不能替主故事形成世界变化或正文，也不进入后调用。主故事自行决定是否消费，并在 `事件卡消费` 中列出本轮实际采用的卡名。
