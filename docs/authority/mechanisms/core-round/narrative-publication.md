# 正文发布

## 目标

正文发布让玩家在主叙事完成后立即获得正式可阅读结果。

## 结果

- 主叙事在同一次有效模型响应中优先归一化可恢复的正文、命运分支和结局信息；函数参数、JSON、旧标签协议、包裹文本或普通正文只要能够可靠识别出正文，均作为同一故事结果发布。只有没有可用正文或故事事实本身无法判定时才拒绝本轮。
- 主叙事在故事需要玩家决定不同走向时输出命运分支；只有当前人生已经不能再产生任何玩家行动、选择或可继续经历时才输出结局。结局不限于死亡，但阶段成果、职责交接、退休、迁移、身份变化、局部能力丧失或仍保留感知与决定能力的转化继续作为正文或分支，结局协议只包含四字评语。
- 通过后的正文立即加入正式故事历史。
- 阅读区直接展示正式正文，不等待故事连续性与天赋成长两路并行后调用。
- 本轮后调用仍在进行时，页面保持清晰的收束状态。
- 已发布正文成为下一轮可引用事实。

## 最大边界

正文发布确认故事文本，不代表故事连续性与天赋成长已经完成。
