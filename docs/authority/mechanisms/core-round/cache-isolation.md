# 调用隔离与缓存

## 目标

调用隔离让不同职责的 AI 请求保持独立上下文归属，同时让同一职责的稳定前缀持续复用。

## 结果

- 主叙事、故事连续性提取和天赋成长各自拥有独立调用池。
- 同一可信主体与同一调用池形成稳定上游身份。
- 不同调用池形成不同上游身份。
- 主叙事正式调用独占主叙事池；当前运行不再启动下一轮预生成调用。
- 缓存命中影响等待和费用，不改变故事或业务结果。
- 主故事固定系统 Prompt 后依次发送稳定世界事实、追加型历史记忆与角色当前语义、白话本轮引导；追加型历史先于会变化的年龄、属性语义和天赋，保持跨轮可复用前缀。
- 连续性提取固定按历史记忆、最近两轮正文、当前回合发送三条 JSON 用户消息；天赋成长固定按历史记忆、最近两轮详细记忆、程序筛选后的玩家已选天赋发送三条 JSON 用户消息，第三条可包含成长历史、角色上下文和世界上下文。
- 标准 JSON 的双引号是格式契约的一部分；删除非结构性强调引号可以减少少量冷输入 Token，但不会单独提高缓存命中。

## 最大边界

缓存归属来自三个已登记调用职责。被删除调用不保留缓存别名、汇总归属或兼容映射；会话编号、回合编号和随机值不改变长期调用池身份。
