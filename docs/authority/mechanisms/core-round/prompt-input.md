# 主叙事输入区

## 职责边界

故事 AI 根据世界、历史、角色、时间窗口、玩家行动和本轮事件材料生成一段合理的正文；故事内容遵守已确认事实、年龄、能力与当前条件。叙事主语、视角、事件数量、场景、主线和结尾形式不由额外模板规定。故事 AI 在故事发展到合适时机时输出命运分支；只有当前人生永久失去意识、感知、决定、行动和任何新经历时才输出结局。结局不限于死亡，只要该条件未完整成立就继续生成正文或命运分支。本轮事实与方向中的环境事实、系统事件、时间尺度和短期引导由本地所属系统只读投影，故事 AI 不拥有它们的状态或生命周期。

固定服务端 Prompt 只保留故事叙事生成器的一句合理叙事目标与 `submit_story_turn` 格式/结构协议；时间、年龄、事件和其他事实由本轮动态输入承载。动态三段 JSON 的字段顺序、事实投影和本地解析边界保持不变。

称呼方式和时间范围属于正文生成的必要输入：称呼方式默认第二人称，也可按设置切换为第一人称或角色姓名；这只决定主角的称呼，不规定句子主语、叙事视角或正文结构。时间范围用于保持日期、先后和跨度合理，故事写法由合理叙事决定。自定义文风只有在设置中存在非空文本时才作为本轮可选约束；未设置时不追加文风项。它们不构成独立分析产品。

已确认状态由故事状态提取 AI 和本地所属系统共同维护。属性分析、系统分析、事件登记、剧情阶段、事实审计、状态写入和其他非故事产品不进入故事 AI 的职责；已由所属系统确认的世界事件、环境事实、因果后果和当前区域概况可以作为只读本轮输入投影，无论是否与本轮玩家行动相交，不改变故事 AI 的状态所有权。

## 固定顺序

1. 固定系统职责。
2. 包含稳定世界事实的标准 JSON 用户消息。
3. 先放历史连续性事实、再放角色当前叙事语义的标准 JSON 用户消息。
4. 包含本轮事实与方向的标准 JSON 用户消息。

三条用户消息都是可直接解析的完整 JSON 对象，不使用 `⟦世界观⟧`、`⟦历史与角色⟧`、`⟦本轮事实与方向⟧` 或其他对象外标签。第三条消息在存在已到期且仍可用的历史事项时增加可选的 `当前到期事件`，只发送时间、标题和事实，不发送候选编号、审计状态或内部状态；时间尺度/历法提示、当前区域概况、历史待续事实和独立系统事件也只能作为第三条消息内的自然语言事实投影，经过本地排序、去重和边界包装，不新增顶层协议字段。

## 世界观

稳定世界事实只包含名称与描述；本轮当前区域、环境 profile、世界事件和因果后果由本地系统在动态事实中只读投影。故事根据当前条件处理玩家行动，结果可以成功、受阻、失败、承担代价或暂留未决。空间形态、世界观本质、力量体系、力量框架、工程标识、世界标签、校准数据、历法名称和系统配置不进入 AI 输入。

## 历史记忆

历史连续性事实按时间顺序以有效 JSON 字符串数组提供故事压缩 AI 已经提炼的人物、关系、选择、行动、结果、承诺和长期变化。每项以“具体时间：同日已经成立的连续事实”表达；同日事实合并到同一字符串，不携带权重、来源 ID、层级、衰减状态或内部标记。主故事历史投影在保留旧压缩事实的同时，可以提供当前回合之前最多四轮的近期完整正文，形成五轮详细窗口；同一来源不重复发送压缩项与全文。角色信息排在连续性事实之后。故事 AI 不再接收独立的剧情阶段、伏笔系统、因果系统、最近变化或重复状态摘要来重新理解同一段历史。

## 角色当前叙事语义

角色只包含姓名、性别、种族、背景、当前年龄、五项基础属性的当前语义，以及键名为 `天赋` 的统一数组。属性语义分成 `开局自带` 与已确认进阶叠加后的 `天赋加成后` 两层；没有进阶时不重复添加第二层。天赋不区分普通命格与轮回天赋，每项只含名称和效果。固定 Prompt 在角色输入映射中说明当前年龄及 0 岁叙事边界，正文规则统一使用“天赋”称谓。等级、属性预算、词条来源、强化等级和其他机制字段保留给各自拥有判断职责的后调用，不进入故事 AI。

## 本轮事实与方向

本轮事实与方向使用自然语言字符串数组，包含当前时间或事件节点位置、玩家行动、年龄边界、称呼方式和字数要求；存在非空自定义文风时再追加原文文风项。根据当前回合已有事实，本地可以在同一数组中追加时间/历法范围、当前区域概况、历史待续事实和事件材料；这些内容只提供本轮事实和时间边界，不规定正文结构、事件数量或叙事主语。称呼方式以动态指令表达第一人称“我”、第二人称“你”或当前角色姓名自适应，默认第二人称；称呼不规定句子主语或叙事视角。字数按玩家当前运行选项表达为“约300字”一类目标值；系统事件只发送可读时间、标题和事实，不发送候选编号、审计状态、内部状态或系统分析。

## 输出边界

每次调用都输出正文。故事尚能自然继续且当前没有玩家必须决定的不同走向时，正文完成当前故事片段后结束；故事抵达需要玩家决定不同走向的时刻时，正文停在选择前并输出 2 到 4 个第二人称可执行行动；只有当前人生永久失去意识、感知、决定、行动和任何新经历时，正文完成结局叙述并输出结局。命运分支和结局在同一次响应中互斥，未使用者统一填写 `null` 四个字符。
