# 主叙事输入区

## 职责边界

故事 AI 使用指定的人生重开模拟器系统 Prompt，根据世界、玩家、剧情记忆、当前属性、当前时间和命运抉择生成下一轮人生事件。固定 Prompt 不拥有世界、角色、记忆、属性或回合状态；动态数据只由各所属系统做只读投影。

主故事不再强制工具调用或 JSON 输出。模型按固定 Prompt 返回人生重开文本：状态行、`正文`、`命运分支`、`结局`。本地解析器从同一次响应中识别可用正文以及可选分支、结局和状态行；正文存在时，不因未使用字段写成 `false`、字段标点差异或固定 Prompt 中的简写对象语法丢弃正文。

## 固定顺序

1. 服务端注入 `D:/AI/docs/系统prompt.txt` 对应的固定系统 Prompt。
2. 浏览器发送一条可由 `JSON.parse` 直接解析的用户消息。

用户消息是四元素 JSON 数组，共含五个顶层字段，顺序固定为：

1. `{ "世界": ... }`
2. `{ "玩家信息": ... }`
3. `{ "剧情": ... }`
4. `{ "玩家属性": ..., "当前信息": ... }`

数组外不添加标签、说明或第二条动态消息。

## 数据层

- `世界` 只含 `名称`、`描述`。
- `玩家信息` 只含 `姓名`、`性别`、`种族`、`背景`、`天赋技能`；天赋技能按“名称：效果”字符串数组投影。
- `剧情` 只含 `长期记忆`、`近期记忆`。长期记忆是故事连续性已经压缩的事实字符串；近期记忆是尚未转入长期投影的完整正文字符串。正常运行在达到压缩阈值后始终至少保留最近五轮完整正文，开局不足五轮时按实际已有轮次发送。
- `玩家属性` 只含 `心智`、`体魄`、`魅力`、`家境`，值均为整数字符串。前三项来自角色所有者当前数值的只读投影；项目没有家境状态所有者，因此 `家境` 固定投影为字符串 `0`，不新增持久字段。
- `当前信息` 只含 `时间`、`命运抉择`。时间同时表达当前年龄和当前历法标签；命运抉择先写本轮玩家已确认行动，没有明确行动时使用自然推进语义，再在同一字符串中附加本轮系统引导、时间参考、已确认世界事实、一次性事件库候选和到期事项，不增加样例外字段。

示例中的具体世界、角色、历史和选择只说明字段形状，不进入固定 Prompt，也不写入运行状态。

## 记忆边界

故事连续性调用一次处理连续五轮完整正文。近期正文超过十轮且到达五轮调用间隔时，最早五轮形成长期记忆投影；原始正文仍完整保存，失败时不删除来源正文。主故事只消费当前长期记忆投影与仍处于近期窗口的完整正文，不接收重复的阶段、伏笔、因果或分析副本。

## 输出边界

每次主故事调用必须提供可用正文。命运分支与结局互斥：未触发者使用 `false`；分支使用三个字符串选项，结局使用四字评语。状态行中的心智、体魄和魅力是 AI 报告的本轮结果值，本地只把能够相对当前角色数值换算且符合单轮变化范围的差值交给 `character-base` 校验、钳制和持久化；年龄、家境和冷却不建立新的 AI 状态所有权。

## 最大边界

主故事只拥有玩家可见正文、可选命运分支、可选结局和本轮属性结果声明，不拥有状态写入。页面消费解析后的公开结果，不自行解析 AI 原文。属性、年龄、历史、未来事件和记忆压缩仍由原所属系统管理。
