# 主叙事输入区

## 职责边界

故事 AI 接收服务端由受保护主叙事资产 `src/mods/mod-engine/server/narrative-system-prompt.ts` 组装的一条 `user` 消息。每次请求都是独立调用，被调用模型看不到存档、既往请求、程序状态或消息之外的全局信息；完成本轮生成所需的事实和职责必须由这条消息自足表达。固定规则由该服务端资产维护；世界、玩家、历史输出、属性和本次信息由动态数据层只读投影。

主故事不强制工具调用，模型返回最小 JSON 对象：`正文`、`属性`、`命运分支`、`结局`、`角色死亡`，并可选 `事件卡消费`、`天赋表现线索`。本地解析器逐项识别正文、财富等属性当前值、可选分支、死亡结局、事件卡消费和天赋表现线索；玩家可见内容仍只消费正文、分支、属性和结局。事件卡消费只用于本地扣卡；天赋表现线索的来源回合由引擎按本轮记录，不由模型输出。

主故事模型的身份是人生模拟器。每轮覆盖当前时间步长，模型在此跨度内自主安排节奏、转折和经历数量；事件卡池（只投影 2–8 字卡名）是软素材，不限定主题或必用数量。正文应让玩家进入人物处境，通过行动、阻力、关系和选择体验变化，不写成因果报告、提纲、规则解释或事件清单。故事可以发生在宏观局势、家庭、友情、成长、工作或平静日常中，不要求每轮出现社会结构变化或戏剧性转折。玩家的计划和输入是 Attempt，必须得到自然回应，但不预设成功。难度仅通过隐藏命运指引和事件卡相对权重影响倾向，不写成角色属性或世界中实际存在的力量。面对非标准世界观，模型依据世界名称、描述和世界状态摘要恢复规则、资源边界、制度、因果、例外、限制和未知；陌生表达不套用现实默认规则，未知内容不擅自登记为既定事实。新创作置于本轮模拟跨度内，不得倒填成既往事实。玩家始终是故事的主角；家庭成员可以是有自身目标的重要人物，但其经历须通过玩家的具体互动或影响进入主线。

## 固定顺序

浏览器只向受保护代理提交动态数据数组；服务端读取主故事固定资产并生成唯一模型消息，不把固定规则发送到浏览器。模型实际接收的一条 `user` 消息按“角色、输入、写法、输出”四段固定规则后接五段只读数据组装。数据不是指令、范文或必须续写的题目。

模型在同一次调用内读取世界、历史、玩家条件和当前年龄；依据世界边界、人物关系、玩家意图与开放可能性，写出这一段时间里真正发生在角色身上的经历。世界规则和既定事实划定边界，已确认意图得到自然回应但不保证成功；正文、分支、结局和属性在同一份 JSON 中返回。

主故事仍只发送一条 `user` 消息；其他 AI 调用保持原消息角色。固定规则与动态数据集中分离，动态数据之后不再追加规则或示例。宽松篇幅偏好不把完整经历压成动作片段；合法返回、事实相容、玩家选择和正文表达要求同时成立。

## Prompt 区块

固定主故事资产按职责分区，顺序固定为：

1. `# 角色`：人生模拟器、角色中心、世界是条件而非任务清单。
2. `# 输入`：世界、玩家、历史、本次行动是已有条件；历史只承接人物、关系、资源和未解决方向；玩家行动是尝试；未知不补；时间节点只用于合龄判断；自然寿命参考年龄只是背景。
3. `# 写法`：按篇幅偏好、叙事称呼和文风偏好表达；写这一段时间里真正发生的事；允许概括、跳跃、留白；正文像人生小说的一章，不是因果报告。
4. `# 输出`：最小 JSON、字段说明和批量边界。

主故事资产不携带故事示例矩阵，也不设置默认字数、事件数量、重大变化、阶段推进或宏观编年配额。日、月、季、一年或更长跨度都由模型按角色处境自然安排节奏；需要压缩跨度时用转场和留白，不逐日列清单，也不把单一现场强行扩写成整年。

## 数据层

- `本次信息`可提供`自然寿命参考年龄`、`叙事称呼`、`文风偏好`和`控制平面`（含`出生背景`、`人生规划`、`事件卡池`、`命运转折调性`、`难度指引`、`到期世界事实`）。`人生规划`至少含`阶段标识`、`当前阶段`和`阶段目标`，可含`下一阶段入口`；列表字段接受字符串或对象，由程序把对象键值展开为可读文本。出生背景中的`介入前史`描述从出生后到玩家起始年龄的既往人生，角色背景明确写出的事实优先；自然寿命参考年龄只是衰老背景，不是自动死亡线。`叙事称呼`由程序解析成自然语言称呼指令，`文风偏好`只影响语言质感，二者都不覆盖世界、事实、因果和返回协议。
- 固定规则由 `src/mods/mod-engine/server/narrative-system-prompt.ts` 中的受保护资产维护；浏览器只发送动态数据，不持有主故事规则文本。
- `世界`只含 `名称`、`描述`；`描述`由世界基础描述与已有世界子系统的只读状态摘要合成，摘要用于恢复当前世界形态，不是本轮题目或第二状态源。非标准描述也必须在本次主故事调用内完成规则恢复：先识别明确的存在方式、力量与资源边界、制度与关系、因果机制、例外、限制和未知，再据此形成玩家与世界交互；不能因为表达陌生就套用现实规则，也不能把未知内容补成事实。
- `玩家信息`只含 `姓名`、`性别`、`种族`、`背景`、`属性尺度`、`当前属性语义`、`天赋技能`；`属性尺度`是固定尺度的只读提示，`当前属性语义`由角色基础属性所有者投影，模型不能修改；`天赋技能`中的每项带有本轮稳定的不透明引用、名称和效果，模型只能在 `天赋表现线索` 中引用该值，不接收持久化 `lineageId`。
- `历史输出`只含 `事件`，包括更早事实和近期已提交记录。未压缩轮次按发生年龄索引投影，发生年龄读取对应历史记录的年龄快照，不添加结算标签；投影内容是该轮完整正文，不再拆分或优先投影结构化事件结果。已压缩轮次沿用记忆所有者的事实投影。历史只用于事实相容、来源归属和已发生事项的辨认，不负责选择主题，也不是待续写正文或文风范本；原始完整正文仍由历史所有者保存并供后续调用使用。
- `玩家本次点属性`只含 `心智`、`体魄`、`魅力`、`财富`，属性来自角色基础属性所有者的当前值。
- `本次信息`含 `时间节点`、`时间窗口`、`自然寿命参考年龄`（可选）、`批量输出`（可选）、`命运分支`、`篇幅偏好`、`叙事称呼`、`文风偏好`和`控制平面`（可选）；`时间节点`的值明确包含当前年龄和内部阶段索引，当前年龄只用于人物处境与能力判断，时间节点其余内容只用于事实顺序和发展范围。时间窗口只提供本轮范围、事实顺序和生成边界，不提供已经形成的状态差事实，也不规定题材或必须出现外部变化。正文与返回字段不得机械复述索引，只有因果不可替代时才保留自然的日期、季节或相对时距。命运分支非空时表示玩家已经确定的方向。没有玩家确认行动时命运分支为空字符串。`叙事称呼`由程序解析为自然语言指令；`文风偏好`为空时按固定文风。篇幅偏好是正文长度参考，不是精确截断线。批量输出开启时，单次最多返回 10 轮；调用时限随目标轮数放大，传输截断时只回收完整前项。

示例中的具体世界、角色、历史和选择只说明字段形状，不进入固定 Prompt，也不写入运行状态。

## 随机故事生成边界

事件卡只投影卡池名称数组：可用卡名进入`控制平面.事件卡池`，每项只是一个 2–8 字的抽象事件名，不带其他字段。正负、权重与来源指纹只用于本地校验与持久化，不进入主故事数据层。卡池不做年龄过滤，同阶段整池可用。卡不保证发生，也不构成成功概率、事件数量或题材要求；主故事可以整轮、整批都不消费。主故事若在本轮采用了某张卡并写进正文，必须在 `事件卡消费` 中列出该卡名；引擎只扣这些卡，未消费卡留在池中供后续轮次或后续批次判断。未在池中的卡名无效，不扣卡也不采纳。整轮不消费时允许平静推进；本轮仍须留下至少一个新的、真实成立且可观察的关系、资源、能力、身份、位置或生活状态，不要求属性增长、成就或危机。年龄只用于事实顺序与人物处境判断，不额外规定故事内容的年龄清单。

每次调用先读取世界、玩家、历史、属性和本次条件，把时间窗口当作本轮范围；模型依据世界规则、世界状态摘要、历史事实和玩家条件写出新的经历。世界各方的自主行动、个人生活和偶然相遇均可发起事件；只有与玩家形成真实交互、体验、关系或持续后果的部分才进入本轮人生主线。家庭成员的就业、搬迁、收入和手续只有在玩家亲历、参与或受到具体影响时才作为故事内容；不能用家庭状况报告替代玩家经历。即使玩家处于依赖阶段，也要通过符合年龄的感知、移动、游戏、依恋、恐惧、社交、观察或选择进入事件因果。

离散化保持现实状态连续，不继承必须继续讲述的题目。既有身份和生活处境决定事情能否成立、如何参与，不要求本轮继续围绕该处境出题。新经历的差别体现为人物关系、选择、练习、发现、日常难题和外部局势的变化，不以表面设定变化重复已经讲过的同一问题与应对过程。多项各自有结果的新事可以并置，也可以由一段关系或一次选择贯穿；玩家、天赋、属性与行动改变参与方式、所得和代价。旧人物、关系和后果在与本轮事件有关时参与，不要求换人换地；宏观变化按自身作用范围成立，不要求每轮出现或取代玩家身边的人物故事。

历史保持事实连续，不继承上一轮主题。世界明确规则优先于与之冲突的旧生成叙述；旧叙述不能自行构成规则突破，本轮有已成立因果改变规则时除外。已有来源、归属、关系、身份和明确结果持续有效，除非本轮新的因果真正改变它们；已完成事件只作为事实条件，不得把自然后果或同一行动链下一步重新当成新事。已成立结果和余波成为后续条件，不预先指定下一轮必须继续讲述的事情。

正文写成能让读者进入其中的人生小说，而非事项报告。可以从正在发生的动作、现场问题、人物声音、异常细节或具体选择切入；让因果通过人物目标与顾虑、行动、阻碍、回应和结果显现。关系变化落在人物说了什么、做了什么、避开了什么或愿意承担什么上，不用抽象结论代替过程。自然使用符合人物关系、年龄和世界条件的对白、停顿、动作反应和感官细节；对白可以表达已成立的意图、分歧或情绪，但不得另造会改变剧情走向的重大事实。细节从玩家当下能感知的范围中选择，具体而克制，不为装饰而堆叠。

不必每轮都有危机、社会变局或戏剧性转折；平静生活中的练习、误会、发现、竞争、关系或责任，只要真实改变玩家的理解、选择、关系或处境，也能成为本轮故事。家庭成员的工作、收入、搬迁和手续只有在玩家亲历、参与或受到具体影响时才进入主线，避免写成家庭状况报告。玩家始终是故事主角；其行动和认知符合年龄与能力，即使处于依赖阶段，也要以符合年龄的感知、移动、游戏、依恋、恐惧、观察或选择进入事件。

正文称呼按程序解析后的 `本次信息.叙事称呼` 执行：第二人称使用“你/你的”，第一人称使用“我/我的”，角色姓名使用玩家姓名；缺失按第二人称。`本次信息.文风偏好` 只影响句式、节奏、意象和措辞，不覆盖世界规则、已成立事实、因果和返回协议；为空时按固定文风。年龄和时间索引只用于人物处境与事实顺序，不机械复述成正文标题、开头或分段骨架；符合本轮因果的昼夜、季节和相对时距可以自然出现。外部事实不自动成为玩家知识。正文应有可理解的落点，但不强制道德总结、转折或悬念钩子。篇幅偏好是宽松参考；在合理范围内优先保留能让人物行动与结果成立的场景，不为压字数把剧情改写成摘要。命运分支非空时落实已选方向。交付前核对玩家经历、因果、事实相容与人物处境，再检查表达和协议。

## 记忆边界

历史条目已有非空已确认选择时，只补充该选择，不再标为未决分支或附上未选候选；尚未选择的分支保持未决信息。此处只改变派生输入，原始正文、分支候选、选择记录和存档保持不变。

故事连续性调用仍一次处理连续五轮完整正文，原始正文继续完整保存，失败时不删除来源正文。主故事的 `历史输出.事件`保留更早事实与近期记录，并以各自发生年龄标明事实归属；近期记录直接投影完整正文，不增加第二状态源或额外提取调用。历史年龄、日期和阶段只用于事实归属与顺序；正文可以自然表现人物确实经历的时间流逝，不以输入坐标机械组织开头、转场或分段。历史结果约束事实相容与来源归属，不规定本轮题材、段落或场景。

## 输出边界

主故事不输出自然寿命变化；自然寿命参考年龄只作背景。`角色死亡`为 `false` 或 `{死因类型, 死因}`；明确死亡必须同时有结局且没有命运分支，只有该字段能启动角色死亡状态和正式历史绑定。普通结局不推断为死亡。

每次主故事调用必须提供可用正文，并遵循 `本次信息.篇幅偏好`表达玩家选择的宽松正文篇幅目标，不把该目标用作整个返回对象的长度。`属性`只写本轮发生持续变化的项，填结算后的当前值，未变化项可省略。`事件卡消费`为可选字符串数组，只列本轮实际采用并写入正文的卡名；引擎按名扣卡，未消费卡留在池中。`天赋表现线索`为可选数组，每项只含不透明天赋引用和 `可观察结果`；来源回合由引擎按本轮记录，不由模型输出；只在玩家实际使用并留下结果时返回，不返回进阶结论、成长路线或属性加成。`命运分支`非空时为 2 至 4 个字符串；`结局`为恰好四个汉字。应用只消费正文、分支、属性和结局，事件卡消费和天赋表现线索不直接进入界面，原始响应日志完整保留。正文可以补足可信且不改变重要结果的现场动作、对白、人物反应与感受，使因果成为可阅读的场景。命运分支承接本轮已形成局面，不用未写完的动作替代完整记录；人生未结束且自然形成新选择时提供选项，否则为 false。正文、属性、命运分支、结局、角色死亡和可选线索必须由同一次主故事调用产生，不得以后续调用补写世界变化或重做正文。

## 最大边界

主故事拥有玩家可见正文、可选命运分支、可选结局、角色死亡和本轮属性结果声明；属性、年龄、历史、未来事件和记忆压缩仍由原所属系统管理。主故事不再提供结构化事件结果，也不成为额外世界状态所有者。
