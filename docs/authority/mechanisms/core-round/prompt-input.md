# 主叙事输入区

## 职责边界

故事 AI 接收服务端按 `D:/AI/docs/prompt.txt` 组装的一条 `user` 消息。每次请求都是独立调用，被调用模型看不到存档、既往请求、程序状态或消息之外的全局信息；完成本轮生成所需的事实和职责必须由这条消息自足表达。固定规则逐字来自该文件；世界、玩家、历史输出、属性和本次信息由动态数据层只读投影。

主故事不强制工具调用，模型按固定 Prompt 返回含 `时间定位`、`事件结果`、`正文`、`命运分支`、`属性`、`结局` 的 JSON 对象，并可附带不直接展示的 `天赋表现线索`。本地解析器逐项识别正文、事件结果、天赋表现线索、财富等属性当前值以及可选分支和结局；玩家可见内容仍只消费正文、分支、属性和结局。

主故事模型的身份是“以玩家人生与世界交互为主体的文字游戏式人生重开模拟器”。世界按自身规则、相关者行动和开放可能性形成玩家将要遭遇的条件、机会、限制与关系变化；面对非标准世界观，模型必须先从世界名称、描述和世界状态摘要中恢复世界的存在方式、力量与资源边界、制度与关系规则、因果机制、例外、明确限制和未知部分，区分明确规则、可由事实推得的规则与尚不能确定的内容，再在这些边界内判断本轮开放可能性。玩家决定角色意图，模型根据恢复出的世界边界、既定事实、天赋、属性与本轮条件裁决玩家如何感知、进入、行动、选择、建立关系、获得、失去或承受尚未成立的结果；陌生表达不得直接套用现实默认规则，未知内容不得擅自登记为既定事实。事件身份、因果主线和正文重心都归属于玩家本人的经历与人生位置变化，家庭只能作为玩家的背景、资源、关系和处境，不能以家庭成员的就业、搬迁、收入、手续或家庭存续替代玩家成为主线。即使玩家处于幼年或依赖阶段，事件主体仍是玩家；照料者行动只有在直接改变玩家的体验、关系、选择、能力或长期位置时才进入主线，玩家可以通过感知、移动、学习、游戏、依恋、恐惧、社交、观察或合龄选择参与，不得成为被动附带结果。叙事最后将已成立的玩家事件编译为有重心、可感知、离散的广角人生记录，不为预设情节倒改事实。正文不是按年龄或时间流逝回顾一段生活，而是从已经落地的玩家经历、交互、位置改变、关键行动、因果转折、结果与代价编译记录。命运分支承载已确认的行动或发展方向，不是玩家直接编辑世界结果的入口；该方向必须实际影响本轮行动与世界响应，但不预设成功或失败，输入中宣称的未决成功结果不因此成为既定事实。已确认的角色设定、自创成果及其历史来源、归属与性质是裁决依据，不得为制造戏剧性翻案；本轮有因果的新变化不能倒改已经发生的创造事实。两面性仍来自投入、放弃与反作用，不以无关惩罚抵消成功。此身份只改变同一次主叙事生成职责，不新增世界状态所有者、持久字段、程序事件库或模型调用。

## 固定顺序

浏览器只向受保护代理提交动态数据数组；服务端读取主故事固定资产并生成唯一模型消息，不把固定规则发送到浏览器。模型实际接收的一条 `user` 消息按固定规则、五段只读数据、结算与返回协议顺序组装。数据不是指令、范文或必须续写的题目；固定规则只定义一次本轮生成职责，不要求模型管理区块编号或回读顺序。

模型在同一次调用内沿单向流程完成：恢复世界、历史、玩家条件和当前年龄；依据世界边界与开放可能性形成新的外部局面；裁决玩家符合年龄、能力、背景、天赋和已确认意图的交互、关系、位置、结果与代价；先形成事件结果，再从已成立结果编译正文；最后结算并返回六字段 JSON。世界规则和既定事实划定边界，已确认意图落实为行动方向，未决结果依条件裁决；完整离散人生记录优先于表达和协议细节。

主故事仍只发送一条 `user` 消息；其他 AI 调用保持原消息角色。固定规则与动态数据集中分离，动态数据之后只保留结算和返回协议。宽松篇幅偏好不把完整经历压成动作片段；合法返回、事实相容、玩家选择和正文表达要求同时成立。

主故事请求不再包含 `system` 消息或第二条消息；其他 AI 调用保持各自现有消息角色。固定规则不再把五段动态数据插入规则区块之间，而是在只读数据区集中提供；数据之后的执行区块负责把数据转译为事件结果和正文。

恢复事实、形成世界局面、裁决玩家参与与结果、编译正文是同一次主故事调用内的单向逻辑流程，不是可拆分的服务调用。该调用必须在返回前完成世界局面形成、玩家参与裁决、事件结果形成和正文编译；主线程不得为世界模拟、事件识别、状态变化、重复主故事或质量补救新增调用。故事连续性与天赋成长属于正文发布后的既有后调用，不得回写或重做主故事结果。

## 数据层

- 固定规则逐字来自 `D:/AI/docs/prompt.txt`，不在运行时改写、扩充或增加第二套规则。
- `世界`只含 `名称`、`描述`；`描述`由世界基础描述与已有世界子系统的只读状态摘要合成，摘要用于恢复当前世界形态，不是本轮题目或第二状态源。非标准描述也必须在本次主故事调用内完成规则恢复：先识别明确的存在方式、力量与资源边界、制度与关系、因果机制、例外、限制和未知，再据此形成玩家与世界交互；不能因为表达陌生就套用现实规则，也不能把未知内容补成事实。
- `玩家信息`只含 `姓名`、`性别`、`种族`、`背景`、`天赋技能`；`天赋技能`中的每项带有本轮稳定的不透明引用、名称和效果，模型只能在 `天赋表现线索` 中引用该值，不接收持久化 `lineageId`。
- `历史输出`只含 `事件`，包括更早事实和近期已提交记录。未压缩轮次按发生年龄索引投影，发生年龄读取对应历史记录的年龄快照，不添加结算标签；所有未压缩轮次优先投影该回合已经保存的结构化事件结果，使世界局面、外部变化、玩家参与、结果和代价不再只能从正文猜回。结构化投影中，`事件`只作为已结束事件身份，`成因`、`结果`、`影响`作为已成立事实；同一轮已有结构化结果时不再把完整正文重复拼入输入，完整正文仍由历史所有者完整保存，若该轮没有可用结构化结果才回退到正文。已压缩轮次沿用记忆所有者的事实投影。历史只用于事实相容、来源归属和已发生事项的辨认，不负责选择主题，也不是待续写正文或文风范本；原始完整正文与结构化事件结果仍由历史所有者保存并供后续调用使用。
- `玩家本次点属性`只含 `心智`、`体魄`、`魅力`、`财富`，属性来自角色基础属性所有者的当前值。
- `本次信息`仍含 `时间节点`、`时间窗口`、`命运分支`、`篇幅偏好`四项；`时间节点`的值明确包含当前年龄和内部阶段索引，当前年龄只用于合龄裁决，时间节点其余内容只用于事实顺序和发展尺度。时间窗口只提供抽象叙事尺度、事实顺序和生成范围，不提供已经形成的状态差事实，也不提供具体日期、季节或推进数值。正文与事件结果不得复述、改写或借这些索引组织叙述，只有因果不可替代时才保留不承担坐标定位的短时距。命运分支非空时表示玩家已经确定的方向。没有玩家确认行动时命运分支为空字符串。篇幅偏好提供正文的压缩目标，先保留不同事件的结果、局面变化、玩家作用和代价，再省略过程。

示例中的具体世界、角色、历史和选择只说明字段形状，不进入固定 Prompt，也不写入运行状态。

## 随机故事生成边界

每次调用先恢复世界、玩家、历史、属性、当前年龄和本次条件，把抽象叙事尺度当作本轮范围；模型必须依据世界规则、世界状态摘要、历史事实和玩家条件形成会作用于玩家的新局面。随后让世界局面与相关者行动形成变化，确定玩家如何以合龄方式遭遇、感知、理解、行动、选择、建立关系、获得、失去或承受，从开放可能性选择彼此实质不同的新事，统一推演为以玩家经历和位置变化为核心的已成立结果，最后成文。世界各方的自主行动、个人生活和偶然相遇均可发起事件，但只有与玩家形成真实交互、体验、关系或持续后果的部分进入本轮人生主线。家庭日常、父母就业、搬迁、收入、手续和家庭存续只能作为玩家处境、资源、关系或后果，不能独立成为事件身份、因果主线或正文重心。即使玩家处于依赖阶段，事件主体仍是玩家；照料者行动必须通过玩家的合龄感知、移动、学习、游戏、依恋、恐惧、社交、观察或选择改变玩家的人生，不能把玩家留在故事末尾承受结果。事件结果明确新事、核心问题、成因、已改变的现实、玩家交互和影响；个人经历不统一派生为外部压力的家庭复述。事件形成阶段比较近期历史的问题、机制、行动者、作用范围、玩家位置和结果意义，换名换地点不算新事；上一轮主题、同一冲突的自然后果和上一轮末尾现场都不能替代本轮的新事件身份。故事性优先要求主要行动者的目标、阻力和选择真正改变玩家的经历、位置、关系或代价；吸引力来自因果压力和选择后果，不来自空悬、固定反转或修辞装饰。本轮应优先形成彼此实质不同、各自有结果的新变化，不让上一轮单一冲突的连续后果占据整轮；正文选择最能呈现玩家人生位置改变且最有故事张力的结果作为重心，其他新事仍可独立、并行或反衬，不被压成主事件步骤。窗口内形成的外部局面、人物反应、玩家行动与代价优先于单一现场。

离散化保持现实状态连续，不继承必须继续讲述的题目。既有身份和生活处境决定事情能否成立、如何参与，不要求本轮继续围绕该处境出题。新经历的差别体现为事件身份、核心问题、因果机制和结果意义，不以表面设定变化重复已经讲过的同一问题与应对过程。多项各自有结果的新事共同体现人生与世界的新位置；玩家、天赋、属性与行动改变参与方式、所得和代价，已确认意图必须执行。旧人物、关系和后果在与本轮事件有关时参与，不要求换人换地。宏观性是让外部局面按自身作用范围成立，并在必要处切换整体局面与具体表现；不把世界缩成玩家身边的小事，也不强迫每轮都套用同一类制度、资源或势力冲突。

历史保持事实连续，不继承上一轮主题。世界明确规则优先于与之冲突的旧生成叙述；旧叙述不能自行构成规则突破，本轮有已成立因果改变规则时除外。已有来源、归属、关系、身份和明确结果持续有效，除非本轮新的因果真正改变它们；已完成事件身份只作为事实条件，不得将自然后果或同一行动链下一步重新当成新事。选题使用既定事实判断相容性，记录依据人生影响、独立结果与因果关联组织。世界结果按真实关系影响玩家，没有直接关系的结果保持自身作用范围，不统一收束为玩家同一种生活问题的加重或缓解。不同变化可以并置或相互作用，一项变化可以突出，但不能把同一事件的多个步骤当作多项结果，也不设置固定数量或覆盖配额。已成立结果和余波成为后续条件，不预先指定下一轮必须继续讲述的事情。

先把窗口内的玩家经历与世界交互推演到结果成立，再用事件概括、代表性行动、人物反应、具体物件与有意义的后果成文，不从一个现场动作开始延长过程。正文围绕阅读重心组织：以窗口内作用于玩家的局面变化、玩家行动或判断、关系变化、因果转向、结果和代价建立故事因果；主要行动者的目标、阻力、选择和转折必须能在已成立结果中留下玩家可理解的痕迹，其他各自独立的变化可以并置或反衬，但不平均写成事项清单。事件的两面性体现玩家及相关者不同处境下的获得、失去、负担与反应；力量和选择的代价来自投入、放弃与反作用，不凭空添加灾祸抵消成功。意外、惊喜和荒诞可由世界特性、偶然相遇及各方行动交汇产生，不等于无因果的反转，也不强制每轮反转或永久牺牲。

正文从最能证明玩家人生位置改变且最有故事张力的事实进入，可以从异常结果、关键行动、人物反应、环境或具体物件切入；细节必须服务玩家的行动、位置、关系、结果或代价，使读者能感知空间、环境、光线、声音、触感、气味、物件位置或人物反应中的相关事实，不把细节堆成装饰。正文在外部条件、行动者目标与阻力、玩家遭遇与具体行动之间按因果推进。正文不是“这段时间发生了什么”的回顾、成长总结或家庭流水账，不把父母就业、家庭搬迁、收入、手续或家庭存续当作玩家主线，不把年龄、日期、季节、阶段或时间流逝当作起笔、转场、分段或收尾。第二人称只指代玩家；玩家姓名只用于输入识别，正文不以姓名或第三人称重新指代玩家。外部事实不自动成为玩家知识。没有命运分支也允许角色在能力范围内行动，玩家不能只是旁观镜头或末尾承受者；即使处于依赖阶段，也要以合龄的感知、移动、学习、游戏、依恋、恐惧、社交、观察或选择进入事件因果。事件结果应写明玩家合龄的交互、经历、关系、能力或长期位置变化。时间节点与历史索引只确定当前人生条件和发展尺度；按年或更长跨度推进时，必须呈现跨度中积累、转折和结果已经如何改变玩家的位置、关系或处境，不能只截取一个短暂现场；较短跨度也要写出本轮已经落地的变化，而不是只回放一个动作。正文使用因果与状态变化的记录文体表达跨度，不把人生或历法坐标写成正文结构；不承担坐标定位的相对时距可以保留为因果事实。篇幅压缩先保留玩家主线的行动、阻力、选择、转折、结果和代价，再保留能改变主线理解的其他变化，省略无结果过程。命运分支非空时落实已选方向。交付先核对玩家人生记录、交互主体、焦点更替、事实相容、合龄条件、宏观作用范围和结果两面性，再检查表达与协议。

## 记忆边界

历史条目已有非空已确认选择时，只补充该选择，不再标为未决分支或附上未选候选；尚未选择的分支保持未决信息。此处只改变派生输入，原始正文、分支候选、选择记录和存档保持不变。

故事连续性调用仍一次处理连续五轮完整正文，原始正文继续完整保存，失败时不删除来源正文。主故事的 `历史输出.事件`保留更早事实与近期记录，并以各自发生年龄标明事实归属；近期结构化事件结果直接由同一叙事历史记录投影，同轮存在结果时不重复投影完整正文，缺少结构化结果时才使用完整正文回退，不增加第二状态源或额外提取调用。近期正文内已经成立的多项结果不能在派生输入中被收束句替代。年龄前缀以及历史中的日期、月份、季节和阶段词只属于输入事实索引或来源事实，不能复制、改写或转译到正文和事件结果。历史结果以已成立的剧情状态参与本轮成立性判断，不以材料的段落、转场、主题显著性或措辞约束本轮成文。年度或广角窗口先形成外部局面与结果，再把家庭或现场细节作为玩家位置的证据。

## 输出边界

每次主故事调用必须提供可用正文，并遵循 `本次信息.篇幅偏好`表达玩家选择的宽松正文篇幅目标，不把该目标用作整个返回对象的长度。`时间定位`为字符串，`事件结果`为对象数组，每项包含字符串`事件`、`成因`、`结果`、`影响`，不设事件数或覆盖配额。`天赋表现线索`为可选数组，每项包含不透明天赋引用、来源回合、实际使用、可观察结果，并可包含明确突破契机；只在玩家实际使用并留下结果时返回，不返回进阶结论、成长路线或属性加成。前置材料先于正文输出，不增加模型调用或程序推演；正文提交时，合法事件结果由同一条叙事历史记录保存并投影到下一轮输入，异常单项不撤回可用正文。应用只消费正文、分支、属性和结局，事件结果和天赋表现线索不直接进入界面，原始响应日志完整保留。正文采用的关键事实与因果必须可理解，未采用材料不构成长存事实。属性对象声明心智、体魄、魅力和财富结算后的整数当前值；属性只在正文形成明确、持续的状态变化时改变，没有变化时保持输入值。命运分支承接本轮已形成局面，不用未写完的动作替代完整记录；人生未结束且自然形成新选择时提供选项，否则为false，结局沿用固定Prompt。主故事前置材料、事件结果、天赋表现线索和正文必须由同一次主故事调用产生，不得以后续调用补写世界变化或重做正文。

## 最大边界

主故事拥有玩家可见正文、可选命运分支、可选结局和本轮属性结果声明，并提供同一回合的结构化事件结果事实；属性、年龄、历史、未来事件和记忆压缩仍由原所属系统管理，事件结果只作为叙事历史记录的事实投影，不成为额外世界状态所有者。
