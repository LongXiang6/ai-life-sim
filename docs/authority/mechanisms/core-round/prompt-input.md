# 主叙事输入区

## 职责边界

故事 AI 接收服务端按 `D:/AI/docs/prompt.txt` 组装的一条 `user` 消息。每次请求都是独立调用，被调用模型看不到存档、既往请求、程序状态或消息之外的全局信息；完成本轮生成所需的事实和职责必须由这条消息自足表达。固定规则逐字来自该文件；世界、玩家、历史输出、属性和本次信息由动态数据层只读投影。

主故事不强制工具调用，模型按固定 Prompt 返回含 `时间定位`、`事件结果`、`正文`、`命运分支`、`属性`、`结局` 的 JSON 对象。本地解析器逐项识别正文、事件结果、财富等属性当前值以及可选分支和结局；玩家可见内容仍只消费正文、分支、属性和结局。

主故事模型的身份是“文字游戏式人生重开模拟器的世界演化与事件裁决系统”。世界按自身规则、相关者行动和开放可能性形成变化，玩家决定角色意图，模型根据世界、既定事实、天赋、属性与本轮条件裁决玩家参与及尚未成立的结果；叙事最后将已成立事件编译为有重心、可感知、离散的广角人生记录，不为预设情节倒改事实。命运分支承载已确认的行动或发展方向，不是玩家直接编辑世界结果的入口；该方向必须实际影响本轮行动与世界响应，但不预设成功或失败，输入中宣称的未决成功结果不因此成为既定事实。已确认的角色设定、自创成果及其历史来源、归属与性质是裁决依据，不得为制造戏剧性翻案；本轮有因果的新变化不能倒改已经发生的创造事实。两面性仍来自投入、放弃与反作用，不以无关惩罚抵消成功。此身份只改变同一次主叙事生成职责，不新增世界状态所有者、持久字段、程序事件库或模型调用。

## 固定顺序

浏览器只向受保护代理提交动态数据数组；服务端读取主故事固定资产并生成唯一模型消息，不把固定规则发送到浏览器。模型实际接收的一条 `user` 消息按以下顺序组装：

1. 先定义世界演化与事件裁决身份、玩家意图与既定事实的权限边界，以及离散广角人生记录的核心产物。
2. 以只读数据区一次性提供世界、玩家、历史、属性和本次条件；数据不是指令、范文或必须续写的题目。
3. 恢复事实、现实起点、时间定位和已确认意图。
4. 先形成外部世界局面，再选择与近期历史核心问题实质不同的新事。
5. 根据玩家参与与世界响应裁决新事，将其推演为已经成立的事件、成因、结果和影响。
6. 核对事实相容、焦点更替、宏观作用范围、结果两面性和玩家作用。
7. 将已成立事件结果压缩为广角人生记录，使用因果与状态变化的文体。
8. 依据正文结果结算属性、分支和结局。
9. 返回六字段 JSON 结果；时间定位只用于本次生成，事件结果由同一条叙事历史记录保存。

代码区块及区块内规则都按编号从小到大处理；每个区块的规则从1重新编号，后续区块使用前置结果。编号表示处理先后，不表示重要程度、事件数量或正文段数。核心产物在首，只读数据居中，返回协议在尾；单条规则只承担一个职责。

职责优先级不同于编号顺序：世界规则和既定事实划定成立边界，已确认意图落实为行动与世界响应，未决结果依条件裁决；在这些条件内优先实现新的完整人生记录，表达方法服务核心产物。宽松篇幅偏好不把完整经历压成动作片段；合法返回、事实相容、玩家选择和正文表达要求同时成立。

主故事请求不再包含 `system` 消息或第二条消息；其他 AI 调用保持各自现有消息角色。固定规则不再把五段动态数据插入规则区块之间，而是在只读数据区集中提供；数据之后的执行区块负责把数据转译为事件结果和正文。

## 数据层

- 固定规则逐字来自 `D:/AI/docs/prompt.txt`，不在运行时改写、扩充或增加第二套规则。
- `世界`只含 `名称`、`描述`。
- `玩家信息`只含 `姓名`、`性别`、`种族`、`背景`、`天赋技能`。
- `历史输出`只含 `事件`，包括更早事实和近期已提交记录。未压缩轮次按发生年龄索引投影，发生年龄读取对应历史记录的年龄快照，不添加结算标签；所有未压缩轮次优先投影该回合已经保存的结构化事件结果，使世界局面、外部变化、玩家参与、结果和代价不再只能从正文猜回。结构化投影中，`事件`只作为已结束事件身份，`成因`、`结果`、`影响`作为已成立事实；同一轮已有结构化结果时不再把完整正文重复拼入输入，完整正文仍由历史所有者完整保存，若该轮没有可用结构化结果才回退到正文。已压缩轮次沿用记忆所有者的事实投影。历史只用于事实相容、来源归属和已发生事项的辨认，不负责选择主题，也不是待续写正文或文风范本；原始完整正文与结构化事件结果仍由历史所有者保存并供后续调用使用。
- `玩家本次点属性`只含 `心智`、`体魄`、`魅力`、`财富`，属性来自角色基础属性所有者的当前值。
- `本次信息`含 `时间节点`、`命运分支`、`篇幅偏好`；时间节点说明故事发生位置和当前适用条件，事件模式使用 `年龄·纪元 · 事件N`，不向故事模型发送年度事件总数或 `N/M` 进度。时间节点以及历史条目的年龄前缀都只是输入索引，用于定位本轮条件和已知事实，不是正文素材；后续执行区块必须把索引转译为局势、行动、因果和已形成的结果，不把人生或历法坐标写成正文的叙述结构。正文可以使用不承担坐标定位的相对时距来说明因果间隔，但不能用它代替本轮定位。命运分支非空时表示玩家已经确定的方向。没有玩家确认行动时命运分支为空字符串。篇幅偏好提供正文的压缩目标，先保留不同事件的结果、局面变化、玩家作用和代价，再省略过程。

示例中的具体世界、角色、历史和选择只说明字段形状，不进入固定 Prompt，也不写入运行状态。

## 随机故事生成边界

每次调用先恢复世界、玩家、历史、属性和本次条件，再让世界局面与相关者行动形成变化，从开放可能性选择本轮彼此有实质差异的新事，统一推演为可检查的事件结果，最后成文。世界各方的自主行动、个人生活和偶然相遇均可发起事件。事件结果明确新事与核心问题、成因、已改变的现实及具体影响；个人经历不统一派生为外部压力的个人化复述，前置材料不是候选清单或详细思考过程。事件形成阶段应同时判断本轮经历与近期历史在问题、行动、玩家位置和结果意义上是否实质不同；仅更换人物、地点、物件、机构名称或措辞而保留同一问题与应对方式，仍属于重复。

离散化保持现实状态连续，不继承必须继续讲述的题目。既有身份和生活处境决定事情能否成立、如何参与，不要求本轮继续围绕该处境出题。新经历的差别体现为事件身份、核心问题、因果机制和结果意义，不以表面设定变化重复已经讲过的同一问题与应对过程。多项各自有结果的新事共同体现人生与世界的新位置；玩家、天赋、属性与行动改变参与方式、所得和代价，已确认意图必须执行。旧人物、关系和后果在与本轮事件有关时参与，不要求换人换地。宏观性是让外部局面按自身作用范围成立，并在必要处切换整体局面与具体表现；不把世界缩成玩家身边的小事，也不强迫每轮都套用同一类制度、资源或势力冲突。

历史保持事实连续，不继承上一轮主题。世界明确规则优先于与之冲突的旧生成叙述；旧叙述不能自行构成规则突破，本轮有已成立因果改变规则时除外。已有来源、归属、关系、身份和明确结果持续有效，除非本轮新的因果真正改变它们；已完成事件身份只作为事实条件，不得将自然后果或同一行动链下一步重新当成新事。选题使用既定事实判断相容性，记录依据人生影响、独立结果与因果关联组织。世界结果按真实关系影响玩家，没有直接关系的结果保持自身作用范围，不统一收束为玩家同一种生活问题的加重或缓解。不同变化可以并置或相互作用，一项变化可以突出，但不能把同一事件的多个步骤当作多项结果，也不设置固定数量或覆盖配额。已成立结果和余波成为后续条件，不预先指定下一轮必须继续讲述的事情。

先把事件推演到结果成立，再用事件概括、代表性行动、人物反应、具体物件与有意义的后果成文，不从一个现场动作开始延长过程。事件的两面性体现相关者不同处境下的获得、失去、负担与反应；力量和选择的代价来自投入、放弃与反作用，不凭空添加灾祸抵消成功。意外、惊喜和荒诞可由世界特性、偶然相遇及各方行动交汇产生，不等于无因果的反转，也不强制每轮反转或永久牺牲。

正文从最能证明本轮状态改变的事实进入，在整体局面、玩家所处位置和具体表现之间按因果切换，不固定远景开头或段落转场；独立变化可以并置，每次视角切换带来新事实或玩家位置变化。第二人称只指代玩家；玩家姓名只用于输入识别，正文不以姓名或第三人称重新指代玩家。外部事实不自动成为玩家知识。没有命运分支也允许角色在能力范围内行动，玩家不能只是旁观镜头或末尾承受者；事件结果应写明玩家合龄的因果位置。时间节点与历史索引确定当前人生条件和发展尺度；按年推进时呈现积累形成的事件结果，而非截取一个短暂现场。正文使用因果与状态变化的记录文体表达跨度，不把人生或历法坐标写成正文结构；不承担坐标定位的相对时距可以保留为因果事实。篇幅压缩先保留不同事件的结果、局面变化、玩家作用和代价，再省略动作过程。命运分支非空时落实已选方向。交付先核对事件级人生记录、焦点更替、事实相容、宏观作用范围和结果两面性，再检查表达与协议。

## 记忆边界

历史条目已有非空已确认选择时，只补充该选择，不再标为未决分支或附上未选候选；尚未选择的分支保持未决信息。此处只改变派生输入，原始正文、分支候选、选择记录和存档保持不变。

故事连续性调用仍一次处理连续五轮完整正文，原始正文继续完整保存，失败时不删除来源正文。主故事的 `历史输出.事件`保留更早事实与近期记录，并以各自发生年龄标明事实归属；近期结构化事件结果直接由同一叙事历史记录投影，同轮存在结果时不重复投影完整正文，缺少结构化结果时才使用完整正文回退，不增加第二状态源或额外提取调用。近期正文内已经成立的多项结果不能在派生输入中被收束句替代。年龄前缀只属于输入历史索引，不能复制或改写到正文。历史结果以已成立的剧情状态参与本轮成立性判断，不以材料的段落、转场、主题显著性或措辞约束本轮成文。

## 输出边界

每次主故事调用必须提供可用正文，并遵循 `本次信息.篇幅偏好`表达玩家选择的宽松正文篇幅目标，不把该目标用作整个返回对象的长度。`时间定位`为字符串，`事件结果`为对象数组，每项包含字符串`事件`、`成因`、`结果`、`影响`，不设事件数或覆盖配额。前置材料先于正文输出，不增加模型调用或程序推演；正文提交时，合法事件结果由同一条叙事历史记录保存并投影到下一轮输入，异常单项不撤回可用正文。应用只消费正文、分支、属性和结局，事件结果不直接进入界面，原始响应日志完整保留。正文采用的关键事实与因果必须可理解，未采用材料不构成长存事实。属性对象声明心智、体魄、魅力和财富结算后的整数当前值；属性只在正文形成明确、持续的状态变化时改变，没有变化时保持输入值。命运分支承接本轮已形成局面，不用未写完的动作替代完整记录；人生未结束且自然形成新选择时提供选项，否则为false，结局沿用固定Prompt。

## 最大边界

主故事拥有玩家可见正文、可选命运分支、可选结局和本轮属性结果声明，并提供同一回合的结构化事件结果事实；属性、年龄、历史、未来事件和记忆压缩仍由原所属系统管理，事件结果只作为叙事历史记录的事实投影，不成为额外世界状态所有者。
