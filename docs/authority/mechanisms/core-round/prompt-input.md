# 主叙事输入区

## 职责边界

故事 AI 只根据世界事实、历史记忆、角色当前叙事语义和本轮白话引导生成正文，并在故事发展到合适时机时输出命运分支；只有当前人生永久失去意识、感知、决定、行动和任何新经历时才输出结局。结局不限于死亡，只要该条件未完整成立就继续生成正文或命运分支。

第二人称、时间尺度和描述文风属于正文生成及辅助正文的必要规则：第二人称保持当前角色的叙事体验，时间尺度决定当前跨度内应展开的场景与变化密度，描述文风决定正文的语言、节奏和呈现方式。它们不构成独立分析产品，但必须继续约束正文。

历史连续性由故事连续性提取 AI 生成的记忆承担。属性分析、系统分析、事件登记、剧情阶段、事实审计、状态写入和其他非故事产品不进入故事 AI 的职责或可见输入。

## 固定顺序

1. 固定系统职责。
2. 包含稳定世界事实的标准 JSON 用户消息。
3. 先放历史记忆和最近两轮详细剧情、再放角色当前叙事语义的标准 JSON 用户消息。
4. 包含白话本轮引导的标准 JSON 用户消息。

三条用户消息都是可直接解析的完整 JSON 对象，不使用 `⟦世界观⟧`、`⟦历史与角色⟧`、`⟦本轮引导⟧` 或其他对象外标签。第三条消息在存在已到期且仍可用的历史事项时增加可选的 `当前到期事件`，只发送时间、标题和事实，不发送候选编号、审计状态或内部状态；固定 Prompt 在输入映射中说明该可选字段，不另建逐项强制处理规则。

## 世界观

稳定世界事实只包含名称、描述、空间形态、世界观本质、力量体系和成立规则，不包含文明阶段或当前区域。挑战与失败取向不以“标准”“困难”等孤立枚举进入世界字段，而是作为本轮引导中的完整游戏语义：故事保持合理挑战，接受合理的玩家行动，行动可因条件不足而失败，结局主要取决于玩家决策质量。工程标识、世界标签、校准数据、历法名称和系统配置不进入 AI 输入。

## 历史记忆

历史记忆按时间顺序以有效 JSON 字符串数组提供故事压缩 AI 已经提炼的人物、关系、选择、行动、结果、承诺和长期变化。每项以“具体时间：同日已经成立的连续事实”表达；同日事实合并到同一字符串，不携带权重、来源 ID、层级、衰减状态或内部标记。最近两轮详细剧情以时间和正文对象保留在历史记忆之后，角色信息排在两类记忆之后。故事 AI 不再接收独立的剧情阶段、伏笔系统、因果系统、最近变化或重复状态摘要来重新理解同一段历史。

## 角色当前叙事语义

角色只包含姓名、性别、种族、背景、当前年龄、五项基础属性的当前语义，以及键名为 `天赋` 的统一数组。属性语义分成 `开局自带` 与已确认进阶叠加后的 `天赋加成后` 两层；没有进阶时不重复添加第二层。天赋不区分普通命格与轮回天赋，每项只含名称和效果。固定 Prompt 在角色输入映射中说明当前年龄及 0 岁叙事边界，正文规则统一使用“天赋”称谓。等级、属性预算、词条来源、强化等级和其他机制字段保留给各自拥有判断职责的后调用，不进入故事 AI。

## 引导内容

引导内容使用自然语言字符串数组，固定且只包含当前时间、玩家行动、年龄边界与挑战/失败取向合并引导、叙述风格和字数要求；第三项把年龄能力边界与合理挑战、合理接受行动、条件不足时可能失败的通用语义合并表达，保持消息仍由五项引导组成。当前时间明确写为“317年3月13日，请合理模拟本日发生的事情”“317年4月，请合理模拟本月发生的事情”“318年，请合理模拟本年发生的事情”一类完整句子，不带历法名称。叙述风格保留古典语感，但略微白话、直接易读，不堆砌典故、意象或晦涩倒装。字数按玩家当前运行选项表达为“约300字”一类目标值，不向模型发送范围。当前区域、当前可叙述状态、事件注入、因果提示、剧情阶段、伏笔、校准摘要、动态输出说明和其他系统摘要不进入引导，也不从其他来源补回。

## 输出边界

每次调用都输出正文。故事尚能自然继续且当前没有玩家必须决定的不同走向时，正文完成当前故事片段后结束；故事抵达需要玩家决定不同走向的时刻时，正文停在选择前并输出 2 到 4 个第二人称可执行行动；只有当前人生永久失去意识、感知、决定、行动和任何新经历时，正文完成结局叙述并输出结局。命运分支和结局在同一次响应中互斥，未使用者统一填写 `null` 四个字符。
