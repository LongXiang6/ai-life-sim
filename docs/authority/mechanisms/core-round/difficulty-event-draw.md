# 事件卡池与自行消费

状态：当前运行机制（主故事固定资产 `10.0.0`）。本文说明抽象事件卡的字段、生成、卡池、主故事自行消费、难度作用与批量推进。代码不再由本地抽固定张数，也不再用难度权重决定卡的出现。

## 当前口径

| 项目 | 当前做法 |
|---|---|
| 事件入口 | 控制平面给出整池卡名，主故事自行判断是否、何时消费 |
| 卡片字段 | `名称`、`正负`、`权重` |
| 消费 | 主故事在 `事件卡消费` 中列出本轮实际采用的卡名；引擎只扣这些卡 |
| 未消费卡 | 留在池中，供后续轮次或后续批次继续判断 |
| 补池 | 池空或来源指纹失效时，与人生规划、时间线承诺并行同步生成并等待，主故事 Prompt 必带池；仅 event 调用失败才转后台重试 |
| 难度 | 只作为隐藏叙事指引；不改变卡池、消费概率或权重 |
| 批量 | 一次最多 10 轮；遇命运分支、结局或阶段结束即停 |
| 年龄过滤 | 不做年龄过滤；同阶段整池可用 |
| 池版本 | `3.0.0`；控制平面缓存结构版本 `3` |

## 卡片字段

| 字段 | 取值 | 用途 |
|---|---|---|
| `名称` | 2–8 个字符 | 投影给主故事的卡名 |
| `正负` | `正`／`负`／`双面` | 生成时的倾向标签；不参与抽取 |
| `权重` | 1–5 的整数 | 本地保留的叙事倾向参考；不参与抽取，也不扣减 |

本地记录另有 `id`（去重与扣卡）和 `sourceFingerprint`（归属校验），都不进入主故事。

卡片是“世界可能给出的东西”：一件可能发生的事的名字，不含剧情、后果、路径或玩法。同一张卡在不同世界、不同主角身上可以写成完全不同的故事，也可能整轮、整批都不发生。

## 生成

- 事件池为空或来源指纹失效时，控制平面在回合准备阶段触发一次生成，与人生规划、时间线承诺并行发起并等待全部提交；主故事 Prompt 生成前池必须就绪。只有这次 event 调用失败时，才转入后台重试，不阻塞当前回合。
- 生成输入为世界规则包、当前人生阶段与年龄、四项属性点数与语义、玩家意图和最近历史；生成不读取难度。
- 每批生成 6–8 张卡，名称限 2–8 个字符，只写事件本身，不写结果、评价或玩法提示。卡按当前人生阶段生成，不设年龄门槛字段；同一阶段内整池都可用。
- 正负按世界事实与因果判断，不预先凑比例；同一批卡不得重名或换名重复同一件事。
- 旧版候选字段在恢复时被归一化丢弃，不做迁移。

## 卡池与消费

1. **过滤**：来源指纹一致即进入本轮整池；同阶段整池可用，不做年龄过滤。
2. **交付**：整池卡名数组随 `控制平面` 交给主故事；不抽固定张数，也没有空手概率。首轮与阶段切换时，事件池与人生规划、时间线承诺并行同步生成并等待，首屏即可有卡。
3. **消费**：主故事在整个批次内自行判断哪一轮用哪张卡；每轮在 `事件卡消费` 中列出本轮实际采用、并已写入正文的卡名。
4. **扣除**：引擎只按这些卡名扣除；未消费的卡留在池中，供后续轮次或后续批次继续判断。未在池中的卡名视为无效，不扣卡也不采纳。
5. **补池**：池为空或指纹失效时，与人生规划、时间线承诺并行同步生成并等待，主故事 Prompt 必带池；返回时指纹或人生代次已变化的结果不写入。仅生成失败才转后台重试；存在待消费批次时不整体替换事件池，批次结束后下一轮再补。

## 难度

五档难度仍为休闲、轻松、正常、困难、噩梦，正常是中性基线。难度只作为隐藏叙事指引影响故事倾向：休闲、轻松允许更顺的处境，困难、噩梦允许更逆的处境。难度不生成卡片、不改变卡池内容、不改变消费概率或卡片权重，也不改变角色数值、世界参数、恢复／衰减或伤害倍率。它不对玩家公开为属性或天赋，也不是世界中的真实力量。

## 批量与停止

- 一次主故事调用最多返回 10 轮完整故事；第一轮立即进入当前回合，其余按顺序排队。
- 批量调用的时限随目标轮数放大；传输被截断时只回收最后一个完整项及其之前的完整前项，半截 JSON 不算一轮。
- 生成端在遇到命运分支、结局或人生阶段结束时停止，命中条件的该轮为本批最后一项；不足 10 轮是正常结果。
- 阶段结束按叙事边界判断：成年、毕业、入职、成婚、生子、卸任、迁居、退休等。阶段标识变化时，旧批次失效。
- 玩家每次推进仍只发布并结算一轮；批次不会在一次点击中连发。
- 命运分支或结局所在轮提交后，后续排队项不再消费。

## 不做年龄过滤

- 同阶段整池可用，卡池不做年龄过滤。
- 年龄只用于主故事对事实顺序、人物处境与能力的判断；不新增年龄硬规则，不套用固定年龄内容清单。

## 比例不是配额

每轮有没有外部事件、有几件、偏正还是偏负，是机制倾向，不是必须满足的分布。整轮不消费、只消费一张或消费多张，都是合法回合；事件、平常与平稳的比例不由固定配额决定。

## 从卡池到故事

```text
读取世界、历史、年龄、阶段、当前时间跨度、玩家意图
  → 池空/指纹失效时生成 6–8 张卡
  → 按来源指纹取同阶段整池（不做年龄过滤）
  → 卡池名称数组随控制平面进入主故事
  → 主故事一次推进最多 10 轮，遇分支/结局/阶段结束即停
  → 每轮自行决定消费哪几张卡，并在“事件卡消费”中列出
  → 引擎按名扣卡；未消费卡留池
  → 每轮只提交正文和最小协议状态
```

例如，玩家本轮查看旧港账目，时间跨度是一年，池中有“漕运断绝”“旧账被翻出”“邻港借船”“账房归附”四张卡。主故事可以在第一轮消费“旧账被翻出”，第二轮消费“邻港借船”，也可以整批一张不用而写平静的守港年。卡池不是事件数量、故事大纲或成功概率。

一个假例：

```json
{
  "事件卡池": ["漕运断绝", "邻港借船", "旧账被翻出", "账房归附"]
}
```

主故事某一轮的响应片段：

```json
{
  "事件卡消费": ["旧账被翻出"]
}
```

这是说明字段形状的假例，不保证任何世界抽到某张卡，也不表示这些事件已经发生。

## 死亡与评测目标

- 正常难度：完整人生样本中多数应进入老年阶段；这不构成免死保护，严重事件、错误选择和死亡结局仍然允许。
- 噩梦难度：“九死一生”目标是约 90% 的完整人生样本在自然衰老前死亡，不是每回合有 90% 死亡。
- 为评测“自然衰老前”，当前参考健康角色最大寿命约 `80%` 的位置作为自然老年风险起点。它是评测标签，不是运行时死亡率或硬性结局规则。
- 现有叙事 Prompt 和难度指引表达了方向，但尚无足以证明正常、噩梦目标分布的完整人生样本结果。权重只是本地保留的叙事倾向参考，不参与抽取，也不扣减；不能把机制目标描述为已达成。
- 有效评测应覆盖不同世界、角色条件和输入行为，保存每条完整人生是否终局、终局年龄、最大寿命、结局类型和难度，并比较样本分布；抽取次数或单轮故事不能替代完整人生分母。

## 常见误读

- 卡池中有负卡不等于坏事已经发生；只有主故事消费并写入正文才算成立。
- 主故事可以整轮不消费；不消费不等于没有故事，平静推进仍须留下真实变化。
- 难度不代表每轮强制死亡，也不提高坏卡出现率；它只影响叙事裁决的隐藏倾向。
- “九死一生”约 90% 是完整人生评测目标，不是卡片权重、单回合概率或实现保证。
- 事件卡生成不读取难度；主故事按世界规则、属性、资源和行动因果裁决。
- 10 轮是单次生成的批次上限，不是玩家每次点击推进的回合数，也不是事件数量配额。
