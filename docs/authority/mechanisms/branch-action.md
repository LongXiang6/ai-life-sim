# 分支行动机制

## 目标

分支行动让玩家在真实命运抉择处选择下一轮要尝试的行动。

## 结果

- 预设选项（稳健/进取/荒诞）和自定义输入共同形成一个下一轮行动方向。
- 每次行动仅投递给下一轮主叙事一次。
- 所有选项与自定义输入都是角色主观尝试（Attempt），不预先保证成功或把结果写成既定事实。
- 下一轮统一依据玩家年龄、能力、资源与关系，结合世界规则、已成立因果和行动者反应，裁决成功、部分成功、失败或替代路径及其直接代价。
- 不可行行动不得被机械采纳；可行行动不得为制造戏剧性而被任意惩罚。荒诞表达不替代因果裁决。
- 成功、部分成功、失败或替代路径都必须留下可观察后果或明确维持的限制；新形成的关系、资源、身份、位置、承诺、阻碍或后续条件写进正文，后续只按这些已发生事实承接。
- 已确认选择保留在产生分支的故事条目中。

## 最大边界

玩家行动表达意图，不直接保证成功，不强行违背世界观规则，也不成为长期后台目标。极端作死行为允许产生与行动直接相关的致命后果。
