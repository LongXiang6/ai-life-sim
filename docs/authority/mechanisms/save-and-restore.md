# 存档与恢复机制

## 目标

存档与恢复让一局人生在完整状态下保存，并在验证通过后恢复到同一结果。

## 结果

- 存档包含正式故事、世界、角色、时间和活动系统公开状态。
- 引擎状态中的未消费故事批次与本局故事历史一并保存和恢复；没有批次的旧存档恢复为空队列，不继承当前另一局的待消费故事。
- 保存采用同一时点的完整状态。
- 恢复先完成完整性和关联验证，再一次替换当前人生。
- 项目曾保存的剧情结构包装在该状态所属系统的恢复边界归一化为当前唯一格式，再参与完整恢复；新的保存与恢复只使用当前格式，不形成双写、双读或第二恢复入口。
- 世界上下文快照中的已淘汰能力字段（如旧版 NPC、经济和政治能力）只在世界快照迁移边界移除，并按当前能力契约重建运行成员，不重新启用已下线子系统。
- 失败保留进入操作前的当前人生。
- OPFS 备份恢复在首屏渲染后、MOD 路由注册前完成；等待或超时不会阻塞应用页面渲染，MOD 页面读取存储前仍先经过该恢复步骤。

## 最大边界

存档保存所属系统结果，不重新解释故事或修复无效业务事实。
