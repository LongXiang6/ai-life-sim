# 人生结算机制

## 目标

人生结算把完整人生转换为评分、评语、诗句、记录和轮回结果。

## 结果

- 评分使用当前世界适配的五个维度。
- 总分来自五项分值的统一计算。
- 评语和诗句引用已经发生的人生事实。
- 完整成功后形成同一份人生记录。
- 结算不生成、展示或保存道德字段与道德倾向。
- 神话强化在 `+5 → +6` 时开始具有 10% 失败率，之后每级增加 10%，`+10` 及以上固定为 50%。成功后强化等级增加 1；失败后强化等级比尝试前降低 1，例如 `+5 → +6` 失败落到 `+4`，`+6 → +7` 失败落到 `+5`。
- 神话强化成败由程序随机决定，AI 只接收成功或失败、实际强化等级、异变程度与可用属性总量并生成对应内容。失败产生不可逆异变，失败率越高异变越重；50% 对应彻底重组。神话完整属性总量上限为 `18 + 实际强化等级`。
- 玩家可以显式重新启动完整结算。

## 最大边界

结算评价已经完成的人生，不改写正式故事和所属系统历史。
