# 第三层：核心模拟

## 存在意义

核心模拟把一次玩家推进转换为一段立即可阅读的广角人生记录，以及随后并行完成的故事连续性与天赋成长结果。角色数值、系统、事件登记、剧情阶段、道德、状态变化和事件库 AI 不属于活动回合调用。

## 玩家结果

主故事由服务端按 `D:/AI/docs/prompt.txt` 把固定规则与浏览器提交的动态数据合成一条 `user` 消息。模型的唯一生成任务是在一次调用内完成：恢复世界与历史事实，形成新的世界局面，裁决玩家与世界的合龄交互及其结果，再把已经成立的结果编译为玩家本人的人生记录。面对非标准世界观，模型只依据世界名称、描述和世界状态摘要中明确或可直接推出的存在方式、力量与资源边界、制度与关系、因果机制、例外和限制；不能把陌生表达套用现实默认规则，也不能把未知补成事实。历史提供事实连续性和来源归属，不提供本轮主题或续写顺序；故事吸引力先由玩家与世界的交互、事件结果和代价成立，再由正文表达。固定消息采用固定规则→五段只读数据→结算与 JSON 的顺序；当前 Prompt 资产为 `9.26.0`。动态数据中的当前年龄只供合龄裁决，时间窗口只供事实顺序和发展尺度，均不作为正文素材。玩家是事件身份、因果主线和正文重心的归属者；家庭只能作为玩家的背景、资源、关系或处境，不能替代玩家的人生。正文应保留服务于玩家行动、位置、关系、结果或代价的具体环境与人物反应。每次主故事流程只发起一次主故事 AI 调用，世界演化、玩家交互裁决、事件结果和正文编译在这一次调用内闭合；不得新增独立世界模拟、事件识别、状态变化、重复主故事或其他补救调用。故事连续性与天赋成长仍由各自状态所有者处理，不代替或修正主故事。解析器接收事件结果并交给同一条叙事历史记录保存；应用只向玩家消费正文、分支、属性和结局。

1. 玩家确认推进后，本地日历时钟先按当前步长推进日、月、季或年；年度基础点只作为统一的内部时间增量投影。
2. 主叙事是文字游戏式人生模拟：世界按自身规则与相关者行动形成玩家将要面对的变化，从开放可能性选取彼此实质不同且已经落地的新事，先确定玩家如何遭遇、理解、行动、选择、建立关系、获得或失去，再把结果组织成以玩家人生为主体的广角记录。实际时间窗口只用于判断本轮尺度、合龄条件和事实顺序，不等于已经提供了可直接续写的状态差事实；模型必须先从真实输入中形成新的外部条件与玩家交互，再从已成立结果中选择最能证明玩家人生位置改变的局面，在整体局面、行动者目标与阻力、玩家行动和具体证据之间切换，其他新事仍可独立并行、反衬或改变代价。历史保持事实连续但不提供续写题目；新意按问题、因果机制、行动者、作用范围、玩家交互和结果意义判断。宏观由外部局面对玩家造成的真实条件和后果及视野切换体现，家庭只作为玩家的背景、资源、关系或处境，不把家庭整体生活写成玩家人生主线。故事吸引力由局面压力、玩家选择、因果转折、结果、关系变化和代价组织；不把世界缩成家庭日常，也不夸大为无因果灾变。正文与事件结果只表达已成立事实及其因果，不把输入索引或历法措辞带入成文；因果确需时才保留短时距。每项结果保留获得、失去、负担或反作用，惊喜与荒诞须来自世界特性和各方行动交汇。正文保留证明玩家经历、交互、选择、位置变化与结果的代表性动作、人物反应或物件，不写成家庭影响报告或过程铺陈的连续小说。
3. 正文通过协议后立即进入正式故事历史，玩家可以马上阅读。事件结果与正文一并保存为同一条叙事历史记录；下一轮的 `历史输出.事件`由历史所有者优先投影结构化结果作为近期已成立事实，只有该轮没有可用结构化结果时才回退到完整正文。完整正文仍由历史、日志和存档保留，不能把末句当作整轮结果而丢掉转岗、关系或资源等事实。历史材料只用于事实相容与来源归属，不用作续写或文风模板；原始正文、事件结果与连续性结果仍由各自所有者完整保存。
4. 天赋成长在正文发布后执行；故事连续性只在近期完整正文超过10轮且到达五轮 cadence 时调用。主故事同次响应可以返回结构化的天赋表现线索，只记录玩家实际使用已选命格、产生可观察结果和明确突破契机，不判断是否进阶。命格系统保存这些线索并维护各血脉的证据窗口与复评水位；只有本地确认年龄、窗口、突破契机、冷却和次数条件同时成立，才启动一次天赋成长 AI。触发时一个正常回合最多包含一次主故事、一次五轮故事连续性批量调用和一次天赋成长；主故事内部不因世界演化、事件识别、状态变化或质量补救新增调用。
5. 后调用完成前，页面保持本轮仍在收束的状态；后调用结果更新各自所属数据或瞬态投影，不撤回已经发布的正文。
6. 连续性提取失败时正文继续保留，五轮来源仍留在完整历史中，并在下一次五轮 cadence 到达时重试；天赋成长失败不伪装成成功结果，也不引入备用调用。
7. 角色显式设定的起始年龄是唯一年龄事实；背景中的穿越、转生或异界身份不得改变开局年龄。输入时间只用于确定人生位置、窗口尺度和时间定位字段；按年推进时概括阶段性结果，不截取单一现场。正文以因果和状态变化体现跨度，不把输入索引或历法措辞写入正文与事件结果；玩家行动符合实际年龄和能力，主动性随人生阶段适配。
8. 主故事输出字段依次为 `时间定位`、`事件结果`、`正文`、`命运分支`、`属性`、`结局`，并可附带不直接展示的 `天赋表现线索`。事件结果是正文唯一的前置事实材料，统一承载玩家人生与世界交互的新事：`事件`保存玩家经历的身份与核心问题，`成因`保存世界机制、相关者行动与玩家进入因果的方式，`结果`保存玩家经历、位置和关系如何改变及其外部响应，`影响`保存仍有效的获得、失去、代价与反作用；天赋表现线索只引用当前玩家信息中的不透明天赋引用，记录实际使用、可观察结果、来源回合及可选突破契机，不得输出成长路线或“应该进阶”的判断。时间索引只留在内部字段，事件结果与正文不复述输入索引或历法措辞。事件结果与正文一并保存并投影到后续输入，不向玩家展示，也不成为平行世界状态源。正文以结果为依据压缩窗口内的不同玩家经历、交互、位置变化和代价；公开中文属性名统一为 `财富`，由角色基础属性所有者现有的内部 `familyBackground` 字段承载，不建立第二状态字段。
9. 已生效天赋在相关事件中通过具体行动、条件、限制和结果进入正文；天赋的稀有度决定强度与效果边界，类别只作为宏观整理标签，不限制天赋类型。没有直接相关事件时不强行插入。多个天赋都能自然作用时，优先让最近未体现的天赋承担本轮行动或结果，避免一项天赋长期独占正文。尚未由玩家确认的成长路线不属于已生效能力。
10. 局内天赋成长必须在角色当前年龄达到 16 岁后才进入资格筛选，并且仍须有跨多个已完成故事窗口的直接证据；普通至史诗分别至少经过 2、3、4、5 个窗口才可进入下一等级；局内最高成长到传说。主故事线索只在玩家实际使用命格并留下可观察结果时形成证据窗口；明确突破契机由主故事线索标记，不能由本地关键词或名称推测。命格系统在本地累计证据窗口、记录已复评水位，并在调用成长 AI 前筛选年龄、证据窗口、突破契机、冷却和次数：同一天赋本局最多进阶 2 次；本局全部天赋最多进阶 6 次；同一天赋完成一次玩家确认的进阶后，至少经过 20 个回合且模拟基础点严格流逝超过 20 年（超过 `20×1000` 基础点）才可再次进入候选。没有新的未复评突破契机，或全部天赋不满足本地条件时，跳过成长 AI 调用。AI 只判断已通过程序筛选的证据并生成三条路线，玩家明确确认后才写入结果。恢复当前年龄未满 16 岁的旧状态时，角色所有者清除待选成长、证据线索、复评水位和未成年阶段形成的成长记录，并把已提交结果恢复到首次成长前的命格版本，不能继续阻塞故事推进或保留其属性结果。
11. 当前到期事件不进入主故事 Prompt，也不通过命运分支、时间引导或系统事件旁路恢复。历史账本继续拥有本地查询、候选生命周期和处置能力，但主叙事只消费本轮单消息中声明的数据。

## 下一轮预生成

- 玩家开启“预生成下一轮”后，核心模拟只在故事连续性与天赋成长都完成并由所属系统提交之后，异步准备下一轮本地事实并请求一次下一轮主故事正文；预生成不执行下一轮连续性提取或天赋成长，也不延迟本轮终态。
- 预生成使用与正式回合隔离的只读投影，结果只保存在 `mod-engine` 的瞬态单槽，不进入 Store、存档或云同步。真实下一轮组装出完整主故事请求后，只有请求指纹完全一致才消费该结果一次；不一致时放弃瞬态结果并正常实时请求。
- 已结局、存在待选命运分支、存在待确认天赋成长或开关关闭时不启动预生成。玩家行动、强制分支、时间步长、模型或叙事设置、存档、新人生及运行生命周期变化都会使旧结果失效。
- 预生成失败、取消或失效不改变已经完成的回合，不伪装为正式正文，不触发重试或备用调用；正式回合只消费已经完成且指纹完全匹配的结果，进行中的预生成不得阻塞玩家推进，未命中时取消该预生成并立即使用正式主故事路径。

## 最大边界

- 主叙事生成玩家可见正文、命运分支、结局和属性中的本轮结果声明，并生成供历史所有者保存的结构化事件结果；不拥有属性、系统、事件、剧情阶段或其他业务状态。可换算的属性差值由 `character-base` 所有者校验、钳制、提交和持久化。
- 连续性提取只拥有五轮批次剧情与未来事件，天赋成长只拥有成长判定与三条候选路线；两者不互相代写结果。
- 事件库 AI、事件生命周期注入、世界事件候选投影和到期候选投递均已退出正式运行，不保留资产、缓存、活动阶段、瞬态结果或主故事输入字段。
- 所属系统拥有校验、提交和持久化结果。
- 页面消费正式故事和公开状态，不解析 AI 协议。
- 每个逻辑调用在一次回合中最多执行一次。
- 下一轮预生成属于下一回合主故事的提前执行；同一请求命中后不得在正式推进时再次调用主故事，失效后不得消费旧结果。
- AI 响应先按字段与数组项独立识别、补全和归一化；单个坏项不撤销其他可用内容。只有所属调用的最低可用结果完全无法形成时才放弃该调用结果，不因此撤回正文或触发额外 AI 请求。

## 模型调用配置

- 核心模拟的主叙事、故事连续性和天赋成长调用必须消费设置界面当前保存的同一组玩家 API 地址、Key 和模型。
- 自定义中转地址与官方兼容地址使用同一代理请求契约；受保护 Prompt 只负责注入服务端固定资产，不改变玩家配置的目标地址或凭据。
- 只有地址、Key 或模型确实为空时才返回未配置错误；自定义中转不得因为模型名包含 `deepseek` 或使用结构化工具而被改发到另一地址。
