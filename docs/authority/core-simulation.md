# 第三层：核心模拟

## 存在意义

核心模拟把一次玩家推进转换为一段立即可读的人生小说章节，以及随后并行完成的故事连续性与天赋成长结果。命运预览阶段先生成并展示出生背景，并把它作为本局控制平面状态交给核心模拟；出生背景的一次调用同时返回可直接阅读的出生叙事和结构化出生事实。出生输入包含四项开局属性的实际点数、中文语义和固定基准：-10是凡人最差，0是凡世凡人基准，+10是凡人正面上限，区间外是超凡。叙事时间停在玩家出生当时，只介绍出生时已经存在的信息，并按点数与语义体现家世和出生条件，不把出生之后的发展写成已发生事实。出生叙事按宏观环境、微观家庭处境和开局总结三层各自成段，段与段之间使用换行；命运预览和正式故事页都保留这些段落。进入核心回合后不重复生成出生背景。核心回合拥有条件触发式叙事控制平面：人生规划、事件卡和未来世界承诺只在状态缺口或来源版本失效时调用，并以只读投影进入主故事输入；主故事拥有本轮正文、属性、命运分支、结局与角色死亡的唯一叙事裁决权。人生规划的`阶段目标`可返回单个字符串或分条数组，程序统一展开为可读文本；`阶段标识`、`当前阶段`、`阶段目标`确实缺失时按诊断错误记录并延后到下一轮重试，不阻断当前回合。

## 玩家结果

玩家从角色设定的起始年龄介入，出生之后至介入时点的经历仍然存在；出生控制平面须同时给出出生叙事与介入前史，角色背景明确的既往事实优先。自然寿命参考年龄只是衰老背景，不是死亡线，也不由主故事逐轮调整。只有主故事明确声明角色死亡，角色状态才转为死亡并由历史账本绑定死亡事实；普通人生结局不推断为死亡。

主故事由服务端按受保护资产把固定规则与浏览器提交的动态数据合成一条 `user` 消息，当前主故事固定资产版本为 `10.0.0`。模型在一次调用内读取世界、角色、历史、本次条件和玩家行动，按角色的年龄、能力、资源、关系与世界规则写出这一段时间里真正发生的事；故事可以从关系、愿望、误会、日常难题或外部局势发端，不要求先形成宏观变化，也不设置事件数量、重大变化或阶段推进配额。模型自主安排节奏、转折和经历数量，允许概括、跳跃和留白；正文像人生小说的一章，不是因果报告、提纲、规则解释或事件清单。面对非标准世界观，模型只依据世界名称、描述和世界状态摘要中明确或可直接推出的存在方式、力量与资源边界、制度与关系、因果机制、例外和限制；不能把陌生表达套用现实默认规则，也不能把未知补成事实。历史提供事实连续性和来源归属，不提供本轮主题或续写顺序；控制平面事件卡只提供软提示，玩家行动是尝试而不是命令，可以成功、失败、延迟、转化或产生意外，已成立事实和世界规则优先。固定消息采用“角色/输入/写法/输出”规则后接五段只读数据的顺序；当前 Prompt 资产为 `10.0.0`。动态数据提供篇幅偏好、叙事称呼、文风偏好和可选控制平面；称呼与文风只影响表达，不覆盖世界规则、已成立事实、因果和返回协议。正文只按本次信息.篇幅偏好控制宽松目标，不设置默认字数或宏观编年阶段配额。主故事固定资产不携带示例矩阵。当前年龄只供人物处境与能力判断，时间窗口只提供事实顺序与发展范围，不强制故事题材或外部局面。玩家是本轮故事的主角；家庭成员可以是有自身目标的重要人物，但其经历须通过玩家的具体互动或影响进入主线。每次主故事流程只发起一次主故事 AI 调用；条件控制平面调用不属于主故事调用，且只在缺口或来源版本失效时触发，不负责提交玩家事实。世界演化、玩家行动裁决和正文编译在主故事调用内闭合。故事连续性与天赋成长仍由各自状态所有者处理，不代替或修正主故事。解析器接收正文、属性、命运分支、结局、角色死亡和可选的 `事件卡消费`、`天赋表现线索`；应用只向玩家消费正文、分支、属性和结局。

### 抽象事件卡与人物驱动

主故事需要外部变化的入口，但入口不能变成第二套剧情。核心模拟按“世界可能给出的东西”生成抽象事件卡，并由主故事自行决定是否、何时消费：
- **卡片**：事件池为空或来源指纹失效时，由 AI 依据世界规则包、当前人生阶段与年龄、四项属性点数与语义、玩家意图和最近历史，生成 6–8 张事件卡。名称限 2–8 个字符，正负取“正／负／双面”，并带权重（1–5）。卡只是一件可能发生的事的名字，不含剧情、后果、路径或玩法；同一张卡在不同世界、不同主角身上可以写成完全不同的故事。
- **卡池**：控制平面按来源指纹筛出当前整池，同阶段整池可用，把卡名数组交给主故事；不做年龄过滤，也不再由本地抽固定张数或设空手概率。首轮与阶段切换时，事件池与人生规划、时间线承诺并行同步生成并等待，首屏即可有卡。
- **消费**：主故事自行判断本轮是否消费、消费哪几张，并在 `事件卡消费` 中列出本轮实际采用并写入正文的卡名。引擎只按这些卡名扣除；未消费的卡留在池中，供后续轮次或后续批次继续判断。未在池中的卡名视为无效，不扣卡也不采纳。
- **难度**：难度只作为隐藏叙事指引影响故事倾向，不改变卡池、消费概率或卡片权重。难度不生成卡片、不封顶风险类型、不改变角色数值、世界参数或伤害倍率。
- **比例不是配额**：每轮有没有外部事件、有几件、偏正还是偏负，是机制倾向，不是必须满足的分布。整轮不消费、只消费一张或消费多张，都是合法回合；事件、平常与平稳的比例不由固定配额决定。
- **玩家位置**：玩家只控制角色，不控制世界。世界按自身规则运行，加征、换防、议和、灾变、招役与封赏由世界与相关者决定；玩家可以遭遇、理解、行动和承受，但不能命令世界发生什么。
- **整池可用**：同阶段整池可用，事件池不做年龄过滤；年龄只影响主故事对人物处境与能力的判断，不形成卡池筛选。
- **归一化**：名称超出 2–8 个字符、正负不在“正／负／双面”内或权重越界的卡片不进入池；同批重名卡合并；旧版候选字段在恢复时被丢弃，不做迁移。
- **生成与补充**：池为空或来源指纹失效时，事件卡池与人生规划、世界时间线承诺并行同步生成并等待，主故事 Prompt 必带池；返回时指纹或人生代次已变化的结果不写入。仅 event 调用失败才转后台重试，不阻塞当前回合。存在待消费批次时不整体替换事件池，批次结束后下一轮再补。
- **平静回合**：整轮没有消费任何卡时允许平静推进。平静不等于停滞：本轮仍须留下至少一个真实成立、可观察的生活、关系、能力、资源、身份、位置或理解变化，不要求属性增长、成就或危机。
- **投影**：主故事收到卡池的名称数组；正负、权重与指纹只留在本地校验与持久化，不进入数据层。卡不保证发生，也不构成成功概率或事件数量。

### 命运分支行动裁决

预设选项和自定义输入都只是玩家选定的行动方向（Attempt），不是成功声明或已成立事实。下一轮对所有分支统一裁决：检查玩家年龄、能力、资源、关系与可用机会；校验世界规则、行动者反应和已有因果；再写出可行的成功、部分成功、失败或替代路径及与之直接相关的代价。不得机械采纳不可行行动，也不得为制造戏剧性而任意惩罚可行行动。荒诞幽默可以表达合理后果，但不是能力裁决本身。命运调性不能改变行动是否可行或结果因果。裁决结果直接写进正文中的人物行动、关系反应、资源变化与后续处境，不另造结构化事件账本。

1. 玩家确认推进后，本地日历时钟先按当前步长推进日、月、季或年；年度基础点只作为统一的内部时间增量投影。
2. 主叙事是人生小说模拟：世界按自身规则与相关者行动变化，玩家从具体处境中遭遇、理解、行动、选择、建立关系、获得或失去；正文通过人物目标、阻力、行动、对白、反应和结果，让这些变化成为可进入的故事。故事可来自个人关系、家庭、成长、学习、工作、发现或外部局势，不要求每轮发生社会结构变化、危机或突变。实际时间窗口只用于判断本轮范围与事实顺序，不等于可直接续写的状态差事实；历史保持事实连续但不提供续写题目。按年或更长跨度时，可以用转场压缩平常阶段，并展开改变玩家经历、关系或处境的关键场景，但不把整段跨度写成流水账或总结，也不把单一短暂现场当作跨年故事的全部。正文以符合玩家视角和年龄的具体经历呈现；对白和细节可以丰富场景，但不另造重大结果或违背已成立事实。吸引力来自人物之间的目标、选择、关系与因果结果，不强制戏剧性转折、道德总结或悬念。
3. 正文通过协议后立即进入正式故事历史，玩家可以马上阅读。正文本身是历史事实底稿；下一轮的 `历史输出.事件`直接投影完整正文与发生年龄，不再拆分或优先投影结构化事件结果。完整正文仍由历史、日志和存档保留，不能把末句当作整轮结果而丢掉转岗、关系或资源等事实。历史材料只用于事实相容与来源归属，不用作续写或文风模板；原始正文与连续性结果仍由各自所有者完整保存。
4. 天赋成长在正文发布后执行；故事连续性只在近期完整正文超过10轮且到达五轮 cadence 时调用。主故事同次响应可以返回结构化的天赋表现线索，只记录玩家实际使用已选命格后的可观察结果；来源回合由引擎按本轮记录，不由模型输出，线索不判断是否进阶。命格系统保存这些线索并维护各血脉的证据窗口、复评水位和机缘判定；只有本地确认年龄、窗口、冷却、次数条件同时成立并命中机缘时，才启动一次 03 路线生成。触发时一个正常回合最多包含一次主故事、一次五轮故事连续性批量调用和一次天赋成长；主故事内部不因世界演化、事件识别、状态变化或质量补救新增调用。
5. 后调用完成前，页面保持本轮仍在收束的状态；后调用结果更新各自所属数据或瞬态投影，不撤回已经发布的正文。
6. 连续性提取失败时正文继续保留，五轮来源仍留在完整历史中，并在下一次五轮 cadence 到达时重试；天赋成长失败不伪装成成功结果，也不引入备用调用。
7. 角色显式设定的起始年龄是唯一年龄事实；背景中的穿越、转生或异界身份不得改变开局年龄。输入时间只用于确定人生位置和窗口范围；按年推进时以自然转场交代跨度，并把关键变化写成具体场景。不要把输入索引机械转写为正文坐标或固定段落结构；符合本轮因果的昼夜、季节和相对时距可以自然出现。玩家行动符合实际年龄和能力，主动性随人生阶段适配。
8. 主故事输出字段为 `正文`、`属性`、`命运分支`、`结局`、`角色死亡`，并可选 `事件卡消费`、`天赋表现线索`。`属性`只写本轮发生持续变化的项，填结算后的当前值，未变化项可省略；`命运分支`非空时为 2 至 4 个字符串；`结局`为恰好四个汉字；`角色死亡`为 false 或明确死因对象。`事件卡消费`只列本轮实际采用并写入正文的卡名；`天赋表现线索`只含 `引用` 和 `可观察结果`，引用当前玩家信息中的不透明天赋引用，来源回合由引擎记录。正文是唯一历史事实底稿，不向玩家展示额外账本，也不成为平行世界状态源。公开中文属性名统一为 `财富`，由角色基础属性所有者现有的内部 `familyBackground` 字段承载，不建立第二状态字段。
9. 已生效天赋在相关事件中通过具体行动、条件、限制和结果进入正文；资质阶位衡量机制复杂度，开发阶段表示掌握程度，二者都不作为能力类型或世界题材限制。类别只作为宏观整理标签，不限制天赋类型。已确认天赋是玩家事实，跨题材金手指沿用[命格界面](pages/talent-draw.md)的能力边界：世界未声明同类力量体系不否定或降格天赋，能力按自身效果成立，世界规则用于裁决外部环境与相关者的反应，不为能力凭空补写全世界的力量体系。没有直接相关事件时不强行插入。多个天赋都能自然作用时，优先让最近未体现的天赋承担本轮行动或结果，避免一项天赋长期独占正文。尚未由玩家确认的成长路线不属于已生效能力。
10. 局内天赋成长必须在角色当前年龄达到 16 岁后才进入资格筛选。初醒到掌握至少需要 2 个证据窗口，掌握到圆满至少需要 3 个证据窗口。成长只推进开发阶段，不改变资质阶位。主故事线索只在玩家实际使用命格并留下可观察结果时形成证据窗口；命格系统在本地累计证据窗口、记录已复评水位，并在调用成长 AI 前筛选年龄、证据窗口、冷却和次数：同一天赋本局最多成长 2 次；本局全部天赋最多成长 6 次；同一天赋完成一次玩家确认的成长后，至少经过 20 个回合且模拟基础点严格流逝超过 20 年（超过 `20×1000` 基础点）才可再次进入候选。满足门槛的候选还要按本轮存档种子做一次确定性机缘判定；未命中不调用 03，命中后只把该天赋、机缘类型和证据窗口送入，03 只生成三条路线，玩家明确确认后才写入结果。没有新的未复评线索、机缘未命中，或全部天赋不满足本地条件时，跳过成长 AI 调用。恢复当前年龄未满 16 岁的旧状态时，角色所有者清除待选成长、证据线索、复评水位和未成年阶段形成的成长记录，并把已提交结果恢复到首次成长前的天赋版本。
11. 到期世界承诺由控制平面按本地时间判断并以 `到期世界事实` 进入主故事 Prompt；它不是玩家已经经历的结果。主故事只有在该承诺真实作用于玩家时才把它写进正文。未到期、失效或与当前玩家范围无关的承诺不进入本轮输入。

## 故事批次

- 玩家开启“批量生成故事”后，一次主故事调用按顺序返回最多十轮完整故事；第一轮立即进入当前回合，后续故事按回合顺序保存在引擎状态和存档中。不足十轮是正常结果。
- 批量调用的时限随目标轮数放大；传输被截断时只回收最后一个完整项及其之前的完整前项，半截 JSON 不算一轮。
- 生成端在遇到命运分支、结局或人生阶段结束时停止：命中停止条件的该轮就是本批最后一项，不再生成其后的回合。阶段结束按叙事边界判断（成年、毕业、入职、成婚、生子、卸任、迁居、退休等）。
- 玩家每次推进只发布并结算一轮。批次故事经过与实时故事相同的解析、正文发布、故事连续性和天赋成长结算；未消费的故事保持排队，不在一次点击中连发。
- 批次各轮是独立回合的人生记录，各自覆盖自身跨度并允许自然跳时，只按前项已成立事实顺序承接；不要求逐场景续写或拆分同一现场。批次后项不预设尚未作出的玩家选择。批次中出现命运分支或结局时，该项可被消费，之后不再消费后续项；阶段标识变化同样使旧批次失效。
- 开关关闭、玩家选择或强制分支、推进步长或叙事设置变化、新人生、上下文切换、存档恢复到另一人生及回合结局都会清除不再适用的待消费故事。有效存档恢复同一人生时，剩余批次随引擎状态一并恢复。
- 批次关闭或队列耗尽后，下一次推进使用普通主故事调用；批次故事由同一次主故事响应提供，不另行预生成、重试或调用主故事。

## 机制清点

- `causal-delay`、`plot-structure`、`foreshadowing` 是 mod-engine 内部叙事运行态，不是外部运行时子系统，也不进入主故事输入。三者仅在 `orchestrator.reset()`（新人生与引擎重置）时重置；`plot-structure` 与 `foreshadowing` 每回合只经内部 `collectState()` 记录阶段与伏笔进展，`causal-delay` 的 `collectState()` 不进入回合管线。它们不产生本轮事件、不写叙事历史、不投影为事件卡，也不与事件卡重叠。
- `mod-history-dynamics` 的 `historical-event-ledger` 只记录已经发生的世界事实、因果边与既有承诺；`submitHistoricalEventCandidates` 与 `getDueHistoricalEventCandidates` 两个导出 API 在当前 `src/` 内没有调用方，不构成事件来源。
- `simulationBridge` 是旧数值模拟留下的 UI 快照发布／订阅桥，只承载外部子系统摘要供界面展示，不是运行时真源；本轮叙事、控制平面、事件卡与历史账本都不从它读取，内部叙事运行态也不进入该快照。
- 条件式控制平面调用中，出生背景必须先生成；人生规划与世界时间线承诺互不依赖，并行发起；池空或来源指纹失效时，事件卡池与人生规划、世界时间线承诺并行同步生成并等待，主故事 Prompt 必带池。只有 event 调用失败才转后台重试，不阻塞当前回合。

## 最大边界

- 主叙事生成玩家可见正文、命运分支、结局、角色死亡和属性中的本轮结果声明；不拥有属性、系统、事件、剧情阶段或其他业务状态。可换算的属性差值由 `character-base` 所有者校验、钳制、提交和持久化。
- 连续性提取只拥有五轮批次剧情与正文中已经明确安排的具体未来事项，并把这些事项登记到历史事件账本；控制平面时间线只拥有脱离玩家历史的世界级未来承诺。两者的输入、状态和账本归属不同，不得把同一条事实双重登记。天赋成长只拥有本地机缘判定、三条候选路线和玩家选择后的阶段推进；这些后调用不互相代写主故事结果。
- 命运预览拥有出生背景的前置生成与展示入口；核心控制平面接收并持久化该结果，不在正式首回合重复生成。核心控制平面继续拥有出生背景、人生规划、事件卡池和世界时间线承诺的持久化状态；这些状态只保存卡片、约束和未来承诺，不拥有已发生玩家事实。每种辅助调用都绑定世界、人生阶段、规范化时间步长、玩家意图和来源版本指纹；指纹不变时复用已生成结果，来源失效或池无法提供适用结果时才刷新。
- 所属系统拥有校验、提交和持久化结果。
- 页面消费正式故事和公开状态，不解析 AI 协议。
- 每个逻辑调用在一次回合中最多执行一次。
- 批次后续项属于同一次主故事响应的待消费回合；消费后不得再次调用主故事，失效后不得消费旧项。
- AI 响应先按字段与数组项独立识别、补全和归一化；单个坏项不撤销其他可用内容。只有所属调用的最低可用结果完全无法形成时才放弃该调用结果，不因此撤回正文或触发额外 AI 请求。

## 模型调用配置

- 核心模拟的主叙事、故事连续性和天赋成长调用必须消费设置界面当前保存的同一组玩家 API 地址、Key 和模型。
- 自定义中转地址与官方兼容地址使用同一代理请求契约；受保护 Prompt 只负责注入服务端固定资产，不改变玩家配置的目标地址或凭据。
- 只有地址、Key 或模型确实为空时才返回未配置错误；自定义中转不得因为模型名包含 `deepseek` 或使用结构化工具而被改发到另一地址。
