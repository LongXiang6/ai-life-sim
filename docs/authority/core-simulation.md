# 第三层：核心模拟

## 存在意义

核心模拟把一次玩家推进转换为一段立即可阅读的故事，以及随后并行完成的故事连续性与天赋成长结果。角色数值、系统、事件登记、剧情阶段、道德、状态变化和事件库 AI 不属于活动回合调用。

## 玩家结果

主故事固定服务端资产采用指定的人生重开模拟器系统 Prompt；世界、玩家、剧情记忆、当前属性、当前时间与命运抉择由一条四元素 JSON 数组消息提供。模型按状态行、正文、命运分支和结局的文本格式响应；正文发布、分支与结局解析、属性提交和连续性提取仍由各自状态所有者完成。

1. 玩家确认推进后，本地事件时钟先推进年度基础点；每年基础点为1000，事件轮次只决定每轮消费多少点。
2. 主叙事根据四元素数据层输入生成一段人生重开式正文，并按固定文本协议返回状态行、`正文`、`命运分支`、`结局`。状态行只包含年龄、心智、体魄、魅力和家境；分支与结局互斥，未触发者写为 `false`，结局对象同时包含四字评语与最终总结。状态行中的四项属性只作为本轮结果声明，本地相对当前数值换算后仍由 `character-base` 校验、钳制和持久化；年龄不由主故事建立新状态。
3. 正文通过协议后立即进入正式故事历史，玩家可以马上阅读。
4. 天赋成长在正文发布后执行；故事连续性只在近期完整正文超过10轮且到达五轮 cadence 时调用。触发时一个正常回合最多包含一次主故事、一次五轮故事连续性批量调用和一次天赋成长。
5. 后调用完成前，页面保持本轮仍在收束的状态；后调用结果更新各自所属数据或瞬态投影，不撤回已经发布的正文。
6. 连续性提取失败时正文继续保留，五轮来源仍留在完整历史中，并在下一次五轮 cadence 到达时重试；天赋成长失败不伪装成成功结果，也不引入备用调用。
7. 角色显式设定的起始年龄是唯一年龄事实；背景中的穿越、转生或异界身份不得改变开局年龄。故事按当前时间窗口、已有事实和玩家行动自然推进，不预设固定视角、事件数量、事件链、场景或主线；玩家行动仍按现实条件产生成功、受阻、误判、代价或未决结果，已确认状态作为合理性边界而非复述模板。
8. 故事内容必须符合对应的年龄能力边界。正文只能写状态行当前年龄这一岁中的一个完整事件，只能叙述当前年龄正在发生或已经发生的事，可以使用当前年龄及以前已经成立的事实，但不得出现任何大于当前年龄的年龄数字或年龄阶段词、成长回顾、人生概览或成长蒙太奇，也不得出现下一岁及以后的事件、成长、关系变化或结果。世界设定中的第二人称描述只作为世界背景，不是本轮已发生事实。叙事行动必须服从当前年龄：0—2 岁只表现婴幼儿能够成立的感知、基础反应和被照料过程，不赋予独立工作、持械、成人技能或成人式决定；3—5 岁的关键决定由照料者、监护人或环境承载；年龄增长后再逐步增加自主行动。玩家输入超出当前能力时，正文表现为尝试受阻、由他人代行或环境回应，不把不可能的成人行动直接写成既成事实。
9. 已生效天赋在相关事件中通过具体行动、条件、限制和结果进入正文；没有直接相关事件时不强行插入。多个天赋都能自然作用时，优先让最近未体现的天赋承担本轮行动或结果，避免一项天赋长期独占正文。尚未由玩家确认的成长路线不属于已生效能力。
10. 局内天赋成长必须在角色当前年龄达到 16 岁后才进入资格筛选，并且仍须有跨多个已完成故事窗口的直接证据；普通至史诗分别至少经过 2、3、4、5 个窗口才可进入下一等级；局内最高成长到传说。成长判定还必须同时看到反复训练或使用形成的长期积累、窗口之间真实经过的时间沉淀，以及机缘、奇遇、顿悟、重大变故、情绪冲击或同等具体事件中的至少一个明确契机；只有重复经历而缺少任一项时不得进阶。程序在调用成长 AI 前先筛选年龄、证据、冷却和次数：同一天赋本局最多进阶 2 次；本局全部天赋最多进阶 6 次；同一天赋完成一次玩家确认的进阶后，至少经过 20 个回合且模拟基础点严格流逝超过 20 年（超过 `20×1000` 基础点）才可再次进入候选。全部天赋均不满足程序条件时跳过成长 AI 调用。AI 只判断已通过程序筛选的证据并生成三条路线，玩家明确确认后才写入结果。恢复当前年龄未满 16 岁的旧状态时，角色所有者清除待选成长和未成年阶段形成的成长记录，并把已提交结果恢复到首次成长前的命格版本，不能继续阻塞故事推进或保留其属性结果。
11. 当前到期事件不进入主故事 Prompt，也不通过命运抉择、时间引导或系统事件旁路恢复。历史账本继续拥有本地查询、候选生命周期和处置能力，但主叙事只消费四元素数据层。

## 下一轮预生成

- 玩家开启“预生成下一轮”后，核心模拟只在故事连续性与天赋成长都完成并由所属系统提交之后，异步准备下一轮本地事实并请求一次下一轮主故事正文；预生成不执行下一轮连续性提取或天赋成长，也不延迟本轮终态。
- 预生成使用与正式回合隔离的只读投影，结果只保存在 `mod-engine` 的瞬态单槽，不进入 Store、存档或云同步。真实下一轮组装出完整主故事请求后，只有请求指纹完全一致才消费该结果一次；不一致时放弃瞬态结果并正常实时请求。
- 已结局、存在待选命运分支、存在待确认天赋成长或开关关闭时不启动预生成。玩家行动、强制分支、时间步长、模型或叙事设置、存档、新人生及运行生命周期变化都会使旧结果失效。
- 预生成失败、取消或失效不改变已经完成的回合，不伪装为正式正文，不触发重试或备用调用；下一轮继续使用正式主故事路径。

## 最大边界

- 主叙事只生成玩家可见正文、命运分支、结局和状态行中的本轮属性结果声明，不拥有属性、系统、事件、剧情阶段或其他业务状态与分析结果；可换算的属性差值由 `character-base` 所有者校验、钳制、提交和持久化。
- 连续性提取只拥有五轮批次剧情与未来事件，天赋成长只拥有成长判定与三条候选路线；两者不互相代写结果。
- 事件库 AI、事件生命周期注入、世界事件候选投影和到期候选投递均已退出正式运行，不保留资产、缓存、活动阶段、瞬态结果或主故事输入字段。
- 所属系统拥有校验、提交和持久化结果。
- 页面消费正式故事和公开状态，不解析 AI 协议。
- 每个逻辑调用在一次回合中最多执行一次。
- 下一轮预生成属于下一回合主故事的提前执行；同一请求命中后不得在正式推进时再次调用主故事，失效后不得消费旧结果。
- AI 响应先按字段与数组项独立识别、补全和归一化；单个坏项不撤销其他可用内容。只有所属调用的最低可用结果完全无法形成时才放弃该调用结果，不因此撤回正文或触发额外 AI 请求。

## 模型调用配置

- 核心模拟的主叙事、故事连续性和天赋成长调用必须消费设置界面当前保存的同一组玩家 API 地址、Key 和模型。
- 自定义中转地址与官方兼容地址使用同一代理请求契约；受保护 Prompt 只负责注入服务端固定资产，不改变玩家配置的目标地址或凭据。
- 只有地址、Key 或模型确实为空时才返回未配置错误；自定义中转不得因为模型名包含 `deepseek` 或使用结构化工具而被改发到另一地址。
