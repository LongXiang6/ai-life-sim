# 邮箱界面

## 目标

邮箱界面让玩家阅读站内消息、发送消息、处理可转移轮回天赋，并领取开发者发放的自定义轮回天赋礼包。

## 主要功能

- 收件箱展示到达当前身份的消息。
- 已发送区域展示玩家已经发出的消息。
- 写邮件区域选择接收身份并编辑内容。
- 附件领取把轮回天赋转入接收者所有权。
- 礼包邮件展示自定义天赋、有效时间、领取资格和当前领取状态；已登录账号可在有效条件满足时领取。
- 定向礼包可只面向指定注册账号，广播礼包为每个注册账号分别保留一次领取机会；匿名诊断邮箱不具备礼包领取资格。
- 礼包天赋领取后进入账号的轮回天赋库，沿用轮回天赋页面与后续人生的既有使用路径。
- 删除或到期结果按附件所有权规则完成退回或回收。

## 视觉补充

- 邮箱以收件箱/已发送页签、邮件列表和展开详情组成；写信、领取和删除动作保持在对应邮件上下文内。

## 边界

页面维护展开、编辑和领取反馈状态。邮件、收件状态、礼包资格与领取账本由邮箱服务维护；账号注册时间、最近登录时间、会话和轮回天赋库仍由账号服务维护。

## 礼包边界

- 开发者通过现有运维邮件入口创建稳定 `rewardId` 的奖励活动，不新增后台页面、外部发送服务或 AI 调用。
- 奖励活动使用 `login-window` 或 `registered-account` 资格模式，默认采用 `login-window` 且从发送时起三天有效；`registered-account` 允许活动结束前已注册、当前已登录的账号领取；开始和结束时间由活动定义明确给出。
- 每个 `rewardId` 与注册账号只允许一条成功领取记录。重复领取返回已领取状态，不重复写入天赋，也不改变当前人生中的普通命格。
- 自定义天赋必须符合现有轮回天赋契约，可填写类别、稀有度、效果及 `physique`、`mind`、`talentAptitude`、`charisma`、`luck` 属性点；领取后不经 AI 改写。
