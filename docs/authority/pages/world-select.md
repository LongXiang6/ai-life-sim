# 世界选择界面

## 目标

世界选择界面让玩家从已有世界中选择一个世界，或填写新的自定义世界；确认后直接进入角色创建。

## 主要功能

- 世界条目展示名称、描述、时代与关键特征。
- 搜索用于按可见世界信息缩小候选范围。
- 选择确认在本地建立目标世界的开局上下文，并直接进入角色创建。
- 自定义世界输入与预设世界使用同一确认路径，不进入独立的世界规则配置页面。
- 当前 Prompt 版本已有命格候选池或有效抽取页状态时，刷新/清除按钮固定在世界卡片角落；它只清除当前 `worldCode` 对应的命格候选池与命格抽取页状态缓存，不恢复已退役的世界初始化 AI 缓存。旧 Prompt 版本候选池由命格缓存所有者自动删除，不显示为可用或可清理缓存。显示或清除缓存不改变卡片正文的水平起点和网格几何。

## 视觉补充

- 世界选择以“当前选中世界 + 来源目录 + 自定义入口”的章节页面呈现；切换来源不会改变确认契约，仍由当前页面直接进入角色创建。

## 深层机制

世界首次进入使用[世界初始化机制](../mechanisms/world-initialization.md)建立本地上下文；该流程不发起世界配置 AI 调用。

缓存版本识别与旧资产删除由命格池所有者负责；失去当前版本候选池支撑的 AI 抽取页状态由抽取页状态所有者删除。缓存清除由两个所有者提供按世界编号的公开命令，世界选择页只负责消费当前版本投影、调用和呈现确认；页面不得直接拼接存储键，也不得清除其他世界、设置或长期角色草稿。
