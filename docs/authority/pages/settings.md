# 设置界面

## 目标

设置界面让玩家调整阅读体验、叙事偏好和玩家自有模型调用。

## 主要功能

- 阅读与界面设置调整视觉和动态效果。
- 叙事偏好设置调整文风与篇幅；核心回合只执行正式故事调用，不启动下一轮预生成请求。
- 模型与调用设置保存玩家自己的 API 地址、密钥、模型和推理强度；兼容 OpenAI 协议的官方地址或自定义中转地址均沿用同一组配置；温度可在 `0–1.2` 范围内调整。
- 玩家可以为一组自定义地址、密钥和模型命名并保存在当前浏览器，之后点击名称即可切换；配置档案不自动云同步，Key 只以脱敏形式展示。
- 自定义模型请求能否成功取决于服务端能否访问目标地址；手机 VPN 只改变手机到游戏服务的连接，不能替代服务端访问目标所需的网络条件。
- 界面主题使用低饱和淡黄色纸面与浅色强调色，避免高饱和黄色造成阅读压力。
- 数据统计展示当前玩家调用产生的用量、缓存和费用结果。
- 外观设置只保留实际控件及其必要说明，不重复展示与控件说明相同的引导标题或介绍段落。
- 数据统计卡片沿用全局淡黄色语义色，不使用残留的蓝色面板、边框或进度强调色。
- 设置及其子面板统一消费全局淡黄色语义色；辅助背景、输入面、边框和选中态不得比主题基准更暗。

## 边界

设置改变后续调用和展示。已经发布的故事保持原结果。
