# 设置界面

## 目标

设置界面让玩家调整阅读体验、叙事偏好和玩家自有模型调用。

## 主要功能

- 阅读与界面设置调整视觉和动态效果。
- 叙事偏好设置调整文风与篇幅；“预生成下一轮”开关控制本轮两路后调用完成并提交后，是否提前请求下一轮主故事正文。关闭时不创建投影、不请求预生成正文并清空尚未消费的瞬态结果。
- 模型与调用设置保存玩家自己的 API 地址、密钥、模型和推理强度；兼容 OpenAI 协议的官方地址或自定义中转地址均沿用同一组配置；温度可在 `0–1.2` 范围内调整。
- 玩家可以为一组自定义地址、密钥和模型命名并保存在当前浏览器，之后点击名称即可切换；配置档案不自动云同步，Key 只以脱敏形式展示。
- 自定义模型请求能否成功取决于服务端能否访问目标地址；手机 VPN 只改变手机到游戏服务的连接，不能替代服务端访问目标所需的网络条件。
- 界面主题提供阅读、暗夜、白色、多彩四套基础方案：阅读主题沿用低饱和淡黄色纸面，暗夜主题使用低亮度深色层次，白色主题使用中性白色与浅灰层次，多彩主题以纯白为整体背景并提供鲜艳明亮的可选强调色；四套主题都保持正文高可读和稳定层级。
- 多彩主题可选用赤、橙、黄、绿、青、蓝、紫等清晰高对比语义色，用于状态、标签、分类、稀有度和提示等界面元素；不要求七色同时出现，不使用深沉、朦胧或低对比配色。
- 主题选择即时生效并在当前浏览器持久化；开始新人生、清除游戏进度和故事存档不清除主题偏好。
- 叙事偏好提供第一人称、第二人称、角色名称自适应三种称呼方式，默认第二人称；称呼选择只影响后续主叙事动态 Prompt 的组装，不改已经发布的故事、故事状态或输出协议。
- 数据统计展示当前玩家调用产生的用量、缓存和费用结果。
- 外观设置只保留实际控件及其必要说明，不重复展示与控件说明相同的引导标题或介绍段落。
- 数据统计卡片沿用全局淡黄色语义色，不使用残留的蓝色面板、边框或进度强调色。
- 设置及其子面板统一消费当前主题的语义色；辅助背景、输入面、边框和选中态必须维持主题内的层次和正文对比度，不得残留其他主题的背景色。
- 设置作为独立页面打开时，键盘可以依次到达页内分类、设置控件和页面底部现有返回/完成操作；只有真正的弹窗实例限制焦点在模态范围内。
- 设置页面的辅助状态、分类元信息和操作说明保持可持续阅读的字号与对比度；移动端分类栏应能发现并触达全部现有分类，不改变分类数量或设置契约。

## 视觉补充

- 设置页面按外观、叙事、模型调用、预设和统计分组为可扫描的工作台，保留现有页签、即时生效和返回路径。

## 边界

设置改变后续调用和展示。已经发布的故事保持原结果。
