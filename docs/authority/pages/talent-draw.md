# 命格界面

## 目标

命格界面让玩家从有效候选中选择本局普通天赋，并查看已经携带的轮回天赋。普通候选以灵躯蜕变、万象听令、洞察天机、万灵随行、造化成形五路命途呈现；轮回天赋单独使用第六个页签。

## 主要功能

- 候选区域展示名称、资质阶位、开发阶段、简要说明和属性加成，不展示单独的详细效果段；普通候选的简介由生成 Prompt 引导为约30至45字的画面化短句，完整触发、作用机制、边界与代价保留在效果字段并由命格所有者传给故事和成长调用，不通过运行时截断、拒收或额外 AI 调用实现文风或简介检查。
- 选择操作明确当前已选数量和可替换状态。
- 普通命格与轮回天赋共用四个携带槽，四项是容量上限而非必选数量；选择零至四项均可确认并进入属性分配。确认只固化实际选中的天赋，空槽不生成或传递占位天赋。
- 轮回天赋区域展示跨局携带结果，并保持与普通命格分离。
- 展示层沿用创建流程的共享页面标题、步骤、返回与底部操作区。抽取阶段使用紧凑、静态的操作台布局，按五类展示首批进度，每类显示已接纳数与四个固定位置，并同时展示总数、当前状态、最近纳入的命格和就近错误；不使用仪式舞台、背景山水、光环或逐格揭示。
- 五类首批条件全部满足时立即显示完成态并开放选择入口，不增加逐格回放或完成后的等待。候选进度只反映现有候选池发布结果，完成判定仍由各类首批条件决定。
- 选择阶段保留四个可移除的携带槽、五类普通命格与轮回天赋共六个页签，以及候选说明、属性加成、重新抽取和确认操作。桌面候选双列、移动端单列；使用中性实底、细分隔线和清晰强调色，不使用持续呼吸、发光或流动动画。
- 页面只重排既有候选、携带槽、等待、错误和确认信息，不新增命格状态、AI 调用、持久化字段或跳转路径。
- 五类普通命格首批由五个独立主机制族调用组成，每类目标四条，共二十条；每类只调用一次，资质阶位由 AI 按能力机制复杂度评定为 1 至 3 阶，不设概率或配额。五类首批调用完成后才进入选择页。轮回天赋沿用独立跨局库，不进入普通候选池。
- 进入选择页后，五类候选分别在后台继续补充，每类达到十二条即停止，完整池目标为六十条；后台补充不改变已经选中的携带槽。
- 刷新或重新进入页面时，只从同一世界与当前 Prompt 版本的候选缓存恢复五类计数；非当前版本候选池自动删除，不读取、不迁移、不兼容。只有每类至少四条普通候选时才把首批标记为完成，任一分类不足四条都不进入选择交接；AI 抽取页状态失去当前版本候选池支撑时同样自动删除。
- 从角色创建确认进入时，同一缓存判定已满足选择页条件则首次渲染直接打开选择阶段，不展示抽取页或等待状态；缓存不存在或不足时仍先进入抽取阶段。
- 候选按分类增量接纳；单条字段或单条命格无法识别时只放弃该条，其余有效命格继续显示。
- 候选名称、题材和效果的重复风险由主机制族 Prompt 接收全池名称及本类已有候选摘要后直接避免；五路命途按能力主要生效机制整理为灵躯蜕变、万象听令、洞察天机、万灵随行、造化成形。主机制族不是能力类型白名单；复制、获取、成长、进化、时空、因果、契约、任务和系统面板等机制可以作为子型或表现形式自由组合，每条候选只归入最主要的一族。五路命途的机制边界分别是身体、精神、形态、属性或成长进化的直接改变；主动影响外物、能量、元素、空间、时间或因果关系；获得、解析、标记、预测或呈现信息；召唤、契约、复制体、伙伴或独立行动单元；创造、合成、炼化、复制、提取或改变对象性质。每条候选必须是类似游戏、小说中觉醒天赋的稳定能力：有明确名称、适用或触发条件、主动使用或可观察的生效机制、有限效果与边界，而不是孤立的身体素质、性格标签、训练履历或身份设定。资质阶位衡量能力机制的复杂度，不衡量影响范围或强度：从单一直接机制、带条件分支的机制、多机制联动，递进到边界清楚的规则与概念机制。阶位名称依次为普通、良好、优秀、卓越、史诗、传说、神话、本源、至高。初抽只生成 1 至 3 阶，开发阶段初始为初醒；不建立全民觉醒制度或其他模拟世界社会设定。能力题材与机制多样性来自原创变化，不照搬作品设定或原句。每条候选必须提供实际正向收益，存在负面效果时必须同时提供明确、可兑现的额外补偿，不能生成只有损失、限制、惩罚或负属性的纯负面天赋。简介使用约30至45字的动作、画面或异常现象呈现能力与可见结果；完整效果写清触发条件、作用机制、边界及真实代价。主语和首句入口应在天赋名、能力机制、触发条件、动作或世界反馈之间变化，不默认使用“此人”“该角色”“这位人物”“此天赋”或“拥有……”的同构开头。运行时对候选名称执行规范化身份 canonicalization，同一规范名称只保留首次有效候选，保证页面和缓存不会显示同名记录。运行时仍不按语义相似度、关键词或换写效果过滤；相同业务身份 ID 也只保留一次。旧缓存恢复和写回前使用同一名称 canonicalization。

## 五路命途

- **灵躯蜕变**：以身体、精神、形态、属性或成长进化产生直接改变为主，可包含再生、适应、熟练度和变身子型。
- **万象听令**：以主动影响外物、能量、元素、空间、时间或因果关系为主，可包含念动力、元素、矢量和时空子型。
- **洞察天机**：以获得、解析、标记、预测或呈现信息为主，可包含鉴定、预感、读心、记忆和系统面板子型。
- **万灵随行**：以召唤、契约、复制体、伙伴或独立行动单元为主，可包含任务、契约和临时借用子型。
- **造化成形**：以创造、合成、炼化、复制、提取或改变对象性质为主，可包含制造、资源转化和能力获取子型。

五路命途只用于候选编排和页面浏览，不是能力类型白名单。天赋是玩家独有的外挂金手指，能力范围开放，包含特异功能、超能力、异常能力、修炼能力、游戏技能、系统面板等，不由世界题材决定是否允许出现。复制、获取、成长、进化、时空、因果、契约与任务等机制可组合为各命途的子型；系统面板是表达载体，可以承载不同主机制，不单独限定能力作用。世界观只影响抽取倾向、表现形式、术语、适配方式和后续世界反应；适配题材的能力更常见，现代都市或纯科幻世界也保留抽取修炼、玄幻等跨题材天赋的可能，不设置固定题材配额或数值概率。跨题材能力可以提供自身成立所需的局部机制，不因此把整个世界改成对应力量体系，也不补造角色前史。资质阶位衡量机制复杂度，不代表影响范围、数值强度或必胜程度；任一阶位都按具体效果写清真实边界。角色种族、身份与背景用于适配能力的发动载体，不否定金手指；初抽候选不直接给出无条件的全局结果、绝对控制、必然命运、无限持续或无需输入即可获得一切信息与资源的效果。

## 深层机制

玩家当前选中的普通天赋与轮回天赋都可以在故事推进中自动形成成长机会，由[后调用](../mechanisms/core-round/post-story-analysis.md)中的天赋成长负责；程序先依据本局总次数、单条天赋次数、回合间隔、模拟时间间隔、证据窗口和当前开发阶段筛选候选，再按本轮种子进行一次本地机缘判定。命中后才调用成长 AI 生成路线；未命中不调用 AI，也不显示成长面板。

成长结果对应本次机缘命中的当前版本，并按固定顺序提供深度强化、广度强化、转变强化三个开发方向供玩家选择；成长只推进开发阶段，不提升资质阶位。初醒到掌握至少需要两个证据窗口，掌握到圆满至少需要三个；同时保留 16 岁起始、冷却和次数门槛。机缘类型分为顿悟、危机觉醒、传承回响、异变，只影响路线表现和代价，不改变进阶成功率。普通命格与轮回天赋沿用各自的长期身份与命途分类。长期身份只串联成长记录，不要求历代能力相似；命途分类只用于整理候选，不代替资质阶位，也不限制能力类型。

每个成长结果展示当前天赋与三条开发路线。深度强化基于当前能力提高同类机制的掌握；广度强化基于当前能力增加适用场景；转变强化依据玩家本局已经发生的经历和机缘气质重新塑造能力，可以改变作用对象和机制组合，但不得删除或削弱已经成立的核心能力。三条路线没有高下之分，均推进同一个开发阶段；路线提供完整效果，不默认叠加历代效果。每条路线包含路线、名称、详细介绍、效果描述与成长后的完整属性加成；名称为二至六个汉字并优先四字，保留古朴有力的幻想质感。简介以动作、画面或异常现象呈现能力与可见结果；完整效果写清触发、机制、边界与真实代价。使用叙事逻辑说明能力会给剧情带来什么变化，不写成功率、判定值、触发率、冷却或其他系统化措辞；比喻最多一处且只能点明效果，不堆砌意象、典故、倒装或玄虚套话。属性加成使用心智、体魄、魅力、财富或低概率出现的气运；允许用负属性抵扣正属性，但每条天赋的正向净加成与负属性绝对值均不得超过资质阶位乘以2，属性点不要求用满。成长后的完整加成不是本轮增量，同向路线不得无故弱于当前词条。

开发阶段依次为初醒、掌握、圆满；资质阶位依次为普通、良好、优秀、卓越、史诗、传说、神话、本源、至高。资质衡量机制复杂度，不决定影响范围或效果强度；开发阶段表示当前机制的掌握程度。已选天赋携带当前属性加成；属性字段包含心智、体魄、魅力、财富与稀有气运。属性加成的正向净值与负值绝对值分别不得超过资质阶位乘以2，至高上限为18。每条天赋本局最多成长两次，本局总成长最多六次；单条天赋再次进入候选必须同时满足至少20轮和严格超过20年的程序冷却。

资质阶位完整顺序为普通、良好、优秀、卓越、史诗、传说、神话、本源、至高。初抽仅产生1至3阶：1阶为单一直接机制，2阶包含改变结果的条件分支或可选择作用方式，3阶为多个子机制联动、前一机制的结果成为后一机制的输入。发动动作、通常限制和副作用不算额外子机制，单纯更强、更远、更准或更持久不构成升阶理由；高阶递进至有明确边界的规则与概念机制，不直接表示影响范围或强度。开发阶段为初醒、掌握、圆满；局内成长只推进开发阶段，初醒到掌握至少两个证据窗口，掌握到圆满至少三个，完成圆满后不再局内成长。轮回时资质升一阶，最高至至高，开发阶段重置为初醒；新效果必须保留既有能力，不得倒退。资质到达至高后沿用现有强化成败与异变机制，字段为 apexStrengthenLevel；属性边界仍为18。成长及轮回依据玩家已经发生的经历和机缘发展，不以世界题材否定或降格能力。条件、限制或代价依据天赋自身机制与实际交互说明，题材和名称不替代实际效果，也不得替角色补写能力来源、成长经历、既定身份或未来事件。资质、开发阶段、效果与属性遵循各自边界。

## 协议迁移边界

新天赋契约只接受资质阶位与开发阶段双轴字段，不读取或转换旧天赋形状、旧等级或类别别名。本地轮回库、旧天赋候选缓存和持久化角色状态中的天赋部分执行一次性清理，角色创建草稿等非天赋字段保留；账号库和玩家内容库分别原子清理旧轮回天赋、邮件天赋附件与托管记录、奖励天赋记录，同时保留邮件正文、账号设置、人生记录和无关数据。整局存档格式为v3；既有v2存档继续保留并按不兼容策略拒绝读取，不迁移或自动删除。

成长证据先由本地按时间和来源做机械装配。一个证据窗口唯一对应一个来源故事回合；同一回合经连续性提取形成的多条记忆、多个事实日期或重复正文合并为同一窗口，不能增加窗口数量。窗口起点必须严格晚于当前版本开发阶段生效时间，生效同日、跨越生效时间、无法证明更晚以及成长选择、改名、效果说明和属性调整记录都不进入该候选的可用窗口；窗口数量尚未达到目标开发阶段最低门槛的候选不进入机缘判定。本地只检查窗口数量、时间、冷却、次数和证据水位，不判断窗口是否真正体现天赋；门通过后按本轮存档种子进行一次确定性机缘判定，未命中不调用 AI，命中后成长 AI 只为该天赋生成三条路线，不再判断是否成长。命中后若 AI 调用或契约失败，不记录该天赋的证据水位，下一轮可继续尝试；其他候选已经完成的判定水位照常提交。成长依据只能引用输入窗口已经明确写出的事实，三条路线的名称和效果都必须形成实质不同的发展方向。
