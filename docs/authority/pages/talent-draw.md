# 命格界面

## 目标

命格界面让玩家从有效候选中选择本局普通天赋，并查看已经携带的轮回天赋。普通候选固定分为战斗、探索、社交、生产四类；轮回天赋单独使用第五个页签。

## 主要功能

- 候选区域展示名称、等级、说明和长期效果。
- 选择操作明确当前已选数量和可替换状态。
- 确认操作固化本局普通天赋。
- 轮回天赋区域展示跨局携带结果，并保持与普通命格分离。
- 首批生成由四个独立分类调用组成，每类目标四条；四类首批调用完成后才进入选择页。
- 进入选择页后，四类候选分别在后台继续补充，每类达到十二条即停止；后台补充不改变已经选中的携带槽。
- 刷新或重新进入页面时，从同一世界与 Prompt 版本的候选缓存恢复四类计数；缓存缺少任一普通分类时不把首批标记为完成。
- 候选按分类增量接纳；单条字段或单条命格无法识别时只放弃该条，其余有效命格继续显示。

## 深层机制

玩家当前选中的普通天赋与轮回天赋都可以在故事推进中形成成长结果，由[后调用](../mechanisms/core-round/post-story-analysis.md)中的天赋成长负责；是否进入 AI 候选由程序依据本局总次数、单条天赋次数、回合间隔和模拟时间间隔先行筛选。

成长结果对应原始已选天赋，并按固定顺序提供深度强化、广度强化、转变强化三个下一阶方向供玩家选择；普通命格与轮回天赋沿用各自的长期身份、类别和当前效果。类别为战斗、探索、社交或生产，只说明主要发挥领域，不代替等级判断。

每个成长结果只包含原始天赋名称与三条升级路线。深度强化沿原路走得更深，使同一场景下的优势更显著、同类事件中的影响力更强；广度强化沿原路走得更宽，使能力适用的场景增加；转变强化使能力的作用方式发生根本性变化，不再沿用原来的用法。三条路线没有高下之分，必须处在同一目标等级和同一总预算内；转变强化只改变作用方式，不额外扩大影响总量。每条路线包含路线、名称、详细介绍、效果描述与成长后的完整属性加成；名称为二至六个汉字并优先四字，保留古朴有力的神话感。介绍先直接说明能力；只有确有条件、限制或属性牺牲时才补充相应说明，不要求每条路线都写代价。使用叙事逻辑说明能力会给剧情带来什么变化，不写成功率、判定值、触发率、冷却或其他系统化措辞；比喻最多一处且只能点明效果，不堆砌意象、典故、倒装或玄虚套话。属性加成使用体魄、心智、悟性、魅力或低概率出现的气运；允许用负属性抵扣正属性，但每条路线的负属性绝对值总和与净分配都不得超过目标等级总量。普通、精良、稀有、史诗、传说、神话的总量上限分别为 2、4、6、8、10、12；这些既是 Prompt 创作边界也是本地提交校验边界，不要求路线用满，也不要求高等级实际点数必然高于低等级。成长后的完整加成不是本轮增量，同向路线不得无故弱于原词条。

已选天赋携带当前属性加成；属性字段包含体魄、心智、悟性、魅力与稀有气运，字段含义由系统 Prompt 说明，路线属性加成与当前属性使用同一字段体系。每条天赋本局最多进阶两次，本局总进阶最多六次；单条天赋再次进入候选必须同时满足至少 20 轮和严格超过 20 年的程序冷却。

等级完整顺序为普通、精良、稀有、史诗、传说、神话；基础抽取只生成普通候选，局内成长封顶传说，神话只由轮回升阶路径产生并继续强化。普通只提供比常人更精、更稳或更持久的局部优势，仍受输入世界与凡俗尺度约束；题材可以是幻想、虚幻、神秘、象征或轻微异常，但题材变化不得抬高强度，也不得替角色补写能力来源、成长经历、既定身份或未来事件。精良形成独到造诣，能以非常之法处理问题，但仍受世界边界约束；稀有能在关键时刻短暂撬动常理并逆转局势，必须付出明确代价且不能久持；史诗是人间传说，能在自身所及领域内改写原本成立的逻辑；传说是所属领域的历史性巅峰与代名词；神话不再只是能力，而是所属概念本身的具象化。名称、效果和属性都必须服从同一等级边界。

成长证据先由本地按时间和来源做机械装配。一个证据窗口唯一对应一个来源故事回合；同一回合经连续性提取形成的多条记忆、多个事实日期或重复正文合并为同一窗口，不能增加窗口数量。窗口起点必须严格晚于当前版本本级生效时间，生效同日、跨越生效时间、无法证明更晚以及成长选择、改名、效果说明和属性调整记录都不进入该候选的可用窗口；可用窗口数量尚未达到目标等级最低门槛的候选不进入 AI 请求。本地不判断窗口是否真正体现天赋，也不决定成长。AI 对剩余候选逐项检查：有条件的当前效果只有在同一窗口中明确发生全部必要触发条件，并且核心能力实际表现出结果时才能计入；任一缺失，或需要用“未直接触发”“类似环境”“能力延伸”“可以视为”及同义解释关联时，该窗口都不构成证据。普通升精良至少需要两个不同后续窗口，其中一个形成稳定成功结果；精良升稀有至少需要三个不同后续窗口，且包含一次重要挑战结果；稀有升史诗至少需要四个不同后续窗口，且包含一次影响群体或局部区域的重大结果；史诗升传说至少需要五个不同后续窗口并贯穿长期阶段，其中至少两次在重大事件中形成决定性结果。任一语义门槛不足时不生成路线；成长依据只能引用输入窗口已经明确写出的事实，三条路线的名称和效果都必须形成实质不同的发展方向。
