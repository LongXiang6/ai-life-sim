# 命格界面

## 目标

命格界面让玩家从有效候选中选择本局普通天赋，并查看已经携带的轮回天赋。普通候选固定分为根基、专精、特质、规则、机缘五类；轮回天赋单独使用第六个页签。

## 主要功能

- 候选区域展示名称、等级、说明和长期效果。
- 选择操作明确当前已选数量和可替换状态。
- 确认操作固化本局普通天赋。
- 轮回天赋区域展示跨局携带结果，并保持与普通命格分离。
- 展示层沿用创建流程的章节化书页骨架：运行头显示当前步骤，抽取阶段突出命印归位状态，选择阶段把携带槽、分类页签、候选比较与当前确认状态按“上下文 → 核心内容 → 当前操作”排列；桌面端允许候选双列扫描，移动端收束为单列。
- 页面只重排既有候选、携带槽、等待、错误和确认信息，不新增命格状态、AI 调用、持久化字段或跳转路径。
- 五类普通命格首批由五个独立宏观原型调用组成，每类目标四条，共二十条；五类首批调用完成后才进入选择页。轮回天赋沿用独立跨局库，不进入普通候选池。
- 进入选择页后，五类候选分别在后台继续补充，每类达到十二条即停止，完整池目标为六十条；后台补充不改变已经选中的携带槽。
- 刷新或重新进入页面时，只从同一世界与当前 Prompt 版本的候选缓存恢复五类计数；非当前版本候选池自动删除，不读取、不迁移、不兼容。只有每类至少四条普通候选时才把首批标记为完成，任一分类不足四条都不进入选择交接；AI 抽取页状态失去当前版本候选池支撑时同样自动删除。
- 从角色创建确认进入时，同一缓存判定已满足选择页条件则首次渲染直接打开选择阶段，不展示抽取页、等待状态或封印归位回放；缓存不存在或不足时仍先进入抽取阶段。
- 候选按分类增量接纳；单条字段或单条命格无法识别时只放弃该条，其余有效命格继续显示。
- 候选名称、题材和效果的重复风险由分类 Prompt 接收全池名称及本类已有候选摘要后直接避免；五类只提供“根基、专精、特质、规则、机缘”五种宏观整理视角，不限制候选只能属于某种能力类型。每条候选必须是类似游戏、小说中觉醒天赋的稳定能力：有明确名称、适用或触发条件、主动使用或可观察的生效机制、有限效果与边界，而不是孤立的身体素质、性格标签、训练履历或身份设定。能力类型决定能做什么，稀有度决定做到什么程度；普通级也保留输入世界允许的能力本质，不把特殊机制降格为普通观察力、熟练技巧或属性加成。候选之间的多样性来自作用机制差异，而非同一能力换名。每条候选必须提供实际正向收益，存在负面效果时必须同时提供明确、可兑现的额外补偿，不能生成只有损失、限制、惩罚或负属性的纯负面命格。描述与效果必须直接落到技能机制、触发条件、动作、可观察现象或结果，主语和首句入口应在天赋名、能力机制、触发条件、动作或世界反馈之间变化，不默认使用“此人”“该角色”“这位人物”“此天赋”或“拥有……”的同构开头。运行时对候选名称执行规范化身份 canonicalization，同一规范名称只保留首次有效候选，保证页面和缓存不会显示同名记录。运行时仍不按语义相似度、关键词或换写效果过滤；相同业务身份 ID 也只保留一次。旧缓存恢复和写回前使用同一名称 canonicalization。

## 五类职责

- **根基**：呈现能力的底层倾向，可落到身体、心智、感知、关系、资源或其他载体。
- **专精**：呈现可被调用、练习或深化的明确优势，题材与使用场景不限。
- **特质**：呈现稳定的能力特性、主动技能、被动倾向或条件效果，不等同于性格标签。
- **规则**：呈现清晰的触发—作用—结果机制，可作用于行动、认知、关系、资源、环境或特殊现象。
- **机缘**：呈现机会、适配、共鸣或轻微偏转等高层原型，仍受普通等级边界约束。

五类只用于候选编排和页面浏览，不是能力类型白名单；同一批可以出现不同能力类型，普通等级决定强度、范围、确定性与效果边界，不决定是否允许某种能力。世界题材决定可成立的机制、表现形式和术语；角色种族、身份与背景只限定其实际拥有的通道，不补造能力来源、经历或世界机制。任何世界允许的能力类型都可以生成其低阶、有限、可观察的版本，特殊能力必须真实改变对应对象或规则，而不是只用名称暗示特殊性；普通候选仍不直接给出无条件的全局结果、绝对控制、必然命运、无限持续或无需输入即可获得一切信息与资源的效果。

## 深层机制

玩家当前选中的普通天赋与轮回天赋都可以在故事推进中形成成长结果，由[后调用](../mechanisms/core-round/post-story-analysis.md)中的天赋成长负责；是否进入 AI 候选由程序依据本局总次数、单条天赋次数、回合间隔和模拟时间间隔先行筛选。

成长结果对应本次待成长天赋的当前版本，并按固定顺序提供深度强化、广度强化、转变强化三个下一阶方向供玩家选择；普通命格与轮回天赋沿用各自的长期身份与宏观整理标签。长期身份只串联成长记录，不要求历代能力相似；类别为根基、专精、特质、规则或机缘，只用于整理候选，不代替等级判断，也不限制能力类型。

每个成长结果展示当前天赋与三条升级路线。深度强化基于当前能力提高同类效果；广度强化基于当前能力增加适用场景；转变强化依据玩家本局已经发生的经历和突破契机重新塑造能力，可以改变能力类型、作用对象和核心机制，不要求保留最初天赋或上一版本的能力特征。连续选择转变强化后，新天赋可以与最初天赋毫不相干；因果依据来自玩家经历，而不是能力名称或机制相似度。三条路线没有高下之分，均处在同一目标等级边界内；转变路线提供替换后的完整能力，不默认叠加历代效果。每条路线包含路线、名称、详细介绍、效果描述与成长后的完整属性加成；名称为二至六个汉字并优先四字，保留古朴有力的神话感。介绍先直接说明能力；只有确有条件、限制或属性牺牲时才补充相应说明，不要求每条路线都写代价。使用叙事逻辑说明能力会给剧情带来什么变化，不写成功率、判定值、触发率、冷却或其他系统化措辞；比喻最多一处且只能点明效果，不堆砌意象、典故、倒装或玄虚套话。属性加成使用心智、体魄、魅力、财富或低概率出现的气运；允许用负属性抵扣正属性，但每条路线的负属性绝对值总和与净分配都不得超过目标等级总量。普通、精良、稀有、史诗、传说、神话的总量上限分别为 2、4、6、8、10、12；这些既是 Prompt 创作边界也是本地提交校验边界，不要求路线用满，也不要求高等级实际点数超过低等级。成长后的完整加成不是本轮增量，同向路线不得无故弱于当前词条。

已选天赋携带当前属性加成；属性字段包含心智、体魄、魅力、财富与稀有气运，字段含义由系统 Prompt 说明，路线属性加成与当前属性使用同一字段体系。每条天赋本局最多进阶两次，本局总进阶最多六次；单条天赋再次进入候选必须同时满足至少 20 轮和严格超过 20 年的程序冷却。

等级完整顺序为普通、精良、稀有、史诗、传说、神话；基础抽取只生成普通候选，局内成长封顶传说，神话只由轮回升阶路径产生并继续强化。普通是任意世界允许能力的低阶形态，保留真实机制且作用局部、有限；精良在同类机制中形成更明显、稳定的优势；稀有的特殊作用能在关键场景改变局势；史诗能在自身所及领域内改写原本成立的逻辑；传说是所属领域的历史性巅峰与代名词；神话是所属概念本身的具象化。等级决定能力的强度和效果边界，不把某种能力类型专属分配给某个等级。条件、限制或代价依据具体机制与世界规则说明，题材和名称不替代实际效果，也不得替角色补写能力来源、成长经历、既定身份或未来事件。名称、效果和属性都必须服从同一等级边界。

成长证据先由本地按时间和来源做机械装配。一个证据窗口唯一对应一个来源故事回合；同一回合经连续性提取形成的多条记忆、多个事实日期或重复正文合并为同一窗口，不能增加窗口数量。窗口起点必须严格晚于当前版本本级生效时间，生效同日、跨越生效时间、无法证明更晚以及成长选择、改名、效果说明和属性调整记录都不进入该候选的可用窗口；可用窗口数量尚未达到目标等级最低门槛的候选不进入 AI 请求。本地不判断窗口是否真正体现天赋，也不决定成长。AI 对剩余候选逐项检查：有条件的当前效果只有在同一窗口中明确发生全部必要触发条件，并且核心能力实际表现出结果时才能计入；任一缺失，或需要用“未直接触发”“类似环境”“能力延伸”“可以视为”及同义解释关联时，该窗口都不构成证据。普通升精良至少需要两个不同后续窗口，其中一个形成稳定成功结果；精良升稀有至少需要三个不同后续窗口，且包含一次重要挑战结果；稀有升史诗至少需要四个不同后续窗口，且包含一次影响群体或局部区域的重大结果；史诗升传说至少需要五个不同后续窗口并贯穿长期阶段，其中至少两次在重大事件中形成决定性结果。任一语义门槛不足时不生成路线；成长依据只能引用输入窗口已经明确写出的事实，三条路线的名称和效果都必须形成实质不同的发展方向。
