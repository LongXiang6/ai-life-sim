# 角色创建界面

## 目标

角色创建界面让玩家建立本局主角的初始身份和人生边界。

## 主要功能

- **姓名输入**确定故事中持续使用的角色称呼。
- **姓名生成按钮**为玩家提供一个可继续编辑的候选姓名。
- 身份、性别、背景和出身输入建立角色的开局事实。
- 节日范围在自定义选项中选择，并写入当前世界的唯一节日设置。
- 起始年龄确定故事从人生哪个阶段开始。
- 寿命范围确定本局生命风险的长期边界。
- 确认按钮把完整角色草稿交给后续命格与属性流程。
- 顶部角色摘要、事实卡片和表单辅助面使用比主体底色更白、更亮的纸面层次，不使用明显黄色摘要块或冷灰事实卡。

## 视觉补充

- 角色创建按“身份、生命边界、开局选项、背景”分段排列，顶部摘要持续显示当前角色、世界和已计算的人生边界；底部确认操作固定可达。

## 边界

页面承接尚未确认的草稿。确认后的角色事实由角色系统持续维护。
