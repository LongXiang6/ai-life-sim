# 欢迎界面

## 目标

欢迎界面让玩家识别产品主体，并选择继续已有进度、开始新人生或进入附属界面。

## 主要入口

- **开始新人生**进入本局重置与世界选择流程。
- **继续游戏**在存在可恢复进度且核心运行时已经就绪时进入该人生；初始化期间入口保持不可操作，不提前发起存档恢复。
- **排行榜、邮箱、设置、说明**进入对应附属界面，并保留返回主体界面的路径。

## 视觉与布局

- 页面基础层保持明亮清晰；使用多彩主题时以纯白为整体背景，鲜艳明亮的赤、橙、黄、绿、青、蓝、紫作为可选强调配色，不要求全部同时出现，也不使用深沉或朦胧的色彩。
- 开始、存档和辅助操作区跟随统一主体宽度，不使用独立的固定窄宽度。
- 桌面端在统一主体宽度内采用左右分区的序章构图：左侧呈现产品标题与进入说明，右侧集中主入口、存档和辅助操作，并在可用高度内保持平衡；不把完整欢迎内容压缩在窄列中。
- 移动端恢复单列顺序，主入口、存档和辅助操作保持可读、可达。
- “开始新人生”在悬停和键盘聚焦时保持当前主题的强调底色与高对比文字，不出现背景和文字同色的状态。
- 欢迎页主标题明确显示“人生模拟器”并带表情装饰；共享运行头的品牌文案仍由 `FlowRunningHead` 维护。

## 视觉补充

- 欢迎页以序章阅读页呈现：主入口优先，最近人生/存档紧随其后，账号、设置、说明、反馈、排行榜和邮箱作为可扫描的附属入口；页面不展示与实际状态无关的伪进度。

## 边界

欢迎界面负责入口和当前可用状态的展示。存档、账号、排行榜和邮箱结果由各自机制提供。
