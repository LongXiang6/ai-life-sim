# 欢迎界面

## 目标

欢迎界面让玩家识别产品主体，并选择继续已有进度、开始新人生或进入附属界面。

## 主要入口

- **开始新人生**进入本局重置与世界选择流程。
- **继续游戏**进入当前可恢复的人生进度。
- **排行榜、邮箱、设置、说明**进入对应附属界面，并保留返回主体界面的路径。

## 视觉与布局

- 页面外框、主体纸面和操作区使用明亮、低饱和、略带黄色的浅色层次，避免中心区域与两侧背景出现明显色差。
- 开始、存档和辅助操作区跟随统一主体宽度，不使用独立的固定窄宽度。
- 欢迎页及所有附属入口共享同一淡黄色主题下限，辅助面板只能使用主题基准或更白、更亮的颜色。

## 边界

欢迎界面负责入口和当前可用状态的展示。存档、账号、排行榜和邮箱结果由各自机制提供。
