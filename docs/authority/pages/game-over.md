# 人生结算界面

## 目标

人生结算界面把已经结束的人生整理成可阅读、可比较和可继承的结果。

## 主要功能

- 五维区域展示当前世界适配的评分维度和分值。
- 总分展示五项分值的统一结果。
- 评语与诗句概括本局人生。
- 重要经历展示结算采用的故事事实。
- 轮回区域展示可进入下一世的结果。
- 轮回天赋在神话以下按严格下一等级升阶；神话词条每次只尝试强化一级，程序先决定成败，再由 AI 描述既定结果。
- 重新结算由玩家显式触发完整结算流程。

## 视觉补充

- 结算页按“此生摘要 → 五维评鉴 → 重要经历 → 轮回结果 → 分享与下一世”顺序组织，评分图表和可操作结果都保留原数据来源与动作。
