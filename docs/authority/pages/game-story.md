# 核心故事界面

## 目标

核心故事界面让玩家阅读正式故事、观察当前人生状态并决定下一次推进。

## 主要功能

- 阅读区按正式顺序展示已经发布的故事；每条回合在正文前显示该轮年龄。
- 正文通过协议后立即出现；附加分析继续运行时，故事保持可阅读。
- 分支按钮把所选行动作为下一轮的一次性玩家行动。
- 自定义分支输入与预设分支互斥，并同样作用于下一轮。
- 时间步长切换保存新的推进尺度，从下一轮开始生效。
- 推进按钮启动下一轮核心模拟。
- 推进按钮在生成中与可推进状态保持相同的主文案、副文案和占位几何；生成中只以灰色禁用态表达等待，避免时间线内容上下跳动。
- 时间、属性状态、结局、已解决选择、成长结果和分析指标属于系统状态，不附着显示在已发布正文条目中；每轮年龄作为该条故事的时间标识显示；未解决的命运分支和待确认成长路线仍以独立交互控件呈现。
- 故事顶栏按“世界名称 · 时间”展示当前身份；世界名称可带确定性的语义 emoji，时间不额外添加 emoji。
- 只有故事条目发生年龄达到 16 岁后才展示天赋成长；路线以稀有度对应的浅色容器展示，属性变化逐项显示为带属性 emoji 的独立 chip，不显示“属性加成”前缀。
- 更多操作提供存档、反馈、结算和返回主体界面的入口。
- 核心故事主体继承所有稳定玩家界面共同使用的桌面宽度；不建立页面专属宽度，移动端继续占满可用宽度。
- 新人生进入故事页时默认选择一个月（`month:1`）作为推进步长；玩家手动选择或存档恢复的步长优先于该默认值。

## 视觉补充

- 故事页采用连续阅读布局：顶部显示世界、时间和角色摘要，正文时间线是主要阅读区域；每条正文前显示该轮年龄，其他系统状态与次级动作作为辅助层，未决分支和成长控件仍保持可操作且不被正文遮挡。
