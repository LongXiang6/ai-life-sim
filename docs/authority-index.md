# 项目权威索引

`D:\AI\AGENTS.md` 负责优先级和执行流程；本文件只负责把任务路由到活动权威树。

## 活动结构

```text
项目权威索引
├─ 界面树：玩家界面、页面机制、交互边界
├─ 系统树：架构层级、时间核心、系统职责、状态所有权
│  └─ 核心模拟：活动成员、回合管线、AI 写入、提交与恢复
└─ 逻辑树：跨界面和跨系统的端到端流程
```

活动权威只包含以下四份文件：

- [界面体系](authority/interface-tree.md)
- [系统体系](authority/system-tree.md)
- [逻辑体系](authority/logic-tree.md)
- [核心模拟](authority/core-simulation.md)

## 按需路由

| 任务范围 | 首选文档 | 跨边界时追加 |
|---|---|---|
| 单个页面、布局、交互、文案、原型 | 界面体系 | 状态所有权变化时读系统体系；流程变化时读逻辑体系 |
| MOD、组件、Store、公共 API、注册与依赖 | 系统体系 | 触及编排或活动子系统时读核心模拟 |
| AI Provider、模型、请求参数、响应终态、限速、缓存或 Token | 系统体系“应用与核心服务” | 触及 Prompt、协议或回合采用时追加核心模拟 |
| 时间推进、剧情进度、跨系统时间依赖 | 系统体系“时间核心原则”与核心模拟“时间驱动与剧情推进” | 端到端流程变化时追加逻辑体系“统一时间链路” |
| 创建流、存读档、账号云端、诊断、发布、世界切换 | 逻辑体系 | 只追加对应所有者的系统体系章节 |
| Prompt、协议、解析、结构化写入、回合推进 | 核心模拟 | 需要端到端调用关系时读逻辑体系 |

只读取目标章节和其中列出的实时源；不为获得上下文而完整读取历史档案。

## 文档标准

- 每棵活动权威树说明目标、当前运行机制、权责边界和实时源。
- 技能、目录、文件、编码、格式、命名、写法、排序和生成物的项目细节统一读取 [项目标准化契约](../../.agents/skills/ai-life-sim/references/standardization.md)；本索引只负责权威路由，不复制标准正文。
- 新界面、新系统、新功能、新跨系统流程或可复用运行策略必须在同一任务归入对应树；交付时唯一活动权威与实时实现保持一致，同一事实只保留一个位置。
- 相关代码、文档、测试、配置和资产归入对应项目与所有者，不在根目录或其他体系建立散落副本。
- 精简重复和无关内容，但不得省略系统目标、关键机制、所有权、边界、实时源或重要结果。
- 活动权威使用中文并随相关实现变化保持最新；代码注释不承担长期权威说明。
- 活动权威只有在存在可独立路由的主题，并且单文件接近或超过 `250` 行或 `20000` 字符时才拆分；单纯超过数字不构成拆分理由。
- 拆分后的主题文件以约 `60-200` 行、`4000-16000` 字符为目标，必须从本索引一跳可达；不建立内容过少的碎片文件，也不通过多层索引增加导航成本。
