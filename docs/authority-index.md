# 项目结果权威索引

本索引把产品结果分成四层。权威文档说明产品为什么存在、玩家得到什么结果、机制能够影响到哪里。代码写法、架构选择、文件组织和实施流程由对应 Skill 负责。

## 四层结构

1. [第一层：玩家表层](authority/interface-tree.md)描述玩家从欢迎页到结算页能够看见的完整产品。
2. [第二层：界面目录](authority/logic-tree.md)导航到每个界面的独立结果文档。
3. [第三层：机制目录](authority/system-tree.md)导航到跨界面或玩家不易直接感知的机制结果。
4. [第四层：核心回合下属机制](authority/core-simulation.md)导航到共同维护核心模拟的大型下属机制。

## 读取规则

- 页面目标读取第一层与对应第二层页面文档。
- 跨页面行为读取对应第三层机制文档。
- 核心模拟、Prompt、缓存、后调用和故事压缩读取核心模拟及其第四层文档。
- 简单页面行为在第二层写清结果后结束，不额外创建深层机制文档。
- 同一结果保留一个权威位置；上层提供导航和概览，下层拥有详细边界。

## 文档职责

- 权威文档使用产品语言描述目标、效果、输入边界、输出边界和玩家感知。
- Skill 使用工程语言描述读取顺序、架构方法、实现方式、文件规范和验证流程。
- 实时实现负责兑现权威结果；实现差异回到所属权威修正结果定义。
- 历史决定和审查报告保存形成过程，不参与活动结果裁决。
