测试中发现并修复：帮助 Markdown 在 Windows CRLF 或混合换行下无法识别二级标题，导致章节导航与正文锚点不一致。`renderMdToHtml()` 现先统一换行符；修复后正文稳定生成 10 个章节。

## 6. 非阻断限制

1. 2.7.4 存档不能自动导入 5.0.0，需要开始新人生。
2. 经济、政治、文化、生态、科技、完整力量体系、NPC、历史和地图等扩展系统仍处于延后状态。
3. AI 速度与结构化输出稳定性仍受模型、网络和服务商影响。
4. 当前结论不包含服务器部署；部署完成后还需执行线上冒烟测试。
