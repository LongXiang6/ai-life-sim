## 已发现问题

### P1 移动端核心叙事布局明显破坏

复现：

1. 在 `/game-story` 设置移动端视口，约 `390x844`。
2. 查看核心叙事界面。

现象：

- 左侧角色/状态栏没有折叠。
- `现代地球`、`测试者`、命格和属性文本被竖向挤压断行。
- 右侧正文区域被压缩。

影响：

- 移动端几乎不可正常阅读。
- 属于核心页面响应式问题。

可能归属：

- `src/mods/mod-pages/pages/game-story/GameStory.module.css`
- 游戏故事页布局容器与侧栏断点策略

### P1 时间步长从年切到月后，未推进时顶部时间回到当年正月

复现：

1. 当前在 `/game-story`，第 4 轮，顶部显示 `2003年`。
2. 点击时间步长按钮 `年`。
3. 在菜单中选择 `月`。
4. 不点击推进。

现象：

- 顶部立即显示 `2003年 · 正月`。
- 此时还没有执行“轻触，让岁月流转”。

风险：

- 角色已经完成 2003 年整年叙事，切到月后显示 `2003年 · 正月` 可能造成时间回退感。
- 需要继续点击一次月推进，确认系统是否会对齐到下一周期，或是否实际重复讲述已经覆盖过的 2003 年。

当前状态：

- 已切换到 `月`。
- 还没有点击推进。

相关代码线索：

- `src/foundation/constants/time-steps.ts`
- `src/mods/mod-engine/helpers/simulation-time-api.ts`
- `src/mods/mod-engine/subsystems/time-system.ts`
- `src/mods/mod-engine/subsystems/orchestrator-system.ts`
- `src/mods/mod-pages/pages/game-story/page.tsx`

初步判断：

- `setSimulationTimeStepByKey` 切换步长本身不推进时间。
- `orchestrator-system` 在下一次 narrative advance 时才调用时间对齐。
- UI 立即显示 `2003年 · 正月`，可能是展示层把当前 round 映射为新粒度后的结果。
- 是否构成真实 bug，需要下一次点击后确认。

### P2 存档弹窗在中等宽度下控件偏挤

复现：

1. 在 `/game-story` 点击 `存档`。
2. 视口约 `973x898`。

现象：

- 存档槽按钮和输入框高度约 21px。
- 按钮区域偏紧凑。
- 弹窗可操作，但视觉质量较弱。

影响：

- 不阻断流程。
- 影响弹窗可读性和点击舒适度。

可能归属：

- 存档弹窗组件样式
- 通用 modal/form token

### P2 命格库数量在生成后跳变

现象：

- 命格生成完成后曾显示 `命格库：15条`。
- 后续后台填充后显示变为 56/76 一类数字。

影响：

- 玩家可能误以为生成结果变化或系统状态不稳定。

建议：

- 区分“本次生成数量”和“总库数量”。
- 或在后台填充阶段显示明确状态。

### P2 命格生成加载文案有破坏沉浸感的技术广告味

示例：

- `HTTP/3 延迟降低30%`
- `1.8万亿参数`

影响：

- 与人生模拟叙事氛围不一致。
- 容易让玩家感觉正在看技术演示，而不是游戏。

建议：

- 改为世界观内文案。
- 避免模型规模、网络协议、性能广告类表达。

### P3 早期叙事意象重复

现象：

- 0 到 3 岁多次使用父亲夜里敲电脑、门缝透光、键盘声等意象。

优点：

- 与角色背景“对电脑和故事感兴趣”一致。

问题：

- 连续重复后事件变化不足。

建议：

- 保留电脑主题，但增加家庭互动、幼儿园前社交、健康、体魄 0 的身体弱项反馈。

### P3 测试名会被模型当作真实语义使用

现象：

- 角色名为 `测试者` 时，叙事中出现父亲认为 `测试` 是好名字的内容。

判断：

- 不一定是产品 bug。
- 但说明占位名或测试名会污染叙事沉浸。

建议：

- 测试用例改用自然姓名。
- 或在 prompt 中弱化名称拆字联想。

### P3 体魄 0 未被叙事体现

现象：

- 角色体魄为 0。
- 早期叙事没有明显体现体弱、易病或成长限制。

判断：

- 不阻断主流程。
- 但属性到叙事的映射还可以加强。
