## 发现问题

### P1 时间步长推进错误

复现：故事页从“年”切换到“月”，点击推进一次。

现象：显示从 `2001年 · 正月` 变为 `2002年 · 正月`，实际推进了一年而不是一个月。再切换到“日”并推进一次，显示从 `2002年 · 春 · 正月第1日` 变为 `2002年 · 春 · 杏月第1日`，实际推进到下个月首日而不是下一日。

影响：核心模拟时间轴不可信，会直接影响叙事、年龄、存档和事件系统。

### P1 自动保存状态回退

复现：故事页推进第 1、2、3、6 轮。

现象：推进完成时曾显示“已保存至第 N 轮”，预生成/缓存完成后又回到“未保存”。继续模拟入口仍可读到存档，但实时保存状态与实际数据不一致。

影响：用户无法判断当前进度是否真正保存，可能误操作退出。

### P1 存档管理页未注册

复现：打开 `/save-manager`。

现象：页面显示“路径 /save-manager 未在任何 MOD 的 routes 中注册”。源码中存在 `src/mods/mod-pages/pages/save-manager/page.tsx` 和导出，但 `src/mods/mod-pages/manifest.ts` 未注册该路由。

影响：用户无法查看、加载、删除具体存档槽位；手动存档无法从管理页验证和维护。

### P1 Debug 日志页未注册

复现：打开 `/debug-log`。

现象：页面显示“路径 /debug-log 未在任何 MOD 的 routes 中注册”。源码中存在 `src/mods/mod-pages/pages/debug-log/page.tsx` 和导出，但 `src/mods/mod-pages/manifest.ts` 未注册该路由。

影响：运行日志页面不可用，调试和用户侧问题定位入口缺失。

### P1 游戏结束页缺少流程守卫并会造成状态错乱

复现：未死亡角色仍在 5 岁故事页时直接打开 `/game-over`。

现象：页面生成“人生落幕”和“英年早逝”总结，五维评分全为 0。点击“查看模拟数据”后跳回 `/game-story`，故事进程变为第 0 轮，年份显示 `2000年` 但年龄仍为 `5岁`。

影响：可绕过生命周期进入结局页，并污染当前故事状态显示。

### P1 角色预设保存疑似无效

复现：角色创建页点击“+ 保存预设”，再点击“保存”。

现象：按钮切换为“保存 / 取消”后，点击“保存”没有关闭状态，也没有成功或失败反馈。

影响：用户无法确认预设是否保存，且交互像卡住。

### P2 说明文档内容陈旧

复现：欢迎页点击“说明文档”。

现象：功能说明仍包含旧版本、旧子系统数量和旧 orchestrator 描述，和当前重写文档口径不一致。

影响：用户会按照过时能力理解当前版本。

### P2 更新日志加载更多无效

复现：说明文档切到更新日志，点击“加载更多历史版本”。

现象：列表没有明显新增内容或状态变化。

影响：更新日志入口不可验证实际历史内容。

### P2 自定义世界反馈和删除确认不足

复现：世界选择页展开自定义世界，新增、编辑、删除一个自定义世界。

现象：新增后表单清空但无明显成功反馈；删除立即生效，无确认弹窗；编辑后保存列表和空表单同时展开，界面状态偏乱。

影响：用户容易误删自定义世界，也不清楚新增是否成功。

### P2 自定义种族在搜索过滤下反馈缺失

复现：角色创建页展开更多种族，搜索“精灵”，再添加自定义种族。

现象：自定义项添加后因为仍处于搜索过滤状态，没有可见新增结果或成功反馈。

影响：用户会误以为添加失败。

### P2 命格卡片缺少语义交互

复现：命格抽取完成后检查可交互元素。

现象：候选命格卡片可鼠标点击，但不是语义按钮，自动化只能用坐标点击；键盘和辅助技术可达性不足。

影响：可访问性和自动化回归测试稳定性差。

### P2 命格库数量显示含义不清

复现：命格生成完成后观察“命格库”数量。

现象：候选卡片显示 13 张，但命格库数量先后出现 13、45、54、71 等变化，没有区分“本次候选数”和“累计库数量”。

影响：用户难以判断本次生成结果数量是否正常。

### P2 AI 加载文案过于技术化

复现：命格抽取等待过程中观察加载文案。

现象：出现“端到端加密”“第一个 token”“校验完整性”等技术/广告式提示。

影响：和人生模拟产品语气不一致，且可能误导用户理解真实网络安全能力。

### P2 手动存档缺少成功反馈

复现：故事页点击“存档”，选择槽位 2，输入“全功能测试-初始存档”并保存。

现象：弹窗关闭，但故事页没有 toast 或明确保存成功提示。

影响：用户只能依赖后续继续模拟入口判断是否保存成功。

### P2 寿命检测结果未回填输入框

复现：角色创建页填写背景后点击“检测寿命”。

现象：检测完成显示“寿命约 100岁 · 出生”，但寿命上限和起始年龄输入框未回填。

影响：若这是自动推断结果，用户无法确认提交值是否采用该推断。

### P2 粗粒度时间步长生成中状态暂态不一致

复现：故事页切换到“3年”，点击推进。

现象：生成中曾显示年份仍为 `2002年`，年龄已变为 `5岁`；完成后才修正为 `2005年 / 5岁`。

影响：生成过程中的顶部状态会误导用户。

### P2 移动端角色页底部重叠

复现：390x844 视口打开 `/new-game/character-create`。

现象：“+ 保存预设”按钮位于 y=775，高度 39；底部固定“返回/确认”栏位于 y=790，高度 42，发生垂直重叠。

影响：移动端保存预设和底部操作区可点区域冲突。

### P3 性别扩展项内容调性不稳

复现：角色创建页点击性别“更多”。

现象：扩展列表包含大量玩梗项，和当前叙事系统的严肃模拟口径不完全一致。

影响：不一定是功能错误，但会影响沉浸感和产品调性。

## 通过项

1. 欢迎页、免责声明、设置弹窗、模型配置和 Prompt 预览可用。
2. 世界选择、更多世界、难度切换、自定义世界新增/编辑/删除主路径可用。
3. 世界定制四组参数可切换 AI 决定、选择、自定义，并可进入角色创建。
4. 角色创建的姓名随机、性别/种族选择、寿命检测、角色确认可用。
5. 命格抽取可调用模型生成候选，并选择 3 个命格进入属性分配。
6. 属性分配的加减点、重置、均分、未分配点确认弹窗可用。
7. 命运预览和世界初始化 4 步完成后可进入故事页。
8. 故事页可展开世界信息面板、打开手动存档弹窗、推进生成叙事。
9. 欢迎页“继续模拟”可回到已生成的第 6 轮故事。
10. 游戏结束页“返回首页”和“开始新人生”按钮可跳转到对应页面。
11. 移动端欢迎页、世界选择页、世界定制页、故事页在 390x844 下无横向溢出，关键按钮可见。
