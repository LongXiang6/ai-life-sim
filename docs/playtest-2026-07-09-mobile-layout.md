# 2026-07-09 移动端核心模拟界面布局测试

## 目标

- 移动端核心模拟页上半部分 HUD/UI 低于半屏。
- 顶部主操作保持 3 个：更多、时间推进长度切换、世界信息。
- 存档、主界面收进更多菜单。
- 下半部分优先留给叙事区域，展开世界信息后叙事区域仍应可读。
- 参考文件独立存放：`docs/reference/jinen.md`，不合并进技能文件。

## 变更

1. `game-story/page.tsx`
   - 顶部操作从 4 个按钮改为 3 个按钮。
   - 新增更多菜单，菜单项为存档、主界面。
   - 时间菜单、更多菜单互斥打开。
   - 自动保存提示改成页面局部样式，方便移动端压缩为单行。

2. `GameStory.module.css`
   - 移动端 header 从纵向堆叠改为左右两栏。
   - 右侧固定承载年龄、3 个按钮和保存状态。
   - 默认 HUD 高度压缩到 115px。
   - 时间菜单移动端最大高度 360px，可滚动。
   - 世界信息面板移动端最大高度 30dvh，可纵向滚动。
   - 世界标签移动端允许换行，禁止内部横向滚动。

## 移动端实测

视口：390 x 844。

| 场景 | 结果 |
|------|------|
| 默认 HUD 高度 | 115px，占 13.6% |
| 默认叙事区高度 | 729px，占 86.4% |
| 顶部按钮 | 3 个：更多、年、世界 |
| 页面横向溢出 | 无 |
| 更多菜单 | 存档、主界面，菜单项 40px |
| 时间菜单 | 12 个选项，最大高度 360px，内部滚动 |
| 世界面板展开 | 面板 253px，占 30.0%；叙事区 476px，占 56.4% |
| 世界面板横向溢出 | 无 |
