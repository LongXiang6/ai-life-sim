## 1. 反馈核查

生产反馈所称“每次都不顺、获得新力量总被官方鉴定”不是逐轮事实：样本角色确实较快获得能力、完成救治并得到认可。但连续 20 轮故事中，检查、登记、复核、封存和认证被多次用作默认变化来源，且主 Prompt、跨年/月提示与情节结构系统都把压力或阻力写成高频必选项。

结论：不取消失败、冲突、代价或符合世界规则的机构介入；修复的是“每轮必须加压”“新能力自动触发机构审查”“已解决障碍换名复用”和“结尾凭空加入观察者或新势力”的结构性偏置。

## 2. 生效行为

1. 三段结构改为变化起点、行动与发展、后果与新局面。
2. 机会、发现、掌握、认可、休整、关系回暖、成功兑现和合理冲突均可成为变化驱动力。
3. 新能力、资源、身份或地位只有在世界规则、既有势力关注或前序事件已建立直接因果时，才允许触发机构介入。
4. 同类审查或障碍仅在未解决且本轮确有推进时延续，结案后不得换名复用。
5. 开局从世界、背景和随机结果推导，不默认贫困、羞辱、资格审查或被针对。
6. 结尾可以由成果、下一目标或关系回声形成牵引；没有前序因果时不得凭空加入陌生观察者、新机构或突然通知。

## 3. 确定性回归

| 检查块 | 结果 | 证明内容 |
|---|---|---|
| 固定 Prompt | 通过 | 存在平衡变化驱动力、机构因果、重复障碍和结尾牵引规则；旧强制压力措辞消失 |
| 动态叙事提示 | 通过 | 跨年、月度和持续目标不再优先要求社会压力或同类阻碍 |
| 时间尺度 | 通过 | 跨月与多年仍完整覆盖因果跨度，但起点不再固定为压力 |
| 情节结构 | 通过 | 低张力可由机会、发现、目标或关系变化推进；升温阶段禁止机械制造威胁、审查或针对 |
| 格式修复 | 通过 | 修复只恢复协议与三段结构，不重新加入强制阻力或障碍 |

## 4. 真实模型切片

固定 Provider 为官方 DeepSeek，模型为 `deepseek-v4-flash`，Prompt 版本为 `4.3.0`。四个用例均使用固定世界、角色、历史和本轮引导；判定由预设允许项与禁止项完成，不让模型自评。

| 用例 | 目标 | 结果 |
|---|---|---|
| `BAL-01` | 无监管因果的新能力直接兑现成果 | 通过；完成治愈、形成口碑与后续工作，没有机构审查、登记、封存或监管 |
| `BAL-02` | 已有城市规则与事故前因时保留合理复核 | 通过；复核按已建立规则执行并当轮给出结果，没有凭空加入陌生观察者或新势力 |
| `BAL-03` | 已结案手续不再换名复用 | 通过；主线转向导航发现、能力展示和新机会，没有重新核验、补登记或档案调查 |
| `BAL-04` | 稳定家庭开局不套负面模板 | 通过；出生现场普通、安稳且有照料，没有贫困、羞辱、资格审查或被针对 |

四例共执行六次模型请求：两例首轮已返回完整协议，两例使用应用现有的一次普通格式修复后通过。格式修复保留原有剧情事实，没有新增压力或障碍。

## 5. 结论

反馈中对结果频率的描述存在夸张，但其指出的 Prompt 结构偏置真实且可复现。Prompt `4.3.0` 已把变化驱动力从“强制压力”改为“因果允许的多种变化”，同时保留世界规则成立时的冲突、失败、代价和机构行为。
