## 1. 原始问题与结论

玩家诊断编号 `U4Q32L` 的两项反馈均有真实生产证据，不属于单一玩家偏好：

1. 玩家明确的异界专属能力被叙事改写为当地药剂可以赋予的通用能力，破坏了设定归属。
2. 三次人生首轮在没有玩家要求的情况下跳到已经训练三周、工作一个月或长期待在组织后的状态，没有说明角色如何来到当前世界或关系如何建立。

根因是固定主叙事约束缺少明确的专属设定归属规则和首轮入口规则，同时旧首轮信息优先级把低层基础属性放在角色身份与背景之前。修复由服务端固定 Prompt 资产承担，版本提升至 `4.5.0`。

## 2. 验收矩阵

| Case | 预期结果 | 状态 |
|---|---|---|
| 专属异界能力 | 保持角色独有来源、名称、边界和事实归属；无因不得变成当地常见能力 | 通过 |
| 当地人物误解 | NPC 可以按当地知识误判，但叙事真相不能随误判被偷换 | 通过 |
| 穿越或跨世界抵达 | 首轮说明触发过程，或至少说明直接后果、最初处境和第一段关系如何开始 | 通过 |
| 本地原生角色 | 不虚构穿越，通过现场、家庭、职责或关键关系的首次回应建立社会位置 | 通过 |
| 玩家明确中途开场 | 允许按玩家要求跳到数周或数月后，但必须给出必要过渡和已成立关系依据 | 通过 |
| 无依据时间跳跃 | 首轮不得直接声称已训练、工作、入职、加入组织或建立亲密关系数周数月 | 通过 |

## 3. 规则边界

- 玩家明确允许共享，或前序剧情已经建立复制、传承、窃取等直接因果时，专属能力可以发生有依据的转移。
- 名称相似、机构猜测、药剂反应或当地传说本身不能证明存在同源能力。
- 本规则不禁止后续合理时间推进；时间推进继续由时间系统、当前事实和叙事过渡共同约束。
- 本规则不要求每个开头都解释宏大背景，只要求玩家能理解角色为何在此、刚发生了什么以及第一段行动或关系从何开始。
- 世界规则仍可限制能力表现，但不能借限制把玩家原创设定改写成他人所有。

## 4. 数据与隐私

验收只记录脱敏后的问题类型、规则结论和测试结果，不复制玩家完整故事、Prompt、响应或其他生产正文。生产内容仅由授权运维在私有诊断目录中按编号查询。
