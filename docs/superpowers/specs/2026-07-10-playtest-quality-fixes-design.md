# 2026-07-10 测试问题修复设计

> 当前命格首屏口径以 [`PD-013`](../../product-decisions.md#pd-013-ai-命格首屏三路并发与十条批量) 为准。本文件第 1 节中的“12 条”“单路/不并发”是 2026-07-10 的历史方案，已被用户于 2026-07-18 明确提出的“三路并发、每路 10 条、满 5 条即用”取代；其他测试问题仍保留为历史设计记录。

## 目标

修复本轮测试发现的九项问题，同时保持 `mod-engine` 对时间、叙事编排、预生成和解析的单一权威；不改变存档结构、公开 API、AI 返回 schema、模型供应商或依赖链。

## 设计决策

### 1. 命格抽取（历史方案，已被 PD-013 取代）

- 首屏只请求满足展示所需的 12 个候选，不再并行生成 3 组各 20 个大响应。（历史口径，已取代）
- 点击后立即发起请求；后台补池改为首屏可用后的独立小批次工作，不阻塞用户进入下一步。
- AI 模式的等待、缓存和兜底语义以 [`PD-001`](../../product-decisions.md#pd-001-ai-命格抽取等待与兜底) 和当前生效的 [`PD-013`](../../product-decisions.md#pd-013-ai-命格首屏三路并发与十条批量) 为准：当前首屏三路并发、每路 10 条，累计 5 条有效去重 AI 命格即交接，不设页面级超时，不混入本地预设。
- 命格描述限定为开局前已经成立的天赋、倾向、认知或行为机制；禁止绝对年份、具体年龄、过去经历和未来事件。

### 2. 时间推进与预生成

- 主推进与预生成不得同时写共享 orchestrator。主推进开始时使当前预生成失效，并等待其退出共享状态区；旧预生成不得在收尾阶段恢复或覆盖主推进状态。
- 保留 `TimeSystem.alignRoundToNextPeriod` 的既有语义：粗粒度已经叙述完的区间不会被细粒度重复叙述。
- 年切季/月/日从下一年开始；月切季从下一季开始；所有时间标签仍由引擎统一派生，页面不补算。

### 3. 叙事解析

- 保持 `[NARRATIVE]...[/NARRATIVE][META]...[/META]` 和现有结构化 schema 不变。
- 解析器容忍模型常见的信封错误：重复 `[NARRATIVE]`、缺少 `[/NARRATIVE]`、缺少 `[/META]`，以及正文由 `[META]` 提前终止。
- 只有在能够恢复完整 JSON 对象时才接受缺少结束标签的 META；无法恢复时沿用现有降级链并保留诊断信息。
- UI 正文不得泄漏协议标签，也不得因最长中文段落兜底而丢失前后段落。

### 4. 叙事时间视角与命运分叉

- 年：使用宏观年度视角，概括阶段变化、长期关系、目标与结果。
- 季：描述季度内的阶段性进展、环境变化和中期选择。
- 月：聚焦当月可持续推进的生活、关系、学习或工作变化。
- 日：聚焦具体日常、小事件与即时感受，但仅在长期轨迹确实出现分歧时生成分叉。
- 分叉选项必须至少影响身份、核心关系、长期目标、关键资源、阵营、存亡或不可逆轨迹之一；鸡毛蒜皮的选择直接写入正文，不生成分叉。

### 5. 节日与现实历法

- 不启用 dormant 的完整 `CultureSystem`，也不恢复传统、改革、艺术等其他模拟系统。
- 从 `mod-culture` 适配一个无状态、轻量的历法上下文提供器，通过公共 API 向叙事引擎提供可用的节日配置。
- 精确节日数据存在时按月/日匹配；没有配置时，不在本地硬编码中国或某类世界观，而是提示 AI 根据世界设定、地区、社会制度和当前日期推断节假日、学期、寒暑假与工作日合理性。
- 现实或类现实世界必须避免在法定假期、寒暑假或明显非上学日机械生成普通上课情节；非现实世界遵循其世界设定中的历法和社会节律。

### 6. 提示词与 UI

- 最新叙事条目取消专属底色，只保留现有布局、排版和动效。
- 不可变提示信息按相关性裁剪：非超凡世界不发送无关力量体系全文；重复的 schema 解释和 few-shot 压缩为最小充分版本。
- 动态时间、分支选择和历法约束保持在动态消息末尾，避免污染稳定缓存前缀。

## 数据流

1. 用户点击推进或切换步长。
2. 引擎使旧预生成代次失效，并保证共享 orchestrator 只有一个写入者。
3. `TimeSystem` 完成必要的周期对齐并产生权威时间标签。
4. orchestrator 组装精简后的稳定上下文，以及当前粒度、日期和节日/校历动态提示。
5. AI 返回标签信封；容错解析器恢复完整正文和 META。
6. 分支质量约束由 Prompt 主导，现有结构化字段与落地链不变。

## 错误处理

- 预生成失效后只丢弃自身结果，不恢复已经变化的主状态。
- 命格单次请求失败后继续等待下一批；页面保持可观测进度，用户离页时中止未完成的首屏任务。
- 标签解析失败时先尝试边界恢复，再走现有 JSON/正文降级；不使用字符串截断伪造成功。
- 节日配置缺失时退化为世界设定驱动的合理性约束，不退化为固定国家节日表。

## 验收

- 5 个有效命格候选不再等待三路 10 条请求全部完成；描述不含年份或传记事件。
- 年切季/月/日、月切季等场景无时间回退或重复区间。
- 已知 malformed 标签样本能恢复完整正文与 META。
- 2006 年春季 1 月 2 日等日期不会在无合理说明时生成普通上学日。
- 分叉选项均能说明其长期影响维度。
- 最新叙事无专属底色。
- 提示词字符数相对基线下降，且 schema、叙事质量约束和完整性不降低。

## 自审结论

- 无 `TBD`、占位或未决产品语义。
- 不启用其他 dormant 模拟系统，不引入依赖，不改变持久化或公开契约。
- 九项问题均有对应实现方向和回归标准。
