## 1. 版本定位

服务器当前运行的是废弃项目 2.7.4。5.0.0 是以旧版真实代码、帮助文档和更新日志为对照完成的整体重写，目标不是恢复最多的系统数量，而是先交付一条稳定、沉浸、可持续游玩的 AI 人生叙事主链。

5.0.0 的产品核心是：玩家创建一个明确的世界与角色，抽取真正影响叙事的命格，在一致的时间线上经历第二人称故事，并能在长局中保持因果、记忆和存档完整。

## 3. 叙事与娱乐性重做

### 3.1 第二人称与现场感

- 正文全程使用“你”，不把玩家写成第三人称传记中的角色。
- 每轮至少落入一个玩家当时能够感知的现场，包含具体动作或对话、行动阻力、他人回应与可见后果。
- 旧版中优秀的短场景、动作—反应句法被保留为风格证据；旧版的事实、输出 Schema 和关键词语义判断不直接复用。

### 3.2 时间服务剧情

- 一轮表达“这段时间发生了什么”，而不是“每个时间步长分别发生了什么”。
- 月、季、年和多年推进都围绕同一主线选取代表性现场，长跨度只用必要过渡连接起点、转折与结果。
- 粗粒度切到细粒度时，引擎记录上一叙事节点并对齐到下一个合法节点，避免重复讲述已经覆盖的年份或月份。

### 3.3 质量优先于字数

- 目标字数不再是拒绝、重写、回滚或截断条件。
- 偏长但完整、有吸引力的故事优于精确贴字数却空洞的文本。
- 项目级红线禁止按字符、条目、数组位置或容量上限硬截断任何会影响剧情的语义数据。

## 4. 长局记忆与压缩

每个通过校验的主叙事响应除了正文，还必须提供：

- 一句完整 `digest`；
- `keyEvents` 关键事件；
- 每个事件 0—100 的 `importance`；
- 事件涉及的明确 `entities`。

L1 每 10 轮生成一个摘要块，并延迟一个完整块：第 21 轮总结第 1—10 轮，第 31 轮总结第 11—20 轮。延迟期间最近约 20 轮完整正文继续进入上下文，远期内容由分层摘要与检索索引覆盖，原始叙事不因 Prompt 窗口变化被删除。

## 5. 创建、命格与跨局成长

- 新游戏流程统一为：欢迎 → 世界选择 → 世界配置 → 角色创建 → 命格抽取与选择 → 属性分配 → 命运预览 → 主故事。
- AI 命格首屏同时发起三路请求，每路正好 10 条；累计 5 条有效去重候选即可交给玩家。
- AI 模式不使用本地预设兜底；本地预设只在玩家明确关闭 AI 命格时使用。
- 普通命格仍选择 3 条；完成一生后可从 3 个神话候选中封存 1 条，下一局最多装备 1 条独立神话命格。

## 6. 存档与兼容性

5.0.0 的存档由元数据索引与分槽 OPFS 文件组成，手动存档和自动存档均使用串行事务替换；写入失败会尝试回滚旧槽位。存档管理页支持查看、加载和二次确认删除。

2.7.4 的聚合存档结构不能自动导入 5.0.0。旧版 `ai-life-sim:game-saves` / `ai-life-sim:save-meta` 与新版 `save-manager` 索引和分槽文件不是同一格式；5.0.0 不会把旧对象伪装成已迁移的新存档。玩家升级后需要开始新人生。

## 7. 当前没有恢复的旧版能力

以下系统在废弃版 2.7.4 中曾以不同程度参与模拟，但没有全部进入 5.0.0 当前 MVP 的正常叙事回合：

- 经济、人口、工作、物品与定居地；
- 政治、法律、阵营、国家关系与社会分层；
- 教育、家庭、关系、声望、艺术与作品；
- 气候、生态、地理、资源与污染；
- 科技、工业、完整修炼/战力/神明/怪物体系；
- NPC 行为与 NPC 记忆；
- 历史事件池、因果模拟与世界地图。

这些源码或 MOD 的存在不等于已经可玩。当前运行能力只以 `src/mods/mod-engine/helpers/mvp-stages-config.default.json` 为准；后续恢复必须逐项经过产品确认、运行接线和玩家路径验收。

## 8. 发布验收

状态：已完成。

已完成的真实玩家路径包括：欢迎与说明、设置、存档入口、预设与自定义世界入口、世界配置、角色创建、AI 命格准备与三选、四项属性、命运预览、两轮主故事、年切月时间边界、手动存档、二次确认删除、自动存档恢复、刷新恢复、结算页流程守卫、390px 移动端与桌面端布局。

首轮正文为 521 个可见字符、严格三段，第二人称“你”出现 16 次，准确使用“沿海小城旧书店”的玩家背景；完成 2000 年叙事后切换到月步长，下一轮正确显示 2001 年冬季 1 月。浏览器记录 0 条 error。

全部通过：`check:ui`、`check:structural`、剧情硬截断审计、压缩运行测试、叙事接线、Prompt 接线、lint、TypeScript、完整 `gate-check` 和 `npm run build`。

非阻断基线：`npm run check:mod` 仍报告历史迁移期 80 项，与任务前记录一致；命格后台补池在模型返回空解析结果时产生 5 条自动重试 warning，但首屏 5/5、选择与后续流程均正常。完整证据见 `docs/playtest-2026-07-18-release-5.0.0.md`。

本结论只确认 5.0.0 MVP 可发布，不宣称第 7 节列出的延后模拟系统已经恢复。当前任务没有部署服务器，线上仍是 2.7.4。
