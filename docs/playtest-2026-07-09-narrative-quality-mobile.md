### 6. 废弃项目参照与改动决策

时间：2026-07-09 12:20

参照结果：
1. 远端废弃项目 `http://49.235.100.36:3000/` 可在移动端打开，并可进入免责声明与世界选择页。
2. 远端废弃项目在确认现代地球后提示 `API 未配置`，继续生成需要配置 API Key；本次不向远端旧站提交测试密钥。
3. 本机 `D:\AI\废弃项目` 中的旧项目叙事 prompt 显示，其默认字数上限为 400，并强调近期事件防重复、生命周期约束、每轮 2-4 段。

小范围优化：
1. 新项目默认叙事目标从 500 字调回 400 字，对齐废弃项目的叙事密度。
2. `buildWordCountInstruction()` 增加移动端可读约束：三段合计控制在目标附近、每段不超过约 160 个汉字、避免重复意象。
3. `buildWordCountInstruction()` 增加常用简体中文约束，减少生僻字、异体字、日文新字体或繁体字混入。
4. `normalizeNarrativeParagraphs()` 增加当前测试命中的安全映射 `晩 → 晚`。
5. 移动端分支 UI 增大触控区域：选项最小高度 44px、radio 18px、确认/取消按钮最小高度 44px、字号提升到 14px。

额外观察：
1. 热更新后直接刷新 `game-story` 曾出现顶部状态为第 10 轮/9 岁，但叙事列表显示第 0 轮空状态。
2. 进入 `save-manager` 后点击自动存档，10 轮叙事历史完整恢复；暂记录为刷新恢复链路的待复查问题，不纳入本次叙事质量主线改动。

2. 第 11 轮出现严重完整性问题：正文在 `问能不能来拍一组素材。你点头时瞥见他胸前的证件上写着` 处中断，缺少收束句和第三段心理余韵。

待修正：
1. Prompt 需要明确要求最后一段必须闭合，正文不得以“写着/说/问/看见/递来”等引出句中断。
2. 解析或接收层需要检测明显未闭合的正文，至少记录警告；理想情况应触发重试或不让其进入历史。

修正：
1. System Prompt 增加完整句收束硬约束：正文末尾必须以完整中文句子结束，禁止停在引出句。
2. 字数约束增加第三段收束要求。
3. 叙事拦截器增加未闭合结尾警告。
4. 段落规范化增加末尾残句裁剪：若尾部不是完整句号/问号/叹号等结尾，且最后一个完整句后残片不超过 80 字，则删除残片，不编造补写。
