# Prompt 标准

<!-- RULE id="prompt-standard.user-hard" source="USER-HARD" owner="prompt" status="active" -->
Prompt 只负责让模型生成用户要的内容，并提供合理、充分的生成职责与返回协议。先保证人生重开模拟器的核心产物成立，不以规则最短或最少为目标，也不为精简删掉完成生成所需的方法。目标清晰，路径开放；禁止把过渡性设计、过渡性防御设计或假设问题的限制写成 Prompt 目标。
<!-- END RULE id="prompt-standard.user-hard" -->

<!-- RULE id="prompt-standard.single-main-call.user-hard" source="USER-HARD" owner="core-round" status="active" -->
主故事流程每轮只发起一次主故事 AI 调用；该调用内部完成事实恢复、控制平面候选适配、世界局面形成、事件裁决、玩家参与、事件结果保存材料和正文编译。出生背景、人生规划、方向、抽象事件和未来世界承诺由条件控制平面按缺口或来源版本失效触发，生成结果可跨回合复用，但不得直接写入玩家历史；不得把这些辅助调用改成每轮固定调用或让其代替主故事事实裁决。故事连续性与天赋成长仍只处理各自既有后调用职责，不回写或重做主故事结果。
<!-- END RULE id="prompt-standard.single-main-call.user-hard" -->

## 职责结构

固定 Prompt 按调用协议使用可读、自足的消息结构；需要机器解析的动态输入与输出使用 JSON。只保留实际有职责的规则段，通常包括：

- `身份`：模型的首要职责、裁决权限与最终产物；主叙事先形成世界局面并裁决事件，最后编译人生记录。
- `目标`：用户要得到的结果。
- `输入职责`：各类输入提供什么事实、条件或意图。
- `生成流程`：在一次调用内形成并组织本轮新变化、玩家交互、事件结果和正文。
- `表达`：必要的人称、主体或视角。
- `输出契约`：工具、字段、类型和互斥关系。

规则段是否保留取决于生成职责，不取决于固定数量或长度。合并重复与冲突，不为形式完整强行加入状态审计、证据清单、固定写法或示例。固定规则先定义一次调用的完整生成职责，随后集中提供五段只读数据；模型在数据之后沿单向流程恢复事实、形成局面、裁决玩家交互与结果、编译正文并返回 JSON。消息中的数据顺序是输入组织方式，不是要求模型回读、复述或管理的执行编号。世界与既定事实划定边界，玩家提供行动意图，模型按条件裁决世界响应及未决结果。

## 文字游戏随机故事生成

主叙事的主身份是以玩家人生与世界交互为主体的文字游戏式人生重开模拟器，叙事是将结果编译为有吸引力的人生记录的末端职责。生成对象是当前条件下随机形成的完整人生记录，不是连续小说片段、单场行动回放或既有历史的改写。世界提供开放的可能性，也按自身规则与利益变化；世界变化构成玩家要遭遇的条件，玩家、天赋、属性和已确认意图改变玩家的参与方式、行动、关系、走向与结果。事件身份、因果主线和正文重心归属于玩家本人，不归属于家庭整体生活。家庭可以作为玩家的背景、资源、关系和处境，但家庭成员的就业、搬迁、收入、手续或家庭存续不能替代玩家成为事件主体。即使玩家处于幼年或依赖阶段，事件主体仍是玩家；照料者行动只有在直接改变玩家的体验、关系、选择、能力或长期位置时才进入主线，玩家可以通过感知、移动、学习、游戏、依恋、恐惧、社交、观察或合龄选择参与。世界中明确写出的规则优先于与其冲突的旧叙述，除非本轮已经成立的因果明确改变该规则。已确认的角色设定、自创成果及其历史来源归属是裁决依据，不因预设情节被翻案；玩家的未决意图不能直接覆盖世界结果。正文涉及玩家时用第二人称，姓名只作输入识别。历史只继承已经成立的状态和因果，不继承上一轮叙事焦点。

在同一次主故事调用中完成以下编排；前置字段输出具体材料，不输出规则复述或自我解释：

1. 从完整输入恢复已经成立的事实、状态、来源归属与仍有效的后果，确认当前适用条件；历史只提供事实相容条件，不提供本轮主题、写法或续写任务。近期最显眼的主题与悬念先降为背景，不作为默认选题。
2. 先从世界规则和相关者行动形成玩家将要遭遇的外部条件、机会、限制或关系变化，再让主要行动者的目标、阻力和选择推动局面转向，最后确定玩家如何遭遇、感知、行动、选择、建立关系、获得、失去或承受结果；宏观由作用范围和玩家所处局面的真实改变体现，不靠夸大规模。没有命运分支不等于角色没有行动；条件允许时，玩家的合龄行动、判断、关系或损失应进入事件因果。家庭事实只有通过玩家的处境、体验、关系或长期后果进入主线。
3. 已提交的事件身份视为已消耗的题目，后续只能作为事实条件。先建立本轮新的事件身份，再从开放可能性选择彼此有实质差异的新事；近期主线只能作为背景条件，比较核心问题、因果机制、主要行动者、作用范围和结果意义，表面换设定或自然后果不算新事。
4. 根据玩家条件、确认的行动意图和世界响应裁决每件新事，将其推演为事件、成因、结果、影响的已成立材料，先于正文输出；主线材料保留局面压力、目标、阻力、选择、转折、结果和代价。不把玩家输入中尚未发生的成功或数值变化当作事实，不预设成败。结果材料不是候选列表、写作计划或详细思考过程。同一事件的起因、行动和直接后果归入同项，不切步骤充当多项经历。
5. 核对世界规则优先级、事实相容、焦点更替、玩家与世界的交互、玩家和天赋作用、获得与代价，再从已成立结果中选择最能呈现玩家人生位置改变且最有故事张力的局面作为阅读重心，用事件概括和代表性细节组织正文。其他独立变化可以并置、反衬或改变其代价；家庭整体生活不能替代玩家经历成为重心。这是阅读组织职责，不规定事件数量或题材，也不要求玩家每轮主动成功。

宏观性来自对事情发展与局面改变的概括，以及外部条件、玩家遭遇与具体表现之间的视野切换，不等于公共新闻起笔，不靠夸大事件尺度，也不把每轮限制在同一种制度、资源或势力冲突。年度或广角窗口的阅读重心应由已经完成的玩家经历、交互或位置变化承担，家庭日常、父母工作、家庭搬迁或短暂现场只作为玩家处境、结果或代价的证据。故事吸引力来自局面压力、行动者目标与阻力、玩家位置、行动、选择、因果转向、结果和代价的组织，不等于连续小说、动作过程或固定戏剧反转。事件两面性由玩家及相关者不同处境下的获得、失去、负担和反应体现；力量与选择的代价来自投入、放弃和反作用，不凭空追加灾祸抵消成功。惊喜与荒诞来自世界特性、偶然性和各方行动交汇，不强制反转、永久牺牲或固定好坏搭配。因果与利益变化连接相关事实，独立变化可并置、反衬或改变阅读重心所呈现的代价，不强造共同原因或时间转场。命运分支非空时落实玩家已选方向，不重新提出同一选择；合龄因果位置不等于每轮主动成功。

时间节点、历史年龄索引和实际时间窗口只供模型判断合龄条件、事实顺序与发展尺度；世界描述中的年代或历法只用于设定识别；时间投影不提供具体日期或季节自然语言素材。历史中的时间措辞是事实来源或索引，不是可见写作素材。正文不是年龄/时间流逝回顾或家庭流水账，而是从最能证明玩家人生位置改变的经历、交互或后果进入，在外部条件、玩家行动、玩家位置和具体证据之间切换；直接组织行动、转折、结果和代价，保留玩家作用和代价，省略无结果过程。外部事实不自动成为玩家知识；即使玩家处于依赖阶段，也不能只写照料者目标或家庭生活，必须写出玩家的合龄体验、行动、关系、能力或位置变化。

## 动态输入

动态区提供世界、玩家档案、天赋、历史输出、属性、时间节点、实际时间窗口、命运分支和已有篇幅偏好等完成本轮记录所需事实。`世界.描述`在既有字段内承载世界基础规则与已有世界子系统的只读状态摘要。维持活动权威规定的五段动态数据和单条 `user` 消息；时间窗口作为现有 `本次信息` 的派生字段进入，不追加顶层数据元素、候选列表、成品示例或第二状态来源。窗口材料说明上一叙事节点、当前结束节点和实际推进跨度，模型据此概括窗口内累积形成的状态变化，不把终点标签或单一现场当作整轮。

主故事历史优先使用所有已有结构化事件结果作为事实依据；只有没有结构化结果的旧记录才回退到完整正文，不让旧正文的段落、转场和文风重新成为选题模板。历史年龄前缀仍保留为输入索引，原始正文仍由历史所有者保存。模型从这些材料继承已成立事实，不继承题目、人物焦点、段落结构、转场方式、文风或时间措辞；历史中的年龄、日期、月份、季节和阶段表达即使属于旧事实，也不构成当前正文或事件结果的写作许可。更早事实继续使用所属系统的现有投影，不增加提取调用或持久字段。

篇幅偏好沿用玩家设置的宽松目标，不另设固定字数或通过截断损失核心结果。字段和状态职责只以活动权威与运行时组装为准。

历史投影已有非空已确认选择时，只附确认方向，不再标未决或附带未选候选；未决分支保持既有信息，源正文和原始选择数据不删除、不迁移。

## 输出协议

工具 Schema、Prompt 和解析器与活动权威保持一致。主故事 JSON 依次输出字符串 `时间定位`、对象数组 `事件结果`，再输出 `正文`、`命运分支`、`属性`、`结局`。每项事件结果使用字符串`事件`、`成因`、`结果`、`影响`，不设事件数或覆盖配额；事件结果中应保留足以组织阅读重心的局面、行动、玩家位置、结果和代价事实。时间定位只作本轮索引；合法事件结果由同一条叙事历史记录保存并投影到下一轮输入，不直接进入界面，不另建世界状态源。应用仍只消费正文、分支、属性和结局。原始响应日志仍完整保留。正文采用的关键事实与因果必须可理解，并由既有历史承接，未采用材料不成为长期事实。属性沿用 `财富` 等公开名称，正文保持非空字符串，未触发分支和结局返回 `false`。保留各项独立恢复，不因事件结果局部缺失或异常阻断可用正文。

## 问题修复

先核对核心产物，再沿 Prompt、动态输入、历史投影、消息顺序、模型参数、解析消费和调用链定位最早偏差，在根因处直接修改。历史事实丢失不能靠更强的“不重复”补救，生成目标偏向连续小说也不能靠去除时间词纠正。删除被取代的防御性规则、过滤、格式补丁和旁路，不以禁词列表、输出过滤、重写、重试或额外调用替代本轮生成职责。

## 测试

先核对被评样本的实际 Prompt 原文、完整组装消息、模型参数和逐字响应，再固定模型、参数、消息顺序、输入、篇幅偏好与输出协议比较，按用户声明的轮次执行。不能只凭相同版本号断言规则相同，也不能把不同历史信息量或推理设置的结果归因于某条 Prompt。

验收先看每轮是否形成新的完整人生记录、多项结果是否真正改变状态、事实是否连续但焦点不被旧事锁定，再检查无时间标记、人称与字段。静态检查不证明真实生成质量；独立 Prompt 评测不证明生产入口、解析、提交和持久化链。测试结果用于判断是否达到设计目标，不把一次失败包装成更多 Prompt 规则，也不自行推进后续轮次。
