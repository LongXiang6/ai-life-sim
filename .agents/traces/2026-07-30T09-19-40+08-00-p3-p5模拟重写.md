## 已确认的执行证据

- 当前唯一推进链为 `game-story -> useSimulationAdvance -> executeRoundV2 -> default campaign stages -> narrative-draft -> narrative-settlement -> RoundCommit -> epilogue-check -> compress-save`；P3-P5 只接入该链，不恢复旧硬编码回合管线。
- P3 最终拥有者为 `geography`、`natural-resource`；`map-projection` 是页面按需调用的纯读取服务。旧 `world-map` 同时拥有地形、人口、势力、资源和外交，且 `mod-world-map` 直接读取 `mod-base-universe`，现已删除；地图页面只消费空间、地理、资源和实体位置投影。
- P4 最终拥有者为 `growth-system`、`achievement`、`reputation`。旧 `skill` 与 `personal-ability` 合并；成就只认历史事件账本事实；声望按人物、上下文和全局评价主体分域，并保留事件依据。
- P5 最终拥有者为 `lifespan`、`lifecycle-system`、`health`。年龄统一由 `totalDays` 派生、推进统一消费 `daysPassed`；`life-stage` 与 `attribute-decay` 内部化；`post-death-epilogue` 改为 `health` 内部的条件流程，由现有 `epilogue-check` 阶段触发。
