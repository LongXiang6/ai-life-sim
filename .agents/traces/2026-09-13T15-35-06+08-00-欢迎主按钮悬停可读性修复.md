## 调研结论与证据

- `.primaryAction:hover/:focus-visible` 与 `routeAction`、`utilityAction` 共用 `background: var(--flow-paper)`；来源：`WelcomeView.module.css`；影响：白色主题下背景变为白色。
- 桌面 `.primaryAction` 使用 `color: var(--text-on-accent, #fff)`，白色主题同值为白色；来源：`WelcomeView.module.css`；影响：hover 背景和文字同色，形成白底白字。
- 四主题在保持 `--flow-accent` 背景并使用 `--text-on-accent` 文字时的对比度为阅读 `5.36:1`、暗夜 `8.02:1`、白色 `6.01:1`、多彩 `5.70:1`；状态：已验证。
- CSS DevTools 强制 `:hover` 后，阅读主题为金底深字、暗夜主题为暖金底深字、白色主题为雾青底白字、多彩主题为紫底白字；来源：本地开发服务器、Puppeteer 与 CDP `CSS.forcePseudoState`；影响：通用白底重置不再作用于主入口；状态：已验证。
- `npm run check:ui`、`npx tsc --noEmit`、定向 ESLint 和 `git diff --check` 通过。响应式浏览器回归仅在 `1024` 及以上视口报告欢迎标题存量尺寸错误，实际为 `56px` 而既有断言预期 `48px`，与本次 hover 样式无关；状态：基线失败已隔离。
