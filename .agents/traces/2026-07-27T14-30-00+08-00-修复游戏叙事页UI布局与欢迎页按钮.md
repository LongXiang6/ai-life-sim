## 变更详情

### 1. GameStory.module.css — sticky header 布局重构

**问题**：`.stickyShell` 内的 header 元素（readerBar、infoPanel 等）随内容一起滚动，未固定在顶部。

**变更**：
- `.bookShell`：从 `display: grid; grid-template-rows: auto 1fr` 改为 `display: flex; flex-direction: column`
- `.stickyShell`：新增 `flex: 0 0 auto; position: relative; z-index: 40; background: rgba(255,255,255,0.98); backdrop-filter: blur(10px)` 使上半部分固定尺寸
- `.reading`：新增 `min-height: 0; flex: 1 1 0; overflow-x: hidden; overflow-y: auto; overscroll-behavior: contain` 作为唯一滚动容器
- `narrativeEndRef` 从 `.bookShell` 移至 `.reading`，使滚动范围正确绑定

### 2. page.tsx（game-story） — addToast 初始化顺序

**问题**：`handleBranchConfirmWithFeedback` 在 `useCallback` 依赖数组中引用 `addToast`，但 `addToast` 声明在该 `useCallback` 之后，导致 `Cannot access 'addToast' before initialization`。

**变更**：
- `const addToast = useToastStore((s) => s.addToast)` 移到 `handleBranchConfirmWithFeedback` 之前（第 123 行）

### 3. 移动端页面宽度适配

**问题**：`TalentDraw`、`WorldCustomize`、`CharacterCreate` 页面使用固定 px 宽度导致不同移动端分辨率下左右留白不一致。

**变更**：
- `TalentDraw.module.css`：容器宽度从固定 px 改为 `width: 100%`，内容区使用百分比 padding
- `WorldCustomizeMobile.module.css`：宽度/高度改为百分比 + 视口单位
- `CharacterCreateMobile.module.css`：同上

### 4. TalentDraw.module.css — 光效截断修复

**问题**：天赋卡 `button` 的 `box-shadow` 光效在 `.candidateList` 滚动区域边界被 `overflow-y: auto` 截断。

**变更**：
- 移除 `.candidateList` 的 `overflow-y: auto`
- 滚动功能移至父容器

### 5. WelcomeView.module.css — 辅助按钮大小统一

**问题**：四个辅助按钮（账号与云端、设置、游戏说明、反馈与建议）共用相同 CSS 类却出现大小不一致，`min-height` 无法约束 Grid 内置 `min-height: auto` 导致内容撑大行高。

**变更**：
- `.secondaryBtn`：`min-height: 6.1cqh` → `height: 6.1cqh` + `min-height: 0`
- `.secondaryBtn .routeCopy`：移除 `white-space: nowrap` 和 `text-overflow: ellipsis`，保留 `overflow: hidden`
- `.secondaryBtn .routeCopy strong`：新增 `overflow: hidden; text-overflow: ellipsis; white-space: nowrap; display: block; line-height: 1.2`，文本直接元素上做截断
