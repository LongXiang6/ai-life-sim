## 调研结论与证据

- 宏观最早根因在固定 Prompt 与动态时间提示的相互强化：固定规则允许从单一现场进入，并禁止总结跨度/用时间锚点组织正文；`prompt-builder.ts` 又把 `timeGuideText` 包装成“仅用于事实校验、不是剧情素材/模板”。来源：`src/mods/mod-engine/server/narrative-system-prompt.ts`、`src/core/ai-service/prompt-builder.ts`、`src/mods/mod-engine/helpers/time-scale-narrative.ts`。影响：年及多年窗口的宏观信号被降权，模型合法地选择近景片段。状态：已修复并由回归验证。
- 宏观输入材料本身不足以支撑完整历史链：`prompt-context-runtime.ts` 主要投影当前区域、单句世界事件候选和压缩事实；`world-event-prompt-projection.ts`/事件目录缺少起因—发展—结果链，`time-bridge-summary.ts` 仅比较修炼境界。来源：对应文件与子代理只读审计。影响：不能仅靠改措辞要求模型凭空写出跨度过程；已在不新增状态所有者的前提下，把现有窗口事实明确投影为可叙述的变化链/差分契约，并要求候选按事件链展开。状态：已修复并由回归验证。
- 天赋“此人”最早根因在生成 Prompt 文体/主语契约缺失，不是解析器或 UI：`destiny-pattern-prompt.ts` 未规定 description/effect 首句入口，`destiny-pattern-context.ts` 没有文体锚点，解析器只判结构非空。03 成长与轮回升阶 Prompt 也存在同类缺口。来源：`src/mods/mod-character/prompts/destiny-pattern-prompt.ts`、`src/mods/mod-engine/server/narrative-talent-growth-system-prompt.ts`、`src/mods/mod-character/prompts/reincarnation-promotion-prompt.ts`。影响：模型默认第三人称说明体，所有同构输出都能通过现有校验。状态：已修复并由 Prompt/终端回归验证。
- 长跨度仍共用玩家字数目标（通常默认200字；缺失字段时 `prompt-builder.ts` 回落300字），没有按时间数值自动改变玩家篇幅。来源：`src/foundation/constants/narrative-word-count.ts`、`src/mods/mod-engine/constants/narrative-config.ts`、`prompt-context-runtime.ts`。影响：短字数可能压缩长跨度；本轮采用不改玩家设置、改为完整事件链与窗口覆盖优先的最小契约。状态：已确认并已处理。
- 已实施的最小处理保留玩家字数设置不变，在时间提示、固定 Prompt 和事件投影中声明“字数为软参考，完整事件链与窗口覆盖优先”；没有新增长度字段或改写玩家设置。来源：`src/core/ai-service/prompt-builder.ts`、`src/mods/mod-engine/helpers/time-scale-narrative.ts`、01 活动权威。状态：已验证。
- 保护资产与缓存版本已同步：主叙事 `7.4.4→7.5.0`，普通命格 `8.5.0→8.6.0`，03 成长 `3.3.0→3.4.0`，轮回升阶 `2.0.0→2.1.0`；旧主叙事/缓存版本引用已清理。状态：已验证。
- 天赋链审计确认：首批命格与后台补充共用 `buildDestinyPatternSystemPrompt` 和 `8.6.0` 缓存版本；03 成长使用 `3.4.0` server asset；轮回升阶直接消费 `2.1.0` Prompt。当前没有活动代码残留旧版本；`generateFromAI()` 仍是无内部调用的公开注入口，本轮不加输出过滤或兼容旁路。状态：已验证接线，真实生成首句仍待 Provider live 证据。
